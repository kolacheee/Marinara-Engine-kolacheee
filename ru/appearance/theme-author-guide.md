# Руководство для авторов тем

Это руководство для тех, кто создает свои темы или делится ими. Первая часть поможет сделать первую тему без опыта программирования. Остальное – справочник: все цвета, изображения и элементы, которые может менять тема, и правила безопасности для любой темы. О выборе, пробе, импорте и удалении тем читайте в разделе [Собственные CSS-темы](custom-css-themes.md).

**Версия контракта токенов 1** (`--mari-tokens-version: 1` на `:root`). Имена из этого руководства продолжают работать между выпусками. Если имя приходится менять, версия повышается, а изменение попадает в раздел [Изменения](#changes) в конце. Всё остальное (другие переменные `--ov-*`, `--mari-*` и `--marinara-*`, классы Tailwind, структура элементов) относится к внутренней реализации и может измениться в любом обновлении.

## Ваша первая тема: шаг за шагом

Тема – это короткий список настроек на CSS, языке, которым веб-страницы задают цвета и шрифты. Для начала знать CSS не нужно. Каждая строка выглядит как `--name: value;`: **токен** (именованная настройка, начинающаяся с `--`), двоеточие, значение и точка с запятой.

1. Откройте **Библиотека → Настройки → Оформление** и нажмите **CSS-темы** в строке разделов.
2. Чтобы изменить начальную тему, скачайте понравившуюся через **Открыть галерею тем**, найдите ее в разделе **Начальные темы** и нажмите **Клонировать и изменить** (значок копирования). Marinara создаст вашу копию, например "Petal OS (моя копия)", и откроет ее в редакторе. Начальные темы доступны только для чтения, поэтому оригинал всегда остается. Чтобы начать с нуля, нажмите **Новая тема**. В шаблоне есть строки между `/*` и `*/` – они выключены. Удалите эти знаки вокруг строки, чтобы включить ее.
3. Введите название в поле названия.
4. Измените цвет. Найдите строку вроде `--primary: #3fae7a;` и замените цвет. `#3fae7a` – шестнадцатеричный код цвета. Его можно получить в любом инструменте выбора цвета в интернете. Подойдут и названия, например `teal`.
5. Оставьте **Предпросмотр** включенным. Приложение меняется по мере ввода, и каждое изменение видно сразу.
6. Посмотрите под редактором. Надпись **Проблем с CSS не найдено.** означает, что с CSS всё в порядке. Иначе каждая проблема показана с номером строки, например пропущенная `;` или `}`.
7. Нажмите **Сохранить**. Новая тема включится, и Marinara спросит **Оставить эту тему?** Нажмите **Оставить тему** в течение 15 секунд, иначе вернется прежний вид.

Токены, которые обычно меняют первыми:

| Токен | Что окрашивает |
| ---------------- | -------------------------------------------- |
| `--background` | Страницу позади всего остального |
| `--foreground` | Основной текст |
| `--primary` | Кнопки, ссылки и выделение |
| `--card` | Карточки и панели |
| `--sidebar` | Боковые панели чатов и библиотеки |
| `--border` | Линии вокруг элементов |
| `--mari-font-ui` | Шрифт приложения, например `"Georgia", serif` |

Небольшая тема:

```css
:root {
  --mari-tokens-version: 1;
  --primary: #3fae7a;
  --mari-selected-tint: var(--primary);
  --mari-font-ui: "Inter", system-ui, sans-serif;
}

[data-theme="dark"] {
  --background: #0f1712;
  --card: color-mix(in srgb, #0f1712 80%, transparent);
  --sidebar: #0b120e;
}
```

`:root { … }` содержит настройки для всех цветовых схем. `[data-theme="dark"] { … }` – только для темной, а `[data-theme="light"] { … }` – только для светлой. Полный список токенов во время работы можно открыть под редактором: **Справочник CSS-переменных**. Или прочитайте раздел [Цветовые токены](#colour-tokens) ниже.

### Добавление изображений и шрифтов

Откройте **Изображения и сведения для публикации (автор, версия, миниатюра, шрифты)** под редактором и нажмите **Добавить изображения**. Нажмите название изображения, чтобы вставить его в CSS в позиции курсора. О том, где можно размещать изображения, читайте в разделах [Изображения](#pictures) и [Фоновые изображения](#backdrops).

Изображения и шрифты должны находиться внутри темы. Тема не может загружать что-либо с другого сайта, поэтому ссылка на изображение или шрифт Google Fonts в CSS не сработает.

### Попросите Professor Mari создать изображения

Если в разделе **Подключения** настроена модель изображений (Codex, NovelAI, ComfyUI, модель изображений OpenAI и так далее), Professor Mari может создать изображения для темы и поместить их в нее. Попросите ее обычными словами, например "сделай для моей темы Harbor фон с ночным небом" или "добавь карточкам на главной латунную рамку".

1. Mari работает только с вашими темами. Для начальной темы сначала нажмите **Клонировать и изменить** и попросите ее работать с копией.
2. Она сама пишет промпт изображения и отправляет его модели в точности как написала. Ваши профили стиля изображений и префиксы промптов (обычно настроенные для изображений персонажей) не добавляются, чтобы вместо фона не получился портрет.
3. Mari сама просматривает каждое изображение (маленькие – увеличенными, прозрачные части – на сером фоне), прежде чем описать его, а вы видите его до внесения изменений. Попросите несколько версий на выбор (до 4 за раз) или правки вроде "обрежь до верхней половины", "сделай белый фон прозрачным" или "уменьши". Каждая правка создает новую версию, предыдущие сохраняются.
4. Когда вы согласитесь, Mari сохранит изображение в тему (в формате WebP, как и кнопка **Добавить изображения**) и вставит его в CSS темы. Оно появится в разделе **Изображения и сведения для публикации**, как любое изображение, добавленное вами.

Рисованные украшения вроде перил, оград и кнопок отправки – это SVG-изображения. Mari может менять их цвет напрямую, без модели изображений, и они останутся четкими.

Каждое изображение создается столько, сколько нужно вашей модели, часто от полуминуты до полутора минут. Если подключение изображений использует ваш собственный рабочий процесс ComfyUI, встроенный в него текст по-прежнему отправляется.

### Как поделиться темой

1. В разделе **Изображения и сведения для публикации** заполните поля **Автор**, **Версия** (например, `1.0`), **Описание** и **Миниатюра**, выберите **Предназначено для** (темной, светлой темы или обеих). Чтобы предложить вместе с темой ваши цвета и шрифт, нажмите **Использовать мои текущие настройки оформления** в разделе **Настройки**. Сохраните.
2. Нажмите **Экспорт** (значок загрузки) в строке темы. Marinara сохранит один файл `.json` с CSS, изображениями и шрифтами внутри.
3. Если вы использовали чужие изображения или шрифты, откройте файл в текстовом редакторе, укажите авторов и лицензию. См. [Файлы тем](#theme-files).
4. Отправьте файл. Другой человек импортирует его кнопкой **Импортировать файл** и перед установкой увидит ваше имя, сведения об авторах и список всего, что меняет тема.

### Если что-то пошло не так

Marinara сохраняет работоспособность верхней и боковых панелей, <kbd>Ctrl</kbd>+<kbd>K</kbd> и поля сообщения при любой теме. Если тема скрывает, перемещает или перекрывает один из этих элементов, при сохранении вы узнаете, что нарушено. Можно выбрать **Все равно сохранить**, но Marinara выключит тему во вкладке, как только она нарушит работу такого элемента. Чтобы в любой момент вернуть обычный вид, нажмите <kbd>Esc</kbd> три раза, добавьте `?safe` в конец адреса или нажмите <kbd>Ctrl</kbd>+<kbd>K</kbd> и введите "Своя тема".

На начальных темах удобно учиться. Клонируйте одну и изучите ее CSS, чтобы увидеть, как она использует токены и привязки элементов, описанные ниже.

## Как тема получает приоритет

CSS самого приложения находится в каскадных слоях, объявленных в самом начале `index.html`:

```
mari-protected, mari-theme-important, theme, base, components, utilities, mari-app, mari-pickers
```

- Тема **не входит в слой**, поэтому обычный селектор темы имеет приоритет над любым правилом приложения без `!important`,
  независимо от специфичности правила приложения.
- `mari-pickers` содержит настройки оформления (фон, акцент, шрифты, цвета чата). Он находится
  выше значений приложения по умолчанию и ниже темы, поэтому цвета темы важнее настроек, а раздел
  оформления сообщает пользователю, когда тема переопределяет настройку.
- `!important` в теме тоже работает. Такие правила копируются в `mari-theme-important`, который
  имеет приоритет над собственными правилами приложения с `!important`.
- `mari-protected` удерживает на месте верхнюю панель, боковую панель чатов, боковую панель библиотеки и Ctrl+K.
  Тема может менять их оформление (цвета, шрифты, границы, радиус, тени), но не скрывать, перемещать, уменьшать или
  перекрывать их. При такой попытке тема выключается во вкладке, а пользователь узнает причину.
- Задержка начала перехода не может превышать одну секунду (`transition-delay` или второе значение времени
  в `transition`). Тема с более долгой задержкой отклоняется, чтобы ничего не появилось спустя долгое
  время после проверки экрана. Для анимаций допустима любая задержка.

Вернуться назад можно всегда: `?safe` в URL, **три нажатия Escape** или Ctrl+K > "Своя тема"
выключают тему. Новая тема спрашивает "Оставить эту тему?" и отменяется через 15 секунд.

## Цветовые токены

### Основные (определены в каждом визуальном стиле)

`--background`, `--foreground`, `--card`, `--card-foreground`, `--popover`, `--popover-foreground`,
`--primary`, `--primary-foreground`, `--secondary`, `--secondary-foreground`, `--muted`,
`--muted-foreground`, `--accent`, `--accent-foreground`, `--destructive`, `--destructive-foreground`,
`--border`, `--input`, `--ring`, `--radius`, `--sidebar`, `--sidebar-foreground`, `--sidebar-border`,
`--sidebar-accent`, `--sidebar-accent-foreground`.

Значения – полные цвета CSS (`#1b1530`, `rgb(…)`, `oklch(…)`). Тройки значений HSL без оболочки, например
`270 25% 8%` (принятые в shadcn), здесь **недопустимы**.

Задавайте светлую и темную схемы отдельно через `[data-theme="light"]` и `[data-theme="dark"]`.

### Новый интерфейс

| Токен | Назначение |
| ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `--ov-line` | Тонкие линии и границы панелей |
| `--ov-text`, `--ov-muted`, `--ov-dim` | Текст, второстепенный текст, бледный текст |
| `--ov-accent` | Акцентные участки (по умолчанию `--primary`) |
| `--ov-hover`, `--ov-active-bg` | Фон при наведении и нажатии |
| `--ov-mode-conversation`, `--ov-mode-roleplay`, `--ov-mode-game` | Цвета режимов чата в боковой панели чатов и редакторах |
| `--ov-serif` | Шрифт заголовков (следует `--mari-font-heading`) |
| `--mari-selected-tint` | Выбранные строки, плашки и переключатели. По умолчанию нейтральный (`--foreground`); задайте `var(--primary)`, чтобы выделение использовало акцентный цвет |
| `--mari-selected-bg`, `--mari-selected-ring` | Производные от оттенка (10% и 18%) |

### Токены темы, добавленные в v1.4

Как и токены v1.1, первая группа ничего не меняет, пока тема не задаст значения.

| Токен | Назначение |

## Изображения

Тема хранит изображения в `images` внутри файла темы, а ее CSS обращается к ним по имени:

```css
:root {
  --mari-app-backdrop: url("theme:night.webp");
}
[data-mari-part="home-widget"] {
  border-image: url("theme:frame.webp") 24 fill / 24px stretch;
}
```

- Изображения входят в лимит пакета 6 МиБ, а не в лимит CSS 256 КиБ, поэтому полноразмерная графика помещается.
- В редакторе откройте **Изображения и сведения для публикации** и нажмите **Добавить изображения**. PNG и JPEG
  при добавлении сохраняются как WebP (маленькие – без потерь, чтобы пиксельная графика и рамки из 9 частей оставались четкими;
  не более 2560 пикс. по длинной стороне). Нажмите имя изображения, чтобы вставить `url("theme:name")` в позиции курсора.
- При импорте темы происходит то же самое: изображения, записанные прямо в CSS как URL `data:`, переносятся
  в `images`, статичные PNG и JPEG становятся WebP, а предпросмотр перечисляет изображения с размерами
  (с флажком "Вместо этого оставить исходные файлы").
- Имена `theme:` также находят по имени элементы `backgrounds` темы, поэтому графику для галереи
  фонов чата можно использовать и в CSS, независимо от того, добавил ли пользователь ее в галерею.
- При применении темы каждое изображение получает короткий URL `blob:` того же источника: ничего
  не скачивается, а изображение, используемое в нескольких местах, декодируется один раз.
- GIF, APNG, анимированный WebP и SVG с `<animate>` считаются движущимися изображениями. Предпросмотр импорта
  сообщает об этом, а при уменьшении движения они показываются первым кадром.

## Фоновые изображения

Задайте `--mari-app-backdrop` на `:root`, чтобы разместить изображение позади приложения:

```css
:root {
  --mari-app-backdrop: url("theme:city.webp");
  --mari-app-backdrop-position: bottom center;
  --mari-app-backdrop-rendering: pixelated;
}
```

Оно отрисовывается один раз на отдельном неподвижном слое под всем приложением (`[data-mari-part="app-backdrop"]`, поэтому
украшения главной и светлая схема никогда его не скрывают) и видно за чатами: поверхности Roleplay,
Conversation и Game становятся прозрачными, а стандартный фон чата уступает ему место. Фон,
выбранный пользователем для чата, по-прежнему виден поверх него. Панели сохраняют `--card` и
`--sidebar`, поэтому сделайте их полупрозрачными, если хотите видеть изображение за ними, и используйте
`--mari-page-veil`, чтобы тонировать целые страницы. Чтобы дать страницам собственную панель, оформите
`[data-mari-part="page"]` (см. "Привязки"): он содержит каждую страницу библиотеки, редактор, настройки и документацию, поэтому
лорбуки получат такую же панель, как персонажи. Поверх фона каждая полная страница также стоит на почти непрозрачном слое вашего `--background` (`--mari-page-floor`, по умолчанию 94%), чтобы длинные списки и редакторы оставались читаемыми. Задайте `--mari-page-floor` другой цвет или `transparent`, чтобы показать больше картинки. Тема, которая оформляет `[data-mari-part="page"]` с `!important`, заменяет этот слой своей панелью.

| Токен | По умолчанию |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--mari-app-backdrop` | Одно изображение или градиент |
| `--mari-app-backdrop-size` | `cover` (для повторяющегося узора попробуйте `auto` или `64px`) |
| `--mari-app-backdrop-position` | `center` |
| `--mari-app-backdrop-repeat` | `no-repeat` |
| `--mari-app-backdrop-attachment` | `fixed` |
| `--mari-app-backdrop-rendering` | `auto` (`pixelated` для пиксельной графики) |
| `--mari-app-backdrop-layers` | Полное значение `background` с несколькими слоями, например `url(city.webp) bottom / 100% auto no-repeat, radial-gradient(#fff3 1px, transparent 1px) 0 0 / 12px 12px, #fbe3ef`. Оно важнее токенов одиночного изображения |

Собственные изображения – самая гибкая часть темы: фон, полоса верхней панели, рамки виджетов
главной и сообщений (`border-image` или `background` на любой привязке элемента), повторяющиеся узоры
и встроенные пиксельные шрифты помещаются внутрь файла темы, а предпросмотр импорта перечисляет их.
Настройка пользователя "Оформление > Специальные возможности > Интенсивность оформления темы" приглушает фон и атмосферный
слой, а высокая контрастность ограничивает их 25%; тема не может отменить ни то, ни другое.

## Атмосферный слой

`--mari-ambient` принимает полное значение `background` для слоя поверх чата и страниц, но
**под** верхней и обеими боковыми панелями: дождь, падающие листья, строки развертки, виньетка.

```css
:root {
  --mari-ambient: url("theme:leaves.webp") 0 0 / 512px repeat;
  --mari-ambient-opacity: 0.6;
  --mari-ambient-animation: leaves-fall 30s linear infinite;
}
@keyframes leaves-fall {
  to {
    background-position: 0 1024px;
  }
}
```

`--mari-ambient-blend` задает `mix-blend-mode`, а `[data-mari-part="ambient"]::before` и
`::after` свободны для еще двух слоев. Слой никогда не перехватывает нажатия, перестает двигаться при уменьшении
движения (его изображения становятся неподвижными кадрами) и должен оставаться в основном прозрачным: тема, чей атмосферный
слой скрывает чат, выключается. Используйте его вместо полноэкранного `body::after`, который
защита считает перекрытием приложения.

Слой замирает, когда его никто не видит: пока приложение находится в фоне (фокус у другой вкладки
или приложения), а на телефонах и планшетах – пока полная страница, например страница библиотеки, редактор или
настройки, закрывает чат. Бесконечные анимации в других частях темы тоже приостанавливаются в фоне. Они
продолжаются с места остановки, поэтому не привязывайте к их времени ничего важного.

Собственный фон чата – это `<img data-mari-part="backdrop">`. У стандартного (когда фон не выбран)
есть и `data-default-background="true"`, поэтому тема может заменить только его:

```css
img[data-mari-part="backdrop"][data-default-background] {
  opacity: 0 !important;
}
```

## Погода

Когда в истории есть погода (Настройки > Оформление > Эффекты > Динамические погодные эффекты, при включенном агенте World State),
приложение рисует поверх чата дождь, снег, туман, лепестки, звезды, солнце или луну. Тема может менять
их оформление токенами `--mari-weather-*` и подстраивать свои изображения под погоду.

Впервые пробуете? [Погода в вашей теме](theme-weather.md) объясняет всё по шагам, с изображениями.

```css
:root {
  --mari-weather-style: pixel; /* every drop and flake lands on a pixel grid */
  --mari-weather-pixel-size: 3px;
  --mari-weather-rain-color: #ffaacd;
  --mari-weather-petal-image: url("theme:petal-a.png") url("theme:petal-b.png");
  --mari-weather-petal-size: 3;
  --mari-weather-tint-strength: 0.4;
}
:root[data-theme="dark"] {
  --mari-weather-moon: none; /* the night backdrop already has a moon */
}
```

Приложение по-прежнему само выполняет всю отрисовку. Оно читает токены при загрузке темы, смене цветовой
схемы и редактировании темы, проверяет каждое значение и игнорирует всё, чего не
понимает. Поэтому дневная и ночная погода (или погода для отдельного чата) работает как любой другой токен.

| Токен | Значения |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--mari-weather-style` | `smooth` (по умолчанию) или `pixel`: слой рисуется в низком разрешении и четко увеличивается, а частицы становятся квадратными ячейками |
| `--mari-weather-pixel-size` | От 2 до 6 (пикс. на ячейку), по умолчанию 3 |
| `--mari-weather-<kind>-color` | Обычный цвет (`#hex`, название цвета, `rgb()`, `hsl()`), без градиентов и изображений |
| `--mari-weather-<kind>-image` | До 4 собственных изображений темы, `url("theme:a.png") url("theme:b.png")`; каждая частица выбирает одно. В плавном стиле листья, лепестки и пепел вращаются при падении |
| `--mari-weather-<kind>-size` | Множитель от 0,5 до 3. В пиксельном стиле изображение рисуется в собственном размере, умноженном на это значение, поэтому пиксельная графика сохраняет пиксели (пиксель изображения = размер x 1 пикс.) |
| `--mari-weather-<kind>-shape` | `round` или `square` (плавный стиль; квадраты для "цифрового снега" или искр) |
| `--mari-weather-amount` | От 0,25 до 1: тема может только уменьшить количество частиц, но не увеличить |
| `--mari-weather-speed` | Множитель от 0,5 до 1,5 |
| `--mari-weather-strength` | Множитель заметности частиц от 0,5 до 1,5 (слабый дождь над темным городом) |
| `--mari-weather-tint-strength` | Множитель стандартного оттенка неба от 0 до 1 (синий в дождь, темный ночью) |
| `--mari-weather-rain-length` | Множитель длины полос дождя от 0,5 до 3 |
| `--mari-weather-sun`, `-moon` | `none`, если на фоне уже нарисованы солнце или луна |
| `--mari-weather-lightning-color` | Цвет вспышки. Ее интенсивность и время сохраняют мягкие значения приложения, безопасные при эпилепсии |
| `--mari-weather-lightning-bolt` | `on`, `none` или 0,5–3 (ширина): разветвленная молния вдоль левого или правого края при каждой вспышке, затухающая вместе с ней |

Виды: `rain`, `snow`, `hail`, `fog`, `dust`, `leaf` (ветреная погода), `petal` (цветение), `ember`, `ash`,
`sand`, `firefly`, `star`, `aurora`, а также `sun` и `moon` (цвет, размер и одно изображение).

### Изображения, которые меняются с погодой

Пока показана погода чата, `<html>` содержит два слова из фиксированных списков (никогда не текст самой истории):

| Атрибут | Значения |
| ------------------- | --------------------------------------------------------------------------------------------------------------- |
| `data-mari-weather` | `clear`, `cloudy`, `rain`, `storm`, `snow`, `hail`, `fog`, `sand`, `ash`, `embers`, `wind`, `blossom`, `aurora` |
| `data-mari-sky` | `dawn`, `day`, `dusk`, `night` |
| `data-mari-shelter` | `indoors` или `outdoors` (отсутствует, если приложение не может определить) |

В помещении приложение не рисует частицы, полосы тумана, солнце, луну или звезды, только оттенок и вспышку
молнии, поэтому погодные токены темы проявляются лишь снаружи. Атрибуты задаются независимо от настройки уменьшения фоновых анимаций (смена фона не движется) и
удаляются, если у чата нет погоды или пользователь ее выключил. Используйте их, чтобы сделать солнечный
фон серым в дождь или убрать собственный атмосферный слой, чтобы он не дублировал погоду:

```css
:root[data-mari-weather="rain"],
:root[data-mari-weather="storm"] {
  --mari-app-backdrop: url("theme:street-overcast.webp");
}
:root[data-mari-weather]:not([data-mari-weather="clear"], [data-mari-weather="cloudy"]) {
  --mari-ambient: none;
}
```

### Что остается за пользователем

- Тема не может включать или выключать погоду; это решает переключатель пользователя.
- Настройка "Уменьшить фоновые анимации и эффекты" (или настройка уменьшения движения на устройстве) полностью отключает отрисовку погоды.
- Настройка "Упрощенная отрисовка" убирает оттенок, свечение и закатную заливку и оставляет 60% частиц.
- Интенсивность оформления темы приглушает ее погоду, как и фон, а высокая контрастность ограничивает ее 25%.
- На любом устройстве отрисовка погоды останавливается, пока панель, редактор или Mari закрывают чат.

Petal OS (пиксельная погода и свои лепестки), NEON//GRID (дождь из голубых полос) и Lantern Path (рисованные
листья, фоны, сереющие в непогоду) – готовые примеры: нажмите **Клонировать и изменить** у одного из них, чтобы прочитать его CSS.

## Акцентные эффекты

Пульсация акцента и режим RGB анимируют несколько акцентных участков нового интерфейса ("+ Новый", основные кнопки,
плитку аватара ассистента) через CSS-фильтр. Ничего не переписывается на каждом кадре. Тема может:

- включить пульсацию акцента для пользователей через `:root { --marinara-theme-accent-pulse: enabled; }`;
- добавить свои элементы через `animation: var(--mari-accent-fx-animation);`.

Оба эффекта останавливаются при `prefers-reduced-motion` и настройке приложения "Уменьшить фоновые анимации и эффекты".

### Слоты

Они появляются, только когда активная тема их запрашивает, поэтому в стандартной странице нет лишних элементов.

- **Рамка фокуса.** `--mari-focus-frame` принимает полное значение `border-image`, например
  `url("theme:frame.png") 24 fill / 24px / 6px stretch`, и рисует его вокруг того, на чем сосредоточено
  внимание читателя: новейшего ответа, Ctrl+K, открытого диалога и недавних чатов на главной. Добавьте
  `data-mari-focus-surface` к другому элементу (в шаблоне сообщения), чтобы обрамить и его.
  Начиная с v1.5 рамка выступает за свою поверхность только через `--mari-focus-frame-outset` (не более
  2rem) и вовсе не выступает при наличии `fill`, чтобы не закрашивать чат; выступ, записанный
  внутри `--mari-focus-frame`, игнорируется. Рамка – это `border-image`: сокращенное свойство `border` дальше
  в CSS для того же элемента сбрасывает ее, поэтому вместо него задавайте `border-color`, `border-width` и `border-style`
  в этом месте.
- **Заголовки окон.** Значение `--mari-window-title` (любое, например `on`) добавляет строку заголовка
  вверху каждого сообщения, виджета главной и поля сообщения: `[data-mari-part="window-title"]` с
  `data-window` (`message`, `home-widget`, `composer`, а с v1.5 – `narration`, `omnibar`,
  `window` и `dialog`), содержащую `window-title-text` (говорящего,
  заголовок виджета или "Сообщение") и пустой `window-buttons` для украшений `_ [] X`.
- **Предпросмотр строк чатов.** Значение `--mari-chat-row-preview` (любое, например `on`) добавляет последнюю
  строку каждого чата под его именем в списке чатов: `[data-mari-part="chat-row-preview"]` с
  `data-role` (`user`, `assistant`, `narrator`…), начинающуюся с `[data-mari-part="chat-row-preview-who"]`
  ("Вы:" для ваших строк или имя говорящего в групповом чате). Она уступает место текущему
  статусу ("печатает…", "Неотправленный черновик"), поэтому двух строк одновременно нет. Без токена строка не запрашивается
  и не рисуется.
- **Атмосферный слой за карточками.** `--mari-ambient-placement: behind-cards` перемещает атмосферный слой под
  сообщения, виджеты главной и панели (всё еще поверх фона), а не над чатом.
  `--mari-ambient-mask` (полное значение `mask`) задает область его видимости, а
  `--mari-ambient-mask: var(--mari-gutter-mask)` оставляет середину окна свободной, чтобы дождь падал
  в боковых полях, а не поверх текста. `--mari-gutter-clear` задает половину ширины свободной области (26rem).

### Данные сообщения

Каждое сообщение содержит автора, свой номер и длительность создания: в атрибутах для селекторов
и `attr()`, а также в CSS-переменных для `content:` и `counter()`:

| Атрибут | Переменная | Значение |
| --------------------- | ------------------ | ------------------------------------------------------------------------------------------ |
| `data-character-id` | | Идентификатор персонажа (отсутствует в ваших сообщениях) |
| `data-character-name` | `--mari-msg-char` | Отображаемое имя (`--mari-msg-char` – строка в кавычках) |
| `data-character` | | Имя в нижнем регистре с заменой пробелов на `-`, для селекторов: `[data-character="captain-faye"]` |
| `data-message-index` | `--mari-msg-index` | Номер сообщения из настройки "Показывать номера сообщений" |
| `data-gen-ms` | `--mari-msg-gen` | Время генерации в мс (`--mari-msg-gen` – строка вроде `"3.2s"`) |

```css

  counter-reset: msg var(--mari-msg-index);
  content: "#" counter(msg) " · " var(--mari-msg-gen, "");
}
```

### Шаблон сообщения (HTML)

Когда CSS недостаточно, например для блока статуса с именем говорящего и номером сообщения,
файл темы может содержать небольшой HTML-шаблон для каждой роли. Он заполняется для каждого сообщения и показывается
в блоке в конце сообщения, `[data-mari-part="message-extra"]`, который ваш CSS оформляет и
размещает:

```json
"templates": {
  "assistant": "<div class=\"status\"><b>{{char}}</b> · entry #{{index}} · {{gen}}</div>",
  "user": "<div class=\"status\">> {{char}} @ {{time}}</div>"
}
```

Ключи: `message` (все роли), `assistant`, `user`, `narrator` (собственный шаблон роли важнее
`message`). Поля: `{{char}}`, `{{role}}`, `{{index}}`, `{{gen}}`, `{{time}}`, `{{date}}`; неизвестные
поля остаются пустыми. Каждый шаблон – не более 4 000 символов. Marinara сохраняет текст и теги разметки
(`div`, `span`, `p`, `b`, `i`, `ul`, `table`, `details`, `progress`, …) с атрибутами `class`, `title`,
`role` и `data-*`, а скрипты, стили, встроенный `style`, ссылки, изображения, формы и
атрибуты событий удаляет. Шаблон с текстом, который просит ключи или пароли, отбрасывается.

Пользователь должен разрешить HTML: тему с шаблоном можно установить, только когда включена настройка **Настройки →
Оформление → CSS-темы → Разрешить темы с HTML** (по умолчанию выключена). Предпросмотр импорта предупреждает
об этом, а при выключенной настройке установленная тема отображается без своего HTML.

## Оформление отдельных чатов

Настройки чата > Тема задают отдельную тему для одного чата ("Оформление по умолчанию" выключает собственные темы
для этого чата). В чате ровно с одним персонажем выбор можно сделать настройкой этого персонажа по умолчанию
для других чатов один на один; групповые чаты и игровые отряды никогда не заимствуют настройку одного участника.
Раздел темы сообщает, откуда взято текущее оформление: из чата, персонажа или приложения.
Настройки, библиотека, редакторы и документация всегда используют тему приложения, а `data-chat-id` и
`data-chat-tags` находятся на `<html>`, только пока показан сам чат.

Теги – переносимый способ оформлять отдельные истории внутри одной темы:
`:root[data-chat-tags~="noir"] { --primary: #c9a227; }`. Добавьте теги в разделе Настройки чата > Название чата
("+ Добавить тег"), кнопкой тегов в строке чата (или через "Теги" в меню долгого нажатия на сенсорном экране).
В атрибуте теги приводятся к нижнему регистру с заменой пробелов на `-`, поэтому "Noir Mystery" соответствует `noir-mystery`.

Любая заданная переменная `--mari-chat-*` (например, `--mari-chat-bg`, `--mari-chat-text`,
`--mari-chat-radius`, `--mari-chat-font-family`) сама включает соответствующее оформление поверхности
чата; пользователю не нужны переключатели "Применять … пресета", чтобы увидеть цвета чата из темы.

## День и ночь

Настройки > Оформление > Цветовая схема позволяют следовать системе или времени суток (по умолчанию светлая с 07:00,
темная с 19:00, оба значения настраиваются). В любом случае меняется только `data-theme` на `<html>`,
поэтому тема получает дневной и ночной вид, оформляя оба варианта:

```css
:root[data-theme="light"] {
  --mari-app-backdrop: url("theme:day.webp");
}
:root[data-theme="dark"] {
  --mari-app-backdrop: url("theme:night.webp");
}
```

Схема определяется на каждом устройстве по его часам (не синхронизируется), поэтому телефон и компьютер
в разных местах показывают каждый свою правильную половину. Файл темы может предложить сам режим переключения:
`"settings": { "colorScheme": "time", "dayStart": "07:00", "nightStart": "19:00" }` (или
`"system"`). Предпросмотр импорта предлагает его, как любую другую настройку.

```json
{
  "license": "CC BY 4.0",
  "labels": ["High legibility", "No motion"],
  "credits": [{ "what": "Backdrops", "by": "Jane Doe", "license": "CC BY 4.0", "url": "https://example.com" }],
  "fonts": [{ "family": "My Display", "src": "…", "license": "OFL-1.1", "credit": "Fraunces by Undercase Type" }]
}
```

`labels` – до четырех коротких тегов (по 40 символов), показанных под названием темы. Шрифт или
запись об авторе с лицензией `OFL-1.1` ссылается на текст SIL Open Font License, поставляемый с приложением. Изображения шире
1920 пикс. (или длиннее 2560 пикс. по длинной стороне) уменьшаются при импорте темы.

Обязательны только `kind`, `name` и `css`. `templates` описан в разделе "Шаблон сообщения". Ключи `settings`: `colorScheme` (`dark`, `light`, `time` или `system`), `dayStart`, `nightStart`, `visualStyle`, `accent`,
`accentLight`, `background`, `backgroundLight`, `fontFamily`, `accentPulse`, `fontSize` (размер
отображения в пикселях: 12, 14, 16, 17, 19, 22, 26, 30 или 34) и `reduceMotion` (true или false). При импорте сначала показывается
предпросмотр с отмеченными предложенными настройками, кроме визуального стиля, пульсации акцента, размера отображения и
уменьшения движения, которые пользователь отмечает по желанию; также пользователь выбирает, добавлять ли
фоны в свою галерею. Изображения меньше 4 КиБ остаются встроенными и показываются одной плашкой "маленькие значки".
Шрифты загружаются вместе с темой (как правила `@font-face`) и удаляются вместе с ней. При импорте темы с тем же
названием, что у установленной, предлагается обновление, причем оно не добавляет тот же фон в
галерею повторно. Лимит CSS – 256 КиБ текста CSS; изображения, миниатюра, шрифты и фоны
вместе получают 6 МиБ. Не поместившееся изображение пропускается отдельно, с указанием размера, а остальная
тема всё равно устанавливается. Обычные файлы `.css`, `{ "name", "css" }` и старый формат экспорта
`marinara.theme-folder` по-прежнему импортируются.

## Как сохранить быстродействие темы

На телефонах и планшетах, особенно iPad в Safari, медленный CSS заметен при каждом нажатии. Большинство тем работает нормально;
вот приемы, которые замедляли темы при проверке:

- **`:has()` на родителе, который затем оформляет дочерние элементы**, например `.panel:has(> .row) > *` или
  `body:has(.open) .chat *`. Браузер заново проверяет всю страницу при каждой введенной букве и
  каждом слове потокового ответа. Поместите `:has()` на оформляемый элемент (`.row:has(> img)`) или используйте
  привязку `data-mari-part`.
- **`backdrop-filter` на многих элементах сразу**, например каждом сообщении или строке чата. Одна-две
  матовые панели допустимы; размытие на каждой из сотни строк – нет. Используйте полупрозрачный цвет.
- **Анимация геометрии** (`width`, `height`, `top`, `margin`) или больших `box-shadow`. Анимируйте `opacity`
  и `transform` либо `background-position` атмосферного слоя.

**Настройки → Дополнительно → Устранение неполадок → Показывать время нажатий** показывает длительность каждого нажатия на этом
устройстве с темой и без нее. Сравните результаты, чтобы найти медленное правило.

## Специальные возможности

Настройки > Оформление > Специальные возможности применяют заданные пользователем межстрочный и межбуквенный интервалы, контуры фокуса,
высокую контрастность, цвета для нарушений цветового зрения и минимум 12 пикс. для текста сообщений. Значения
записываются в слой `mari-protected` как литералы на каждом элементе (lib/accessibility-css.ts), поэтому
тема не может их отменить, даже переопределив переменные. Пока параметр выключен, тема может задать:

| Токен | Назначение |
| ------------------------------------------------------ | ---------------------------------------------------------------- |
| `--mari-focus-ring-color` | Обычный контур фокуса приложения (по умолчанию `--primary`) |
| `--mari-cvd-good`, `--mari-cvd-warn`, `--mari-cvd-bad` | Цвета статусов и шкал, если вы хотите свою пару синего и оранжевого |

Для изображений еще три настройки важнее темы:

- **Интенсивность оформления темы** (0–100%) приглушает фон и атмосферный слой.
- **Высокая контрастность** также делает поверхности непрозрачными в собственных цветах схемы (`--background`, `--card`,
  `--popover`, `--sidebar`, `--secondary`, `--muted`, `--mari-rp-bubble-bg`, вуаль страницы, заливка
  главной, ее виджеты и подложка верхней панели) и ограничивает графику темы 25%, чтобы текст никогда не оказывался на
  пастельном изображении. Цвета, записанные темой как литералы на собственных селекторах, не меняются, поэтому
  предпочитайте токены.
- **Уменьшение движения** показывает движущиеся изображения первым кадром и останавливает атмосферный слой.
  Принудительные цвета (высокая контрастность Windows) скрывают графику и рамки `border-image`.

Используйте указанные выше токены статусов и шкал вместо фиксированных зеленого и красного, и переключатель цветов
для нарушений цветового зрения повлияет и на вашу тему. Ссылки пропуска (`.mari-skip-link`) доступны при любой теме.
Предпросмотр импорта сообщает пользователю, если тема пытается изменить что-либо из этого.

## Безопасность

- Верхнюю панель (включая ее автоматическое скрытие в полноэкранном режиме), боковую панель чатов и строки чатов,
  боковую панель библиотеки, Ctrl+K и поле сообщения можно оформлять, но нельзя скрывать, перемещать, перекрывать, делать прозрачными,
  убирать фильтрами или лишать возможности нажатия. Защита измеряет их с темой и без нее после
  загрузки темы, через 2,5 и 10 секунд, при открытии чата, открытии панели, смене цветовой схемы,
  изменении размера и начале или завершении собственной анимации темы и выключает
  тему во вкладке, если та нарушает работу одного из элементов.
- Изображения учитываются (защита v3). Всё, что нарисовано поверх вкладки, значка, строки чата или поля
  сообщения, обнаруживается в центре элемента управления, независимо от `pointer-events: none` и размера; слой,
  скрывающий его (цвет, градиент или изображение, чьи пиксели в этом месте в основном непрозрачны), считается
  перекрытием. Как и выступ `border-image`, заходящий на элемент управления, и маска-изображение `mask` на нем.
  Внутри верхней панели каждый `::before` и `::after` находится под надписями и значками, а
  маски, `list-style-image` и `border-image-outset` не применяются. Фон и атмосферный
  слой никогда не учитываются: они изначально находятся под панелями.
- Защита v4 (этап 4). Контрастность учитывает слои за текстом в порядке отрисовки (заливку `border-image`,
  затем каждый фоновый слой сверху вниз, затем цвет), взвешивает каждый по доле текста, которую он
  действительно закрывает (размер, положение и повтор), и берет образцы изображения только под текстом.
  Тонкая линия или маленькое украшение в углу больше не учитываются, а темная вуаль над светлой страницей
  считается темной. Верхняя панель и поле сообщения проверяются строже: их текст должен сохранять
  контрастность 3:1 в худшей точке, если она была такой до этого. Изображение на собственном `::before` или
  `::after` элемента управления, закрывающее его, считается перекрытием в верхней панели, строках чатов и
  поле сообщения. Изображение с `position: fixed` на псевдоэлементе вызывает предупреждение редактора; используйте
  `position: absolute`, `--mari-ambient` или `--mari-app-backdrop`. Если изображение верхней панели
  обнаружено на псевдоэлементе, вкладки и значки получают подложки, как при `--mari-top-bar-bg`.
- Контрастность поверх изображения: когда за текстом находится изображение, защита считывает его цвета,
  а не пропускает проверку.
- Текст чата (v1.5): защита проверяет несколько последних видимых строк чата и выключает тему,
  если та закрашивает половину из них (перекрытие псевдоэлементом, непрозрачный атмосферный слой за карточками или
  рамка фокуса, выступающая поверх текста). Строка, которую собственная разметка темы уводит за экран,
  не учитывается, как и строка имени, закрепленная темой поверх ответа.
- Текст, добавляемый темой через `content:`, показывается в предпросмотре импорта.
- Правила текста темы (аудит безопасности, ноябрь 2026). Каждая строка, которую тема может вывести, проверяется до
  применения темы независимо от источника (файл, редактор, Mari, резервная копия, выбор для отдельного чата):
  строки `content:` и `quotes`, пользовательские свойства (поэтому `content: var(--x)` тоже учитывается),
  символы `@counter-style`, подсказка в поле сообщения, шаблоны сообщений (слова и `title`) и
  текст внутри SVG-изображений. Отклоняется текст, который просит ключи, пароли, вход в систему или сведения об аккаунте,
  выдает себя за приложение ("hacked", "RCE", "security alert", "verified by Marinara", "call
  support"), содержит номер телефона или веб-адрес либо превышает 80 букв и цифр в одном
  объявлении: тему нельзя установить, а установленная не применяется. Перед проверкой похожие
  буквы, диакритика, символы нулевой ширины, пробелы и написание 1337 нормализуются. Строки в
  селекторах, `font-family` и названиях областей сетки не учитываются. Название темы, автор, описание
  и сведения об авторах тоже не могут просить секретные данные или заявлять об официальном статусе (веб-адреса там допустимы).
- URL: помимо очистки текста (список разрешенных адресов url(), запрет `@import`, только шрифты data:),
  браузер разбирает таблицу стилей перед применением, и любой адрес, кроме собственных
  изображений темы, встроенных изображений и шрифтов data:, `#fragments` и `about:invalid`, приводит к отклонению
  темы. `src()` следует правилам url(), а незакрытый в конце `image-set(` отбрасывается.
- Предлагаемые цвета в файле темы (`settings.accent`, `background` и их светлые пары) должны быть
  обычными цветами или градиентами: без `url()`, `image-set()` и чего-либо, выходящего за границы значения.
- SVG-изображения перед использованием пересобираются по списку разрешенных элементов: без `<script>`, `<foreignObject>`, `<a>`,
  атрибутов событий, внешних ссылок, `<?xml-stylesheet?>` и сущностей DOCTYPE, а их CSS
  очищается так же, как CSS темы. Растровые изображения, которые после декодирования превышают 8192 пикс. по стороне или 40 мегапикселей,
  отклоняются.
- Погодные токены читаются по списку разрешенных значений: известные имена токенов, числа в пределах своих диапазонов,
  слова из фиксированных списков и обычные цвета (без `url()`, градиентов и функций, кроме цветовых).
  Погодные изображения должны принадлежать самой теме (адреса того же источника, созданные приложением для
  них после пересборки SVG и ограничения размера); любой другой адрес игнорируется. Ничего, написанного темой,
  не исполняется, а вспышка молнии сохраняет интенсивность и время приложения.
- Шаблоны сообщений не могут использовать роли, создающие диалог, меню или объявление, а также собственные
  атрибуты приложения `data-` и имена классов `mari-`/`ov-`.
- Проба темы ("Оставить эту тему?") происходит только в текущей вкладке: другие устройства получают ее лишь после
  сохранения кнопкой "Оставить тему". Без ответа оформление возвращается; наведение или фокус на панели приостанавливают отсчет. Три нажатия Escape
  выключают собственные темы во вкладке; Escape, закрывающий Ctrl+K, меню или диалог,
  показанный приложением, не учитывается.
