# Просмотр промпта

Просмотр промпта располагает рядом пресет, лорбуки, персонажей и персону и показывает собранный промпт в порядке отправки. Нажмите часть, чтобы редактировать её на месте. Правки сохраняются в настоящем пресете, лорбуке, карточке или персоне и сразу видны в других редакторах.

Он появился как расширение AIO Prompt Viewer and Editor от kolache, а теперь входит в новый интерфейс.

<a id="opening-it"></a>
## Как открыть

- **Компьютер:** кнопка просмотра промпта (🥞) на верхней панели сразу после Search.
- **Телефон или планшет:** нажмите счётчик вкладок, чтобы открыть All Tabs, затем кнопку просмотра (🥞) рядом с **+**.
- **Откуда угодно:** откройте Search и введите `prompt viewer`.

Открывается в своей вкладке. При переключении сохраняются выбор и несохранённые правки; закрытие с правками требует подтверждения.

<a id="the-three-columns"></a>
## Три столбца

| Столбец | Назначение |
| --- | --- |
| **Sources** | Выберите пресет, лорбуки, персонажа (нескольких для группы) и персону. Отметьте записи или папки, чтобы включить их в промпт. **+** создаёт элемент, карандаш открывает настройки. |
| **Промпт** | Выбор в порядке сборки: разделы пресета, записи на своих позициях и глубинах, персонаж и персона в маркерах. **Validate** ищет незакрытые XML-теги и повреждённые `{{macros}}`. Перетаскивайте разделы для смены порядка. |
| **Editor** | Поля выбранного элемента. **Сохранить** сохраняет, **Откатить** отменяет правку. |

На телефоне и вертикальном планшете столбцы переключаются через **Sources / Промпт / Editor**. Нажатие блока открывает Editor.

<a id="inspect-summaries-and-settings"></a>
## Inspect, Summaries и Settings

Верхние кнопки открывают эти виды внутри страницы; **Назад** возвращает к столбцам.

- **Осмотреть** показывает промпт как при отправке модели. С открытым чатом **Include history** запрашивает точный промпт (макросы раскрыты, история обрезана по размеру); **Omit history** показывает структуру с заполнителем чата. Копируйте как текст или список сообщений JSON.
- **Summaries** экспортирует все сводки чатов библиотеки в Markdown или JSON, включая выключенные записи. Открытый чат не нужен.
- **Настройки** задаёт работу Inspect с историей, число ходов чата без подключения, значки столбца Prompt и цвета Inspect.

<a id="what-it-does-not-show"></a>
## Что не отображается

- В столбце Prompt нет агентов; Inspect включает их, поскольку запрашивает Engine.
- История, сводки, примеры диалогов и данные агентов в Prompt — заполнители: содержимое существует только при работе чата.
- Поведение группы в ходе (кто отвечает, «Respond only as…») описывается, но не собирается, пока не открыт чат.
