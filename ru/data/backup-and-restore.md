# Резервное копирование и восстановление Marinara

Сохраните копию данных Marinara Engine, чтобы потом вернуть ее обратно. Это пригодится перед обновлением, переездом на новое устройство или [сбросом данных](clearing-data.md).

## Какой способ выбрать

| Вариант | Что создает | Для чего нужен |
| --- | --- | --- |
| **Download Backup** | Файл `.zip` со всеми вашими данными и файлами. | Одна полная копия всего. |
| **Export Profile** | Файл поменьше с данными вашего аккаунта (персонажи, чаты, лорбуки и другое). | Копия без секретов или файлы для других инструментов. |

`.zip` – это один файл, в котором лежит много файлов. Оба варианта и восстановление находятся в разделе **Настройки → Данные → Резервное копирование и восстановление**.

**Перед началом.** На компьютере, где запущена Marinara, эти инструменты работают сразу. С телефона, планшета или любого другого устройства сначала задайте на сервере секрет администратора и введите то же значение в **Настройки → Дополнительно → Безопасность**. Секрет администратора – это пароль в файле `.env` сервера, параметр `ADMIN_SECRET`. См. раздел "Privileged APIs (ADMIN_SECRET)" в [справочнике настроек сервера](../CONFIGURATION.md) и руководство [Удаленный доступ](../REMOTE_ACCESS.md).

## Скачивание резервной копии

1. Откройте **Настройки → Данные**.
2. В разделе **Резервное копирование и восстановление** нажмите **Download Backup**. Пока идет работа, на кнопке видно **Creating backup…**.
3. Сохраните файл, когда браузер предложит, или найдите его в папке загрузок.

В файле `.zip` лежат:

- ваши сохраненные текстовые данные (персонажи, чаты, лорбуки, пресеты, подключения, настройки);
- загруженные и созданные вами файлы: аватары, спрайты, фоны, изображения галереи, шрифты, свои эмодзи и стикеры, а также свой звук уведомления;
- файл `.encryption-key`, если он есть;
- заметка `RESTORE.txt` о том, как восстановить файлы вручную (см. [Восстановление вручную](#restore-by-hand)).

Названия папок см. в руководстве [Где Marinara хранит ваши данные](where-data-is-stored.md).

> **Предупреждение:** в резервной копии лежат ваши сохраненные ключи API и файл `.encryption-key`, который их открывает. Никому не передавайте ее. Храните ее в закрытом месте.

На Android папка данных приложения недоступна, поэтому **Download Backup** – единственный способ вынести копию с устройства.

Если не получилось: при сообщении "Backup preparation timed out after one hour." повторите попытку. Если с другого устройства скачать не удается, проверьте секрет администратора (см. выше).

## Автоматические резервные копии

Marinara может сама делать полную копию по расписанию на компьютере, где она запущена.

1. Откройте **Настройки → Данные → Резервное копирование и восстановление**.
2. Включите **Automatic backups**.
3. Выберите **Daily**, **Weekly** или **Monthly**.
4. Задайте **Automatic backups kept** от 1 до 9999.

Первую копию Marinara создает вскоре после включения. После каждого запуска она хранит заданное число самых новых копий и удаляет более старые автоматические. Копии, которые вы сделали кнопкой **Download Backup**, она никогда не удаляет.

Автоматические копии лежат в папке `backups/` внутри папки данных. Самая новая называется `marinara-automatic-backup.zip`. У более старых в имени есть дата и время. Формат тот же, что у **Download Backup**.

Каждому запуску нужно свободное место еще для одного полного архива, потому что старый архив остается, пока не будет готов новый. Если места не хватает, Marinara пропускает запуск и показывает причину рядом с настройкой. Когда место освободится, она повторит попытку.

> **Совет:** держите вторую копию вне папки данных. Если диск выйдет из строя или приложение будет стерто, автоматические копии тоже пропадут.

## Экспорт профиля

1. Откройте **Настройки → Данные → Резервное копирование и восстановление**.
2. Нажмите **Export Profile**. Откроется окно с тем же названием.
3. Выберите формат.
4. Браузер скачает файл.

- **Marinara Native** сохраняет ваших персонажей, персоны, чаты, лорбуки, пресеты, агентов, темы и код Personal Extension, а также медиафайлы. Ключи API, ссылки вебхуков и некоторые настройки чатов не восстанавливаются (см. [Снова введите ключи](#enter-your-keys-again)). Такой файл можно восстановить в Marinara.
- **Compatible JSON** создает `.zip` из простых файлов персонажей, персон и лорбуков для других инструментов. В Marinara его восстановить нельзя.

Профиль в родном формате скачивается как `marinara-profile.json`. Если он слишком большой, Marinara предлагает вместо него файл ZIP. Нажмите **Export ZIP**, чтобы скачать `marinara-profile.zip`.

Профиль в родном формате сохраняет скрипты регулярных выражений, их папки и настройку паузы каждой папки. Как поделиться отдельными скриптами в формате JSON, см. [Скрипты регулярных выражений](../extending/regex-scripts.md#import-and-replace-scripts).

Профиль в родном формате хранит код Personal Extension, но не то, включено ли расширение и одобрено ли оно. Каждое восстановленное расширение приходит выключенным. Проверьте его заново в **Библиотека → Расширения**.

## Восстановление через Import Profile

**Import Profile** загружает файл профиля или архив из **Download Backup** (`.zip`).

1. Откройте **Настройки → Данные → Резервное копирование и восстановление**.
2. Под кнопкой оставьте **Тег импорта** и **Тег источника** отмеченными, чтобы добавить импортируемым персонажам, персонам, лорбукам, пресетам и чатам теги **Imported** и **Backup**. Снимите отметки, чтобы восстановить всё в исходном виде.
3. Нажмите **Импортировать профиль (JSON/ZIP)**.
4. Выберите `marinara-profile.json`, `marinara-profile.zip` или `.zip` резервной копии. Пока идет проверка, на кнопке видно **Scanning Profile...**.
5. Прочитайте окно **Импортировать профиль**. В нем перечислено то, что нашла Marinara. Элементы, которые уже есть в Marinara, заменяются версиями из файла, если вы не выбрали [добавление только недостающего](#only-add-whats-missing).
6. Нажмите **Импортировать** или **Отмена**, чтобы остановиться. На кнопке видно **Импорт профиля...**. Сначала Marinara сохраняет страховочную копию ваших данных, затем появляется полоса прогресса. Когда импорт закончится, сообщение сообщит, что профиль импортирован.

Если не получилось:

- Если вы не открыли Marinara по адресу `localhost`, `127.0.0.1` или `[::1]`, для импорта профиля нужен HTTPS. Ошибка выглядит так: "Profile import requires HTTPS outside local development." Откройте Marinara по адресу HTTPS.
- Если в `.zip` не хватает части медиафайлов, импорт все равно доходит до конца. Предупреждение перечисляет то, чего нет, а Marinara импортирует остальное.
- Если на диске не хватает места для страховочной копии, ничего не импортируется. Ошибка начинается с "Nothing was imported, because a safety copy could not be saved first." Освободите примерно столько места, сколько занимает полная резервная копия, затем повторите импорт.

Если вы дважды импортируете один и тот же профиль, Marinara обновляет ваши элементы и не создает копии. Профили из куда более старых версий могут создать дубликаты.

### Добавление только недостающего

Чтобы вернуть удаленное, не потеряв последующие изменения, включите **Keep my current versions, only add what's missing** (сохранить текущие версии и добавить только недостающее) над кнопкой **Импортировать профиль (JSON/ZIP)**, затем импортируйте, как описано выше. Все элементы и файлы, которые уже есть в Marinara, остаются как есть, и добавляется только то, чего в Marinara нет. Это включает всё, что вы удалили после сохранения файла, например отдельные сообщения или записи лорбука, а не только нужный вам элемент. Долговременная память считается одним элементом: если в Marinara она уже есть, память из файла не добавляется.

Ничего не заменяется, поэтому Marinara не сохраняет страховочную копию, а **Undo Last Import** (отменить последний импорт) по-прежнему отменяет предшествующий импорт.

Профили из куда более старых версий этого не поддерживают: они всегда добавляют свои элементы рядом с вашими, о чем и сообщает окно **Импортировать профиль**.

### Отмена импорта

Перед каждым импортом с заменой элементов Marinara сохраняет полную копию ваших данных в папке `backups/` внутри папки данных. Имя файла начинается с `marinara-before-import-`, за которым следуют дата и время. После завершения импорта копия от предыдущего импорта удаляется, поэтому остается только последняя.

1. Откройте **Настройки → Данные → Резервное копирование и восстановление**.
2. Нажмите **Undo Last Import**. Строка под кнопкой показывает, когда была сохранена страховочная копия.
3. Нажмите **Undo Last Import** в диалоговом окне для подтверждения.

Отмена возвращает ваши версии элементов и файлов, замененных последним импортом. Если вы изменили один из этих элементов после импорта, это изменение будет потеряно. Всё остальное остается как есть, включая элементы, добавленные при импорте. Отменить импорт можно один раз, после чего страховочная копия удаляется.

Отмена не включает обратно то, что импорт выключил для безопасности. Включите вручную:

- вашу активную тему;
- личные расширения (проверьте их повторно в **Настройки → Дополнения**);
- собственные инструменты, запускающие скрипт или вебхук;
- воспоминания Professor Mari.

Если при импорте был очищен ключ API подключения, введите его снова (см. [Повторный ввод ключей](#enter-your-keys-again)). Снова назначьте подключение используемым по умолчанию или резервным, если оно было таким.

Ветки чатов, замененные при импорте, остаются отвязанными от чата, из которого были созданы. Импорт уже удалил эту связь, и отмена не может ее вернуть.

Профили из куда более старых версий только добавляют элементы, поэтому Marinara не сохраняет для них страховочную копию и отменять нечего.

Страховочная копия занимает столько же места, сколько полная резервная копия. Чтобы освободить это место без отмены импорта, нажмите **Delete Safety Copy** (удалить страховочную копию) в **Настройки → Данные → Резервное копирование и восстановление**, затем подтвердите. Ваши данные останутся как есть, но отменить этот импорт уже нельзя будет. Если импорт был прерван, кнопка **Delete Safety Copy** может появиться отдельно; тогда копию нельзя использовать для отмены, но ее по-прежнему можно удалить.

## Снова введите ключи

**Import Profile** никогда не возвращает ключи API и ссылки вебхуков, даже из архива **Download Backup** `.zip`. Ключ API – это секретный код, который вам выдает сервис. В файле профиля и в профиле внутри резервной копии эти значения пусты. Поэтому после импорта на новом компьютере введите их снова:

1. Откройте **Библиотека → Подключения**.
2. Откройте каждый используемый аккаунт, введите его ключ API и сохраните. См. [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md).
3. Введите ссылку вебхука в каждом своем инструменте, где она нужна.

Некоторые настройки с адресами или ключами (Discord, DeepL, Intiface) тоже не возвращаются. Введите их снова в **Chat Settings** (настройки чата) каждого чата.

Импорт никогда не стирает ключи, которые уже есть в этой же установке.

## Перенос на новый компьютер

1. Установите Marinara на новом компьютере и запустите ее. См. [Установка](../INSTALLATION.md).
2. Откройте **Настройки → Данные → Резервное копирование и восстановление** и нажмите **Import Profile (JSON/ZIP)**.
3. Выберите архив **Download Backup** `.zip` или файл профиля, затем нажмите **Import**.
4. Введите ключи API снова, как описано выше.

Ключ из резервной копии помогает, только если вы копируете всю папку данных вручную, как ниже.

## Восстановление вручную

Используйте это, только если **Import Profile** применить нельзя. Внутри `.zip` лежит одна папка, например `marinara-backup-...`, с заметкой `RESTORE.txt`.

1. Остановите Marinara.
2. Распакуйте резервную копию.
3. Скопируйте папки и файл `.encryption-key` из распакованной папки в вашу папку данных. См. [Где Marinara хранит ваши данные](where-data-is-stored.md).
4. Запустите Marinara.

Храните файл `.encryption-key` рядом с папкой `storage`, иначе сохраненные ключи API нельзя будет прочитать.

Список **Existing backups** в разделе **Резервное копирование и восстановление** обычно пуст. Он вам не нужен.
