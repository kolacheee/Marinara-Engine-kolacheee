# कीबोर्ड शॉर्टकट और टच जेस्चर

Marinara कंप्यूटर पर कुंजियों और फ़ोन या टैबलेट पर स्वाइप व खींचने से चलता है। यहाँ सभी तरीके हैं; वही सूची **सेटिंग्स › शॉर्टकट** में है। कहीं भी <kbd>?</kbd> दबाने से यह पेज खुलता है, जब फ़ील्ड में टाइप न कर रहे हों।

Mac पर यहाँ <kbd>Ctrl</kbd> का मतलब <kbd>⌘</kbd> और <kbd>Alt</kbd> का मतलब <kbd>⌥</kbd> (Option) है, जब तक अलग न लिखा हो।

<a id="going-back-and-forward"></a>
## पीछे और आगे जाना

ब्राउज़र की तरह Marinara चैट, कैरेक्टर, लोरबुक, प्रीसेट, Library सेक्शन, Docs, Professor Mari और Home याद रखता है। उनके बीच पीछे और फिर आगे जा सकते हैं।

- **कंप्यूटर:** ऊपर बाएँ लोगो के पास **←**, **→**, या <kbd>Alt</kbd>+<kbd>←</kbd> और <kbd>Alt</kbd>+<kbd>→</kbd> दबाएँ (Mac पर <kbd>⌘</kbd>+<kbd>[</kbd> और <kbd>⌘</kbd>+<kbd>]</kbd>), या माउस के किनारे के बटन लें।
- **फ़ोन और टैबलेट:** बाएँ किनारे से अंदर स्वाइप करें या ब्राउज़र/Android का पीछे बटन लें। हर कदम ऊपर की चीज़ बंद करता है: मेन्यू, शीट, चैट सेटिंग, एडिटर, Library पेज, फिर Home।

ध्यान रखें:

- पीछे जाकर नया पेज खोलने से आगे के पेज हटते हैं, ब्राउज़र की तरह।
- बंद टैब वाला पेज छोड़ दिया जाता है।
- पीछे जाने को कुछ न हो तो तीर धूसर है; कुंजी और माउस सामान्य ब्राउज़र काम करते हैं।
- अनसहेजे बदलाव अपने टैब में रहते हैं, जैसे टैब बदलने पर ([टैब, विभाजित दृश्य और अनसहेजे बदलाव](tabs-and-drafts.md) देखें)।

<a id="keyboard-shortcuts"></a>
## कीबोर्ड शॉर्टकट

<a id="moving-around"></a>
### नेविगेशन

कंप्यूटर या कीबोर्ड लगे आड़े टैबलेट पर चलते हैं।

| शॉर्टकट | काम |
| ----------------------------------------------------------------------------------- | ------------------------------------- |
| <kbd>Alt</kbd>+<kbd>←</kbd>, या माउस का पीछे बटन                             | पिछले पेज पर लौटें |
| <kbd>Alt</kbd>+<kbd>→</kbd>, या माउस का आगे बटन                          | पीछे जाने के बाद आगे जाएँ |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>←</kbd> या <kbd>Alt</kbd>+<kbd>Page Up</kbd>   | पिछला टैब |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>→</kbd> या <kbd>Alt</kbd>+<kbd>Page Down</kbd> | अगला टैब |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd> से <kbd>8</kbd>                        | बाएँ से गिने उस टैब पर जाएँ |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>9</kbd>                                        | अंतिम टैब |
| <kbd>Alt</kbd>+<kbd>W</kbd>                                                         | दिख रहा टैब बंद करें |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd>                                       | अभी बंद टैब फिर खोलें |

टैब कुंजियाँ <kbd>Alt</kbd>+<kbd>Shift</kbd> लेती हैं, क्योंकि ब्राउज़र <kbd>Ctrl</kbd>+<kbd>Tab</kbd>, <kbd>Ctrl</kbd>+<kbd>W</kbd> और <kbd>Ctrl</kbd>+<kbd>1</kbd> से <kbd>9</kbd> अपने टैब के लिए रखते हैं। Linux पर Chrome और Firefox <kbd>Alt</kbd>+<kbd>1</kbd> से <kbd>9</kbd> भी रखते हैं। <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> केवल Firefox या इंस्टॉल ऐप में Marinara तक पहुँचता है; वरना टैब के राइट-क्लिक मेन्यू में **बंद टैब फिर से खोलें** लें।

<a id="touch-gestures"></a>
## टच जेस्चर

| जेस्चर | काम |
| ----------------------------------------- | --------------------------------------------------------------- |
| बाएँ किनारे से अंदर स्वाइप | एक कदम पीछे |
| ऊपरी शीर्षक बाएँ/दाएँ स्वाइप | अगला/पिछला टैब |
| ऊपरी बार नीचे खींचें | Search, या उसकी ओर खींचने पर Professor Mari खोलें |
| चैट सूची ऊपर से नीचे खींचें | दूसरे डिवाइस की चैट समेत सूची रीलोड करें |
| नया जवाब बाएँ/दाएँ स्वाइप | जवाब बदलें (आखिरी के आगे नया बनाने से पहले पूछता है) |
| चैट पंक्ति बाएँ स्वाइप | पिन, नाम बदलें, टैग और हटाएँ |
| संदेश, चैट पंक्ति या टैब दबाकर रखें | मेन्यू खोलें |

<a id="the-edge-swipe-in-the-home-screen-app"></a>
### होम स्क्रीन ऐप में किनारे से स्वाइप

Safari में बाएँ किनारे का स्वाइप Safari का है; Marinara ऐप छोड़ने के बजाय एक स्तर पीछे जाता है। **Share › Add to Home Screen** से जुड़ी ऐप का अपना पीछे स्वाइप नहीं, इसलिए Marinara गोल तीर बनाता है जो उँगली के साथ चलता है और पर्याप्त खींचने पर रंगीन होता है। छोड़ने पर पीछे जाएँ, वापस किनारे पर लाकर रद्द करें। दाएँ-से-बाएँ भाषाओं में दाएँ किनारे से होता है।

<a id="every-gesture-has-a-button"></a>
### हर जेस्चर का बटन है

जेस्चर ज़रूरी नहीं:

- **पीछे:** पेज के ऊपर **‹** या **होम**।
- **टैब बदलना:** ऊपर-दाएँ टैब बटन **सभी टैब** दिखाता है।
- **खोज:** ऊपरी बार का आवर्धक।
- **चैट रीफ़्रेश:** सूची के **⋯** में **लिस्ट रीफ़्रेश करें** (कंप्यूटर पर ऊपर गोल तीर)।
- **जवाब:** सबसे नए जवाब का **Reply 1 of 3** दूसरी वर्ज़न दिखाता है।
- **चैट ऐक्शन:** पंक्ति दबाकर रखें।

<a id="turning-swipes-off"></a>
### स्वाइप बंद करें

**सेटिंग्स › शॉर्टकट › टच जेस्चर** का **टच स्क्रीन पर स्वाइप जेस्चर** बंद करने से शीर्षक, जवाब और चैट पंक्ति के स्वाइप रुकते हैं; आड़ा खींचना केवल स्क्रॉल करता है। किनारे से पीछे, नीचे खींचना और दबाकर रखना चलते हैं।
