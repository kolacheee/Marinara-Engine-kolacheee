# SillyTavern से आ रहे हैं

SillyTavern में आप जो इस्तेमाल करते थे, उसमें से ज़्यादातर Marinara Engine (आगे Marinara) में है, कभी किसी दूसरे नाम से। तालिका में अपना जाना-पहचाना शब्द ढूँढें, फिर ऐप में वह जगह खोलने के लिए **मुझे दिखाएँ** दबाएँ, या उसकी गाइड पढ़ने के लिए नाम पर क्लिक करें।

आप SillyTavern वाला शब्द सर्च में भी टाइप कर सकते हैं (**Ctrl+K**, या फ़ोन पर शीर्षक पर टैप करें)। "chat preset", "world info" और "author's note", सभी Marinara के उस फ़ीचर तक पहुँचाते हैं।

अपने कैरेक्टर, चैट, प्रीसेट और World Info लाने के लिए [SillyTavern से इंपोर्ट करना](importing-from-sillytavern.md) देखें।

## वही चीज़, Marinara का नाम

| SillyTavern में | Marinara में | कहाँ | |
| --- | --- | --- | --- |
| Chat presets, chat defaults | [सेटिंग्स प्रोफ़ाइल](../chats/settings-profiles.md) | नया Roleplay → **प्रोफ़ाइल इस्तेमाल करें**, या चैट सेटिंग्स → **प्रोफ़ाइल** | [मुझे दिखाएँ](#show-settingsProfiles) |
| World Info, World Book | [लोरबुक](../lorebooks/overview.md) | लाइब्रेरी → **लोरबुक** | [मुझे दिखाएँ](#show-lorebooks) |
| Author's Note | [लेखक के नोट्स](../roleplay/getting-started.md) | चैट सेटिंग्स (Roleplay) | [मुझे दिखाएँ](#show-authorsNotes) |
| Quick Replies, STscript | [तुरंत जवाब और स्लैश कमांड](../chats/guided-and-impersonate.md) | **भेजें** के बगल में, या `/` टाइप करें | [मुझे दिखाएँ](#show-quickReplies) |
| Extensions (Summarize, Image Generation…) | [एजेंट](../agents/agents-overview.md) | लाइब्रेरी → **एजेंट**, फिर हर चैट में चालू करें | [मुझे दिखाएँ](#show-agents) |
| Summarize, Vector Storage, Data Bank | [मेमोरी रिकॉल और सारांश](../agents/memory.md) | चैट सेटिंग्स → **मेमोरी रिकॉल** | [मुझे दिखाएँ](#show-memory) |
| API Connections, Connection Profiles | [कनेक्शन](../connections/connecting-to-a-provider.md) | लाइब्रेरी → **कनेक्शन** | [मुझे दिखाएँ](#show-connections) |
| Prompt Itemization | [प्रॉम्प्ट देखें](../chats/peek-prompt.md) | सबसे नया AI जवाब → **प्रॉम्प्ट देखें** | [मुझे दिखाएँ](#show-peekPrompt) |
| Checkpoints, branches | [ब्रांच](../chats/branches.md) | कोई संदेश → **यहाँ से ब्रांच बनाएँ** | [मुझे दिखाएँ](#show-branches) |
| Swipes, reroll | [स्वाइप](../chats/messages.md) | जवाब के नीचे तीर, या टच स्क्रीन पर स्वाइप करें | [मुझे दिखाएँ](#show-swipes) |
| Persona Management | [पर्सोना](../characters/personas.md) | लाइब्रेरी → **पर्सोना** | [मुझे दिखाएँ](#show-personas) |
| UI Themes, Custom CSS | [थीम और CSS थीम](../appearance/custom-css-themes.md) | सेटिंग्स → **रूप** | [मुझे दिखाएँ](#show-themes) |

**मुझे दिखाएँ** जब हो सके पेज खोलता है या स्टेप शुरू करता है। चैट के अंदर मिलने वाली चीज़ों (प्रॉम्प्ट देखें, मेमोरी) के लिए पहले चैट खोलें; नहीं तो यह गाइड खोलता है।

## जो चीज़ें अलग तरह से काम करती हैं

- **तीन चैट मोड।** Marinara चैट को **Conversation** (DM जैसे छोटे संदेश), **Roleplay** (नैरेशन वाले लंबे सीन) और **Game** (Game Master नियमों वाली दुनिया चलाता है) में बाँटता है। हर नई चैट पूछती है कि आपको कौन-सा चाहिए, और उसका सेटअप सिर्फ़ वही दिखाता है जो उस मोड में इस्तेमाल होता है।
- **चैट शुरू करना।** नई चैट में छोटा सेटअप खुलता है। बार-बार इस्तेमाल होने वाला सेटअप सेटिंग्स प्रोफ़ाइल के रूप में सेव करें, तो अगली बार एक ही स्टेप है: **प्रोफ़ाइल इस्तेमाल करें**, फिर **लागू करके शुरू करें**। प्रोफ़ाइल को स्टार देकर उसे उस मोड की नई चैट के लिए डिफ़ॉल्ट बनाएँ।
- **सर्च सब ढूँढता है।** **Ctrl+K** चैट, कैरेक्टर, सेटिंग्स और गाइड ढूँढता है, कमांड चलाता है और Professor Mari की मदद से सवालों के जवाब देता है।
- **Professor Mari।** Marinara की बिल्ट-इन असिस्टेंट ऐप के बारे में सवालों के जवाब देती है और आपके लिए कैरेक्टर, लोरबुक और एजेंट बना सकती है। उसे Home से खोलें।
