# テーマで天気を表現する

物語に天気があると、Marinaraはチャットの上に雨、雪、霧、舞い落ちる葉や花びら、星、太陽、月を描きます。テーマでは、そのすべてを独自の見た目にできます。雨の色を変えたり、雪をピクセルの四角形として降らせたり、自分で描いた画像を葉の代わりに使ったり、雨が降ると背景を灰色に変えたりできます。

このガイドでは、手順を1つずつ説明します。まず自作のテーマが必要です。まだない場合は、[テーマ作成ガイド](theme-author-guide.md)に従えば数分で作れます。そちらの[天気](theme-author-guide.md#weather)セクションは、このページの短いリファレンス版です。

## 天気の仕組み

天気は物語から決まります。RoleplayまたはGameのチャットでは、**World State**(世界の状態)エージェントが「heavy rain」や「night」のような天気と時間帯を追跡します。Marinaraはその言葉を読み取り、何を描くかを選びます。「rain」なら雨筋、「snow」なら雪片、「night」なら星と月、といった具合です。

描画は必ずアプリ自身が行います。テーマが何かを描画するわけではありません。テーマはいくつかの`--mari-weather-`トークン(`--primary`のような名前付き設定)を指定し、アプリがそれを読み取ってテーマに合った天気を描きます。この仕組みによりテーマの安全が保たれます。テーマ内ではコードを実行できず、動きを減らす設定など、利用者自身の設定が常に優先されます。

### 屋内では天候を外にとどめる

物語の舞台が宿屋、寝室、World Mapsの部屋などの屋内にあるとき、アプリは画面全体に雨を降らせません。天候の色合いと稲妻の閃光だけを残し、室内は濡れないままにします。「屋内」かどうかは、World Stateの場所(「Tideglass Inn, Brinewatch」)やWorld Mapsの場所の種類から判断します。判断できないときは、通常どおり天候を描画します。**Weather Versions of Backgrounds**(背景の天候差分)をオンにすると([背景の天候差分](../media/scene-backgrounds.md#weather-versions-of-backgrounds)を参照)、背景画像自体に窓を打つ雨が描かれ、動く天候も窓ガラスの上だけに再び表示されます。テーマで設定した天候の見た目は、そこにも適用されます。

### テーマを使わない場合の天気

テーマを使わない雨の夜は、濃い青の色合いに薄く細い雨筋が重なります。この先の画像では、同じチャットに3つのスターターテーマを使った様子を示します。

## 作業中に天気を表示する

物語で雨が降るのを待つ必要はありません。自分で天気を設定できます。

1. **Library → Settings → Appearance**(ライブラリー → 設定 → 外観)を開き、**Dynamic weather effects**(動的な天気エフェクト(雨、雪、霧など))がオンになっていて(**Effects**(エフェクト)内)、**Reduce Ambient Animations & Effects**(環境アニメーションとエフェクトを減らす)がオフになっていることを確認します。
2. Roleplayのチャットを開き、**Chat Settings → Agents**(チャット設定 → エージェント)を開いて**World State**をオンにします。
3. **World State**トラッカーを開きます。コンピューターではTracker Panelにあります。スマートフォンでは、**World State**ボタンをタップします。
4. **Weather**(天気)の値をクリックし、`heavy rain`などの天気を表す言葉を入力します。**Time**(時刻)をクリックし、`night`と入力します。
5. 天気がすぐに始まります。チャットのタブがトップバーに表示されます。

テーマの作業中は、Settingsがウィンドウ中央を埋め、その背後では天気が一時停止します。テーマを保存してから、トップバーにあるチャットのタブをクリックして結果を確認します。別の天気を試すには、手順4の言葉を変えてください。下の**どの言葉でどの天気になるか**の表に、すべて記載されています。

> **ヒント:** テスト中にAIが変更しないよう、Weatherの値をロックしてください(トラッカーのロックモード)。[RoleplayのHUDとトラッカー](../roleplay/hud-and-trackers.md)を参照してください。

## 最初の天気表現を手順に沿って作る

NEON//GRIDスターターテーマと同じように、雨に色を付けて雨筋を長くしてみましょう。

1. **Library → Settings → Appearance → CSS Themes**(ライブラリー → 設定 → 外観 → CSSテーマ)を開き、自分のテーマにある**Edit theme CSS**(テーマのCSSを編集)(コードのアイコン)をクリックします。
2. CSSの先頭近くにある`:root {`の行を探します。テーマにない場合は、新しい行に`:root {`を追加し、その次の行に`}`を追加します。
3. その中の`}`より前に、次の行を追加します。

```css
--mari-weather-rain-color: #3ff0ff;
--mari-weather-rain-length: 2.2;
--mari-weather-strength: 1.4;
```

4. **Save**(保存)をクリックします。Marinaraに**Keep this theme?**と尋ねられたら、**Keep theme**(テーマを維持)をクリックします。
5. トップバーにあるテスト用チャットのタブをクリックします。雨がシアンになり、雨筋が約2倍の長さになって、よりはっきり表示されます。

各行には次の働きがあります。

- `--mari-weather-rain-color`は雨粒の色です。`#3ff0ff`のような16進コード、`skyblue`のような名前、`rgb(63 240 255)`など、どの色でも使えます。
- `--mari-weather-rain-length`は雨筋を長くしたり短くしたりします。`1`が通常で、`2.2`は2倍より少し長くなります。
- `--mari-weather-strength`は、すべてのパーティクルを強く(`1`より大きい値)または弱く(`1`より小さい値)表示します。

### 表示されるもの

これは、同じ雨の夜にNEON//GRIDを使った様子です。このテーマでは、上の3行と、それ以外のいくつかの設定を使っています。

### 昼と夜の色を選ぶ

暗い背景で見栄えのよい色が、明るい背景では見えなくなることがあります。ほかの色を設定する場合と同じように、昼の色は`[data-theme="light"]`ブロックに、夜の色は`[data-theme="dark"]`ブロックに入れます。

```css
:root[data-theme="light"] {
  --mari-weather-rain-color: #1aa7c4;
  --mari-weather-snow-color: #22b8d6;
}
:root[data-theme="dark"] {
  --mari-weather-rain-color: #3ff0ff;
  --mari-weather-snow-color: #7af7ff;
}
```

## どの言葉でどの天気になるか

天気の種類ごとに短い名前があります。`snow`を`--mari-weather-snow-color`の中に入れるように、トークンでその名前を使います。

| 物語内の言葉 | アプリが描くもの | トークン内の名前 |
| ----------------------------------- | ------------------------------------------------- | ---------------------------------------------------------- |
| rain, downpour | 雨筋 | `rain` |
| storm, thunder, lightning | 稲妻の閃光を伴う大雨 | `rain`(閃光: `lightning-color`、稲妻: `lightning-bolt`) |
| snow, sleet, blizzard, frost, cold | 雪片 | `snow` |
| hail | ひょう | `hail` |
| fog, mist, haze | 画面下部に漂う柔らかな霧の層と地表の霧 | `fog` |
| sand, dust storm | 吹きつける砂 | `sand` |
| ash, smoke, volcanic | 舞い落ちる灰 | `ash` |
| fire, embers, inferno | 舞い上がる残り火 | `ember` |
| wind, breeze, gusts | 舞い落ちる葉 | `leaf` |
| cherry blossom, petals | 舞い落ちる花びら | `petal` |
| aurora, northern lights | オーロラの帯 | `aurora` |
| clear, sunny, cloudy, anything else | 少数の漂う微粒子 | `dust` |
| night (the time) | 星とホタル | `star`、`firefly` |
| dusk, evening (the time) | ホタル | `firefly` |
| morning, day, dusk (clear sky) | 太陽 | `sun` |
| night (clear sky) | 月 | `moon` |

霧や雪の夜には星が表示されず、雨のときにはホタルが現れません。太陽と月は空が晴れているときだけ表示されます。

## 色、大きさ、形を変える

表にあるすべての種類で、同じ3つの設定を使えます。トークンの中央に種類の名前を入れます。

| トークン | 働き | 値 |
| --------------------------- | ---------------------------- | ---------------------------------------------------------- |
| `--mari-weather-snow-color` | 色 | 単色: `#fff0f7`、`white`、`rgb(...)`、`hsl(...)` |
| `--mari-weather-snow-size` | 各パーティクルの大きさ | `0.5`(半分)～`3`(3倍) |
| `--mari-weather-snow-shape` | 丸い点または小さな四角形 | `round`または`square` |

`snow`を、`--mari-weather-ember-color`や`--mari-weather-leaf-shape`など、表にある別の名前に置き換えてください。

例: コンピューター風のテーマで使う「データの雪」。雪片の代わりに小さなシアンの四角形を表示します。

```css
:root {
  --mari-weather-snow-color: #7af7ff;
  --mari-weather-snow-shape: square;
  --mari-weather-snow-size: 1.2;
}
```

形の設定は、独自の形状を保つ雨、霧、オーロラには適用されません。霧では、`--mari-weather-fog-color`が漂う霧の層と地表の霧の両方に色を付け、`--mari-weather-tint-strength`が霧を薄くしたり濃くしたりします。

## 自分の画像を使う

点や雨筋の代わりに、種類ごとに自作画像を降らせることができます。カエデの葉、桜の花びら、紙の星、小さなピクセルの雪片などを使えます。

1. PNGなど、背景が透明な小さな画像を描くか見つけます。小さく保ってください。葉なら幅24～64ピクセル程度で十分です。それより大きい画像は、最も長い辺が160ピクセルになるよう縮小されます。
2. テーマエディターで、**Pictures and sharing details**(画像と共有情報(作者、バージョン、サムネイル、フォント))を開き、**Add pictures**(画像を追加)をクリックします。1種類につき最大4枚の画像を追加します。
3. CSSで、種類の`-image`トークンに画像を並べ、画像同士を空白で区切ります。

```css
:root {
  --mari-weather-leaf-image: url("theme:leaf-1.png") url("theme:leaf-2.png") url("theme:leaf-3.png");
  --mari-weather-leaf-size: 0.8;
}
```

4. 保存してテスト用チャットを開き、天気を`windy`に設定します。葉が漂いながら舞い落ちるようになり、1枚ごとに追加した画像のいずれかが使われます。

画像を使う際のヒント:

- **Pictures and sharing details**の下にある画像名をクリックすると、その`url("theme:...")`がCSSのカーソル位置に挿入されるため、名前を入力する必要がありません。
- 画像には、`leaf-1.png`のように拡張子も含め、追加時のファイル名がそのまま使われます。一覧に表示された名前を正確に使ってください。
- 画像は元の色で描画されるため、その種類では`-color`トークンの効果がありません。
- `-size`を使うと、すべての画像を大きくしたり小さくしたりできます。滑らかなスタイルでは、すべてが同じ見た目にならないよう、大きさも少しずつ変わります。
- 滑らかなスタイルでは、葉、花びら、灰が落ちながら穏やかに回転します。それ以外の種類は上向きのままです。
- 画像はテーマ内に置く必要があります。別のウェブサイトにある画像へのリンクは無視されます。

Lantern Pathスターターテーマでは、この方法で4枚の手描きの葉を使っています。

## ピクセルスタイル

ピクセルスタイルでは、天気レイヤー全体を大きな正方形のピクセルで構成されたグリッドに載せ、ピクセルアートのテーマに合わせます。雨粒、雪片、星は、くっきりとした小さなブロックになります。

```css
:root {
  --mari-weather-style: pixel;
  --mari-weather-pixel-size: 3px;
  --mari-weather-petal-image: url("theme:wx-petal-1.png") url("theme:wx-petal-2.png");
  --mari-weather-petal-size: 3;
}
```

- `--mari-weather-style: pixel`でピクセルスタイルをオンにします。`smooth`を指定するか省略すると、通常の見た目になります。
- `--mari-weather-pixel-size`は各ブロックの大きさで、`2px`～`6px`に設定できます。最初は`3px`がおすすめです。
- ピクセルスタイルでは、自分の画像は元の大きさに`-size`を掛けた大きさで描画されます。アートの1ピクセルを画像の1ピクセルとしてピクセルアートを描き、`-size`をピクセルサイズと同じ数値にすると、アートのピクセルが天気のピクセルと揃います。Petal OSでは、11ピクセルの花びらをサイズ`3`で描きます。
- ピクセルスタイルでは、画像は落下中に回転せず、くっきりと描画されます(3段階ではっきりとフェードイン、フェードアウトします)。そのため、ピクセルアートの鮮明さが保たれます。

### 例: Petal OS

これは花の舞う夜にPetal OSスターターテーマを使った様子です。花びらは独自の11ピクセルの画像で、星も同じ3 pxのグリッドに揃っています。

## 太陽と月

太陽と月には、ほかの種類と同じように色、大きさ、1枚の画像を指定できます。

```css
:root {
  --mari-weather-sun-color: #ffe9a8;
  --mari-weather-moon-color: #ffe2f0;
  --mari-weather-moon-size: 1.5;
}
```

背景にすでに月が描かれている場合は、月が2つにならないよう、アプリの月をオフにします。

```css
:root[data-theme="dark"] {
  --mari-weather-moon: none;
}
```

太陽にも`--mari-weather-sun: none`で同じ設定ができます。

## 穏やかにする、または強める

次の設定は、天気レイヤー全体をまとめて変更します。

| トークン | 働き | 値 |
| -------------------------------- | ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `--mari-weather-amount` | 降るパーティクルの数 | `0.25`(4分の1)～`1`(通常)。テーマでは天気を減らせますが、増やすことはできません。 |
| `--mari-weather-speed` | 落下する速さ | `0.5`(半分の速さ)～`1.5` |
| `--mari-weather-strength` | パーティクルを表示する強さ | `0.5`(薄い)～`1.5`(濃い) |
| `--mari-weather-tint-strength` | チャットに重ねる色(雨では青、夜では暗い色) | `0`(なし)～`1`(通常) |
| `--mari-weather-lightning-color` | 稲妻の閃光の色 | 単色。点滅する光に敏感な人にも安全なよう、閃光は穏やかでゆっくりしたままです。 |
| `--mari-weather-lightning-bolt` | 閃光のたびに、稲妻の色で枝分かれした稲妻を描きます | `on`、または`0.5`～`3`の幅。`none`(デフォルト)では閃光だけを表示します。 |

落ち着いて読めるテーマにするには、`--mari-weather-amount: 0.5;`と`--mari-weather-tint-strength: 0.3;`を試してください。

### 稲妻

デフォルトでは、嵐のときに画面が光るだけです。`--mari-weather-lightning-bolt`を追加すると、閃光のたびに枝分かれした本物らしい稲妻を描けます。

```css
:root {
  --mari-weather-lightning-color: #e8f2ff;
  --mari-weather-lightning-bolt: 1.2;
}
```

稲妻は画面の左端または右端を下に向かって走り、チャット本文がある中央を横切ることはありません。複数の枝に分かれ、指定した稲妻の色で光ります。アプリ自身の閃光が表示されている間だけ現れ、それと同時に消えるため、テーマが閃光を増やしたり速くしたりすることはできません。ピクセルスタイルでは、稲妻はピクセルグリッド上にブロックで描かれます。ほとんどのスターターテーマでは稲妻を使っています。Apogee Lounge、Crepuscular、Dewglass、Gutterlight、MARI to the Moon、Sanguine Keep、Under Sail、Velvet Casketです。Granite WatchとQuiet Irisは屋内に設定されているため、稲妻をオフにしています。

## 背景を天気に連動させる

テーマ自身のアートも天気に合わせて変えられます。チャットに天気が表示されている間、MarinaraはCSSから確認できる2つの言葉をページに追加します。

- `data-mari-weather`は、`clear`、`cloudy`、`rain`、`storm`、`snow`、`hail`、`fog`、`sand`、`ash`、`embers`、`wind`、`blossom`、`aurora`のいずれかです。
- `data-mari-sky`は、`dawn`、`day`、`dusk`、`night`のいずれかです。

これらは必ず上記のいずれかになり、物語内の元の文章が使われることはありません。チャットに天気がない場合や、利用者が天気をオフにした場合は表示されなくなります。

### 例: 雨のLantern Path

Lantern Pathでは、雨が降ると、晴れた森を灰色の曇り空の森に切り替えます。左は晴れた朝です。右は同じチャットに雨が降っている様子です。

### 背景を切り替える

同じことをするには、雨または嵐のときだけ適用されるブロックを追加し、2枚目の背景画像を指定します。

```css
:root {
  --mari-app-backdrop: url("theme:forest-sunny.webp");
}
:root[data-mari-weather="rain"],
:root[data-mari-weather="storm"] {
  --mari-app-backdrop: url("theme:forest-overcast.webp");
}
```

読み方は次のとおりです。`:root[data-mari-weather="rain"]`は「雨が降っている間だけ」という意味です。カンマは「または」を意味します。

- テーマで`--mari-app-backdrop-layers`を設定し、`--mari-app-backdrop`を使っていない場合は、天気のブロックでも`--mari-app-backdrop-layers`を変更してください。こちらが1枚の画像より優先されます。
- 昼夜も一致させるには、スキームを追加します。`:root[data-theme="dark"][data-mari-weather="rain"]`は「Darkで雨の夜」を意味します。
- `data-mari-sky`も同じように使えます。たとえば、夕焼け版のアートには`:root[data-mari-sky="dusk"]`を使います。

### 天気を二重にしない

テーマに舞い落ちる葉や雨の独自の環境オーバーレイ(`--mari-ambient`)がある場合、物語の天気の上に重なることがあります。実際の天気が降っている間はオフにしてください。

```css
:root[data-mari-weather]:not([data-mari-weather="clear"], [data-mari-weather="cloudy"]) {
  --mari-ambient: none;
}
```

これは「天気があり、晴れでも曇りでもないときは、環境オーバーレイを隠す」という意味です。

独自の落ち葉や雨のオーバーレイも、屋外だけに表示できます。天候が表示されている間、`data-mari-shelter`は`indoors`または`outdoors`になります(アプリが判断できないときは付与されません)。

```css
:root[data-mari-shelter="indoors"] {
  --mari-ambient: none;
}
```

## 利用者の選択として残るもの

テーマが変えるのは天気の見た目であり、表示するかどうかではありません。

- テーマでは天気をオン、オフにできません。Settingsの**Dynamic weather effects**で決まります。
- **Reduce Ambient Animations & Effects**がオンの場合や、端末の動きを減らす設定が有効な場合は、天気は一切描かれません。画像の切り替えは動きを伴わないため、背景は引き続き`data-mari-weather`に従います。
- **Reduced paint effects**(描画エフェクトを減らす)は色合いと光を取り除き、パーティクルを減らします。
- **Theme art strength**(テーマアートの強さ)は背景と同じように天気を薄くし、**High contrast**(ハイコントラスト)は天気を薄いままにします。
- バッテリーを節約するため、パネル、エディター、Mariがチャットを覆っている間、天気は一時停止します。

## 動かない場合

- **何も変わらない。** トークンが`{ }`ブロック内にあり、`;`で終わっていることを確認します。綴りも確認してください。`--mari-weather-rain-color`であり、`color`はアメリカ英語の綴りです。
- **値が無視される。** トークンの範囲外にある数値は最も近い端の値に移され、アプリが理解できない値は破棄されます。色には単色を指定する必要があります。グラデーションと`url()`は無視されます。
- **画像が表示されない。** 画像がテーマの画像一覧にあり、`url("theme:...")`の名前が正しい拡張子(`.webp`または`.png`)を含めて完全に一致している必要があります。
- **天気がまったく表示されない。** チャットで**World State**がオンになっていること、Weatherの値に表内の言葉が含まれていること、**Dynamic weather effects**がオンになっていること、**Reduce Ambient Animations & Effects**がオフになっていることを確認します。
- **Roleplayでは天気が表示されるが、Conversationでは表示されない。** これは想定どおりです。天気はRoleplayとGameのチャットでのみ表示されます。

## スターターテーマから学ぶ

テーマギャラリーにあるすべてのスターターテーマで、天気の見本を確認できます。1つダウンロードし、**Clone + Edit**(複製して編集)をクリックして、CSS内の`Weather`と記された部分までスクロールすると、仕組みを確認できます。

- **NEON//GRID**: 長いシアンの雨筋、四角形の「データの雪」、葉や花びらの代わりに使われるマゼンタの火花。実際の天気が降ると、描かれた雨のオーバーレイは表示されなくなります。
- **Petal OS**: 3 pxのグリッドを使うピクセルスタイル、独自のピクセルの花びら、夜の淡いピンクの雨と昼の濃いベリー色の雨、悪天候になると灰色がかる街。
- **Lantern Path**: 独自の手描きの葉、暖色のホタル、アプリの太陽はなし(背景が独自の光を描いています)、天気に合わせて曇りや雪景色に変わる背景。
- **Dewglass**: 微粒子の代わりに使われる独自のシャボン玉、コードで描かれた結晶の雪片、アクアの雨、シアンの稲妻、曇り、凍結、霧に変わるラグーンの背景。
- **Velvet Casket**: 昼夜で異なる嵐。昼はピンクの稲妻とライラック色の雨、夜は墓地に降る紫がかった白の稲妻と銀色の雨、風には独自のコウモリとバラの花びらが舞います。
- **Gutterlight**: 冷たいコミック風の雨、風に舞う破れた新聞紙、ナトリウムイエローのスモッグ、稲妻が走るとガーゴイルから水が流れ落ちる嵐の背景。
- **Under Sail**: 索具の脇を白青の稲妻が落ちる海上のスコール、海霧、手すりやラットラインに積もる雪、風に舞うカモメの羽。
- **Apogee Lounge**: ラウンジの窓から見える宇宙の天気。嵐は紫のプラズマの稲妻が走る星雲内のイオンストームになり、雨は微小隕石の筋、雪は氷原、霧は星雲の霞になります。マスクにより、すべてがガラスの内側に収まります。
- **Granite Watch**: 屋内のテーマなので、天気はテーマで可能なかぎり薄く表示されます。雨は導管から落ちる水滴、雪はしっくいの粉に見え、稲妻はオフで、アプリの閃光はランプのちらつきのような色になります。屋内設定で天気を穏やかにする方法は、このテーマを参考にしてください。
- **Quiet Iris**: こちらも屋内のテーマですが、展望窓があります。天気はガラス越しにだけ見え、背景は展望窓に雨、霜、霧がついたバージョンに切り替わります。稲妻はオフで、嵐のときはベイが少し暗くなります。
- **MARI to the Moon**: トレーディングルームの窓から見える相場の天気。雨は緑のティックとして降り、嵐は赤い稲妻と赤い画面を伴う暴落、雪は降ってくるコインとダイヤモンド、風は紙幣を吹き飛ばし、花は小さなロケットを打ち上げ、霧はスカイラインを覆うFUDです。
- **Sanguine Keep**: 城の窓から見える天気。背景ごとのステンシルが、雨、雪、花びら、木の葉、稲妻を大広間（スマホでは階段塔）の窓ガラスの内側だけに収め、石壁の上には決して出しません。
- **Crepuscular**: 暦を通して読む同じ海。雪は粉砂糖、ちりはパンくず、ホタルは見張る目、風は紙切れを運び、稲妻は細い彫版の枝、そして見張りは傘の下で続きます。屋内では、鉛枠のステンドグラス窓越しに海が見えます。
