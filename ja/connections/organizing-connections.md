# 接続の整理

このガイドでは、**Connections**(接続)ページ(**Library → Connections**(ライブラリー → 接続))でアカウントとモデルを整理する方法を説明します。星付け、並べ替え、編集、削除、Shuffle、フォルダー、エクスポートを取り上げます。アカウントを追加する方法は、[AIプロバイダーへの接続](connecting-to-a-provider.md)を参照してください。

## アカウントの一覧

**Defaults**(用途)ボックスの下に、**Models**(モデル)、**Status**(状態)、**Balance**(残高)の列がある表でアカウントが並びます。**On this device**(このデバイス上)には[内蔵モデル](local-model.md)があります。アカウントをクリックすると、その下に保存済みのモデルが表示され、もう一度クリックすると折りたたみます。モデルの行には、名前と、担当している役割(**Main**、**Agents**、**Images**)、**Custom settings**、価格、サブスクリプションに含まれるモデルを示す**Plan**などのバッジが表示されます。ローカルまたはセルフホストのアカウントには、**Default**も表示されることがあります。これは「Whatever model the server has loaded」と表示され、星はありません。[サーバーに読み込まれているモデルを使う](local-self-hosted.md#use-whatever-model-the-server-has-loaded)を参照してください。

表の上には次の操作があります。

- **All kinds**(すべての種類)で、一覧を**Chat**(チャット)、**Images**(画像)、**Video**(動画)、**Voice**(音声)のアカウントに絞り込めます。
- **Search accounts and models**(アカウントとモデルを検索)に入力すると、その場で一覧が絞り込まれます。
- 並べ替えメニューには、**Sort: Name**(並べ替え: 名前)、**Sort: Most models**(並べ替え: モデル数が多い順)、**Sort: Recently changed**(並べ替え: 最近変更した順)があります。

NanoGPTやプロキシのように、複数の開発元のモデルを使えるアカウントもあります。そうしたアカウントのモデルは、**via NanoGPT**のような見出しの下にまとめられます。

### アカウントの操作

アカウントの行にある**⋯**をクリックします。

| 操作 | 内容 |
| --- | --- |
| **Edit account**(アカウントの編集) | 設定を開きます。**Name**(名前)、**Address**(アドレス)、**API key**(APIキー)、**Use this account**(このアカウントを使う、削除せずにオフにできます)、**Test account**(アカウントをテスト)、**Usage and balance**(使用量と残高)があります。**More options**(その他のオプション)には、**Requests per minute**(1分あたりのリクエスト数)と**Parallel requests**(同時リクエスト数)があります。**Delete**(削除)もここにあります。 |
| **Replace key**(キーを置き換える) | 新しいキーを貼り付けます。古いキーがほかのアカウントにも設定されている場合は、それらも更新するかどうかをMarinaraが尋ねます。 |
| **Add model**(モデルを追加) | アカウントのモデル一覧を開きます。画像も作れるサービスでは、**Add image model**(画像モデルを追加)も表示されます。 |

アカウントを削除するには、**Edit account**を開いて**Delete**をクリックします。Marinaraは確認を求め、そのモデルを使っているもの(チャット、エージェント、モデル、役割)を**Used by**(使用先)の下に一覧で示します。**Delete with its N models**(N個のモデルごと削除)をクリックすると、アカウントとそのモデルを削除します。それらのチャットと役割には、別のモデルが必要になります。削除できないモデルがある場合は、エディターの**This account still has models. Remove these first:**の下に表示されます。1つずつ開いて削除してください。

### プロバイダーのアイコン

各アカウントには、そのサービスのアイコンが表示されます。アイコンはMarinaraに同梱されており、インターネットから読み込まれることはありません。カスタムのアドレスでは、アドレスや名前に既知のサーバーやゲートウェイが含まれている場合、そのアイコンが表示されます。たとえばOllama、LM Studio、KoboldCpp、Bifrost、LiteLLMです。それ以外の場合は、名前の最初の1文字が表示されます。クラシックレイアウトでは自分で選べます。アカウントの画像をクリックし、サービスのロゴを選ぶか、画像をアップロードするか、文字を使います。

## 星付きのモデル

星は、すぐに見つけたいモデルの印です。星付きのモデルは、どのモデル選択画面でも、上のほうの**Starred**(星付き)の下に並びます。対象は、**Defaults**(用途)ボックスの**Model for**(役割に使うモデル)ウィンドウ、**Model for this chat**(このチャットのモデル)、**Chat Settings**(チャット設定)とエージェントエディターのモデル欄です。

モデルに星を付けるには、モデルの行か、アカウントの**Add model**(モデルを追加)の一覧でそのモデルの星をクリックします。モデルに役割を割り当てた場合も、そのモデルは保存されます。

星を外すには、もう一度星をクリックします。Marinaraはそのモデルを削除し、数秒間**Undo**(元に戻す)を表示します。チャットで使われている場合、**Defaults**で役割を持っている場合、独自の設定がある場合、またはアカウントの最後のモデルである場合は、星だけが外れてモデルは残ります。その理由はメッセージに表示されます。

## モデルの編集と削除

モデルの行をクリックすると、すべての設定がある**Edit model**(モデルの編集)が開きます。**Export model**(モデルをエクスポート)でファイルに保存できます([エクスポートとインポート](#export-and-import)を参照)。モデルに役割を割り当てるには、**Defaults**(用途)ボックスでその役割をクリックし、モデルを選びます。

コンピューターでは、モデルの行をチャットの上にドラッグすると、そのチャットでそのモデルを使えます。

### モデルの操作

モデルの行の末尾にある**⋯**をクリックするか、行を右クリックします。

| 操作 | 内容 |
| --- | --- |
| **Edit model**(モデルの編集) | モデルの設定を開きます。 |
| **Make default for…**(…のデフォルトにする) | モデルに役割を割り当てます。**Defaults**で選ぶのと同じです。すでに担当している役割にはチェックマークが付きます。 |
| **Move to account…**(アカウントへ移動…) | モデルを別のアカウントへ移します。移したモデルは、移動先のアカウントのキーを使います。名前、画像、役割、チャットも一緒に移り、サービス固有のオプションはリセットされます。 |
| **Move to folder**(フォルダーに移動) | モデルをフォルダーに入れます([フォルダー](#folders)を参照)。 |
| **Duplicate**(複製) | 同じ設定のまま丸ごとコピーし、そのコピーを開きます。 |
| **Add to Shuffle**(Shuffleに追加) / **Remove from Shuffle**(Shuffleから外す) | [Shuffle](#shuffle)を参照してください。プールに入っているモデルの行には**Shuffle**タグが表示されます。 |
| **Export**(エクスポート) | モデルをファイルに保存します。 |
| **Remove**(削除) | 確認したあとでモデルを削除します。確認画面には、そのモデルを使っているものが表示されます。 |

## フォルダー

フォルダーを使うと、たとえば**RP**や**Work**のようにモデルをまとめられます。1つのモデルは1つのフォルダーに入ります。

1. モデルの**⋯**をクリックし、**Move to folder**(フォルダーに移動)を選びます。
2. フォルダーを選ぶか、**New folder…**(新しいフォルダー…)をクリックして名前を入力し、**Create**(作成)をクリックします。
3. フォルダーを表示するには、並べ替えメニューの横のメニューで、**By account**(アカウント別)から**By folder**(フォルダー別)に切り替えます。

**By folder**では、各フォルダーにモデルがアカウント名とともに並び、フォルダーに入っていないモデルは**Not in a folder**(フォルダーなし)の下に表示されます。フォルダーの名前を変えたり削除したりするには、その**⋯**をクリックするか、右クリックします。フォルダーを削除しても、中のモデルは**Not in a folder**の下に残ります。クラシックパネルにも同じフォルダーが表示され、さらにアイコンと色を設定できます。

## Shuffle

Shuffle(シャッフル)を使うと、チャットが返信を書くたびに別のモデルを選べます。複数のサービスやモデルにリクエストを分散したいときに使います。

1. プールに入れたい各モデルの**⋯**をクリックし、**Add to Shuffle**(Shuffleに追加)を選びます。
2. チャットで、チャット入力欄から**Model for this chat**(このチャットのモデル)を開くか、**Chat Settings → Connection → Model**(チャット設定 → 接続 → モデル)を開き、**Shuffle**を選びます。

以降は返信ごとに、Shuffleのプールからランダムにモデルを選びます。

返信のために選ばれたモデルが失敗し、**Main**(メイン)に**If it fails**(失敗したとき)のモデルが設定されている場合は、代わりにそのモデルが返信を書きます。通知には、失敗したモデルと、「key rejected」「rate limited」「not found」のような短い理由が表示されます。返信には小さな**Fallback**(フォールバック)ラベルが残ります。タップするかポインターを合わせると、同じ内容をもう一度確認できます。

**Model for this chat**で選んだモデルが変わるのは、そのチャットだけです。新しいチャットのモデルを変えるには、**Defaults**(用途)ボックスで**Main**を設定します。

## クラシックレイアウトでの操作

クラシック版のConnectionsパネルには、さらにいくつかの操作があります。**Settings → Appearance → Theme**(設定 → 外観 → テーマ)の**New layout**(新しいレイアウト)で切り替えられ、同じ操作で戻せます。どちらのレイアウトでも同じアカウントを使います。

- モデルの**⋯**には**Change picture**(画像を変更)もあります。
- アカウントの**⋯**には、**Test**(テスト)、**Select models**(モデルを選択、複数のモデルをまとめて移動または削除)、**Duplicate**(複製)、**Turn off**(オフにする) / **Turn on**(オンにする)もあります。
- パネル上部の**More actions**(その他の操作、3つの点のアイコン)には、**Fold all accounts**(すべてのアカウントを折りたたむ)、**Open all accounts**(すべてのアカウントを開く)、**Show only Off or Needs key**(オフまたはキー未設定のものだけを表示)、**Show cost badges**(料金のバッジを表示)があります。

## エクスポートとインポート

アカウントはファイルにエクスポートできます。バックアップとして保管したり、別のインストール先へ移したりして、あとからインポートできます。

> **Warning:** エクスポートしたファイルにAPIキーは含まれません。インポートしたあとは、アカウントを1つずつ開いてキーを入力し直してください。キーは誰とも共有しないでください。

- **1つのモデルをエクスポートする:** **Edit model**(モデルの編集)で開き、**Export model**(モデルをエクスポート)をクリックします。
- **すべてをエクスポートする:** Connectionsページ上部の**Export all accounts**(すべてのアカウントをエクスポート、**Import**の隣にあるアップロードアイコン)をクリックします。ファイルにキーが含まれないことをMarinaraが知らせます。**Export**(エクスポート)をクリックします。
- **インポートする:** Connectionsページ上部の**Import**(インポート)をクリックします。1つ以上のファイル(`.json`、`.jsonl`、`.zip`)をウィンドウにドロップするか、クリックしてファイルを選びます。エクスポートした`marinara-connections.zip`もインポートできます。インポートした各アカウントのキーは、入力するまで空のままです。

モデルが1つのときは`.connection.json`ファイルとしてダウンロードされます。複数のときは`marinara-connections.zip`にまとめてダウンロードされます。星は含まれます。サービスのモデルカタログは含まれないため、アカウントのモデルを初めて開いたときに読み込み直します。
