# チャットのギャラリー

**Gallery**(ギャラリー)には、チャットの画像と動画が保存されます。イラスト、自撮り、生成した背景、ストーリーボードのフレーム、アップロードした画像や動画などが含まれます。**Chat Settings**(チャット設定)内のセクションです。コンピューターでは、独立したウィンドウとして切り離せます([チャット設定の概要](chat-settings.md#popping-a-section-out-into-its-own-window)を参照してください)。

チャットのギャラリーは、そのチャットに属します。どのチャットでもキャラクターと一緒に使えるように残しておきたい画像は、そのキャラクター自身のギャラリーに保存します。[キャラクターとペルソナのギャラリー](../characters/galleries.md)を参照してください。

## ImagesとVideos

**Gallery**(ギャラリー)には、**Images**(画像)と**Videos**(動画)の2つのタブがあります。各タブには、保存されている項目の数が表示されます。**Videos**タブには、RoleplayとGameのチャットではシーン動画、Conversationのチャットではビデオメッセージが保存されます。

セクションの上部には、そのチャットで使える機能に対応する操作ボタンだけが表示されます。

- **Illustrate**(イラストを描く): Illustratorエージェントを1回実行して、シーンの画像を生成します。[Illustratorエージェント](../media/illustrator-agent.md)を参照してください。
- **Selfie**(自撮り): Conversationモードでキャラクターの自撮りを生成します。
- **Background**(背景): 現在のシーンの背景を生成して適用します。[Illustratorが作る背景](../media/scene-backgrounds.md#paint-a-background-now)を参照してください。
- **Video**(動画): 最新のイラストからシーン動画を作ります。Conversationモードでは、代わりにキャラクターからビデオメッセージを送ります。[ビデオメッセージ](../conversation/selfies.md#video-messages)を参照してください。
- **Create storyboard**(ストーリーボードを作成): Storyboardが有効なときに、最新のGame Modeのターン、または完了したRoleplayのエピソードのキーフレームを生成します。
- **Browse Images**(画像を参照): 挿入する保存済み画像を探す画面を開きます。
- **View storyboard**(ストーリーボードを表示): 最新のGame Modeのストーリーボードを開きます。

ボタンの下には、**Upload Images**(画像をアップロード)のドロップ領域があります。ここに画像をドラッグすると、自分の画像をこのチャットのギャラリーに追加できます。

### 画像ごとの操作

**Images**(画像)タブの画像にポインターを合わせるか、モバイルでは画像をタップすると、操作が表示されます。

- 画像をフルサイズで開きます(**Open gallery image**(ギャラリーの画像を開く))。
- **Pin to chat**(チャットにピン留め): 画像をチャット上に浮かぶ画像としてピン留めします。ドラッグで移動し、角のハンドルでサイズを変更できます。このブラウザーでページを再読み込みしても、位置とサイズは保持されます。閉じるボタンの隣にあるロックボタンを押すと、ロックを解除するまで移動やサイズ変更ができなくなります。
- **Download image**(画像をダウンロード): 画像をデバイスに保存します。
- **Animate illustration**(イラストをアニメーション化): その画像をシーン動画にします。
- **Copy prompt**(プロンプトをコピー): 保存された画像プロンプトをコピーします。画像に保存されたプロンプトがない場合は、**No prompt saved**と表示され、操作できません。
- 画像の左上にあるタグボタン: **Use as background**(背景として使用)は、画像に背景のラベルを付け、`John's bedroom`など、その画像がどの場所を描いているかを尋ねます。
- **Add to a character's or persona's gallery**(キャラクターまたはペルソナのギャラリーに追加)(人物のボタン): 画像をそのキャラクターまたはペルソナ自身のギャラリーに保存し、このチャットがなくなっても残るようにします。背景のラベルと場所も引き継がれ、そのキャラクターがいるすべてのチャットで使えるようになります。[キャラクターと一緒に使える背景](../roleplay/backgrounds.md#backgrounds-that-follow-a-character)を参照してください。
- **Delete gallery image**(ギャラリーの画像を削除): 確認後に画像を削除します。

### 画像の再生成

生成した画像は、その画像を含む返信を再生成せずに作り直せます。イラスト、自撮り、ストーリーボードのフレームなど、チャットのギャラリーにある、プロンプトが保存された画像で使えます。

1. ギャラリーか、画像が含まれるメッセージから、画像をフルサイズで開いてください。
2. **Regenerate image**(画像を再生成)(画像の右上にある円形の矢印ボタン)をクリックしてください。
3. 画像の下の欄で、変更したい内容を編集してください。**Prompt**(プロンプト)、**Negative prompt**(ネガティブプロンプト)、画像にキャラクタープロンプトがあった場合は**Character prompts**(キャラクタープロンプト)内のキャラクターごとの欄、画像モデルを変更できます。
4. **Generate image**(画像を生成)をクリックしてください。画像をそのままにする場合は、**Cancel**(キャンセル)をクリックしてください。

新しい画像がメッセージの選択中バージョンになります。以前の結果はバージョン数付きの同じGalleryタイルにまとまり、各版がプロンプト、ネガティブプロンプトなどの保存情報を保持します。現在のアバターに続き、元の生成で使ったロアブック項目の画像も再送します。Stability AI、Arli AI、SD Web UI、Draw Thingsに項目画像は送りません。古い画像でネガティブプロンプトやキャラクター別プロンプトが保存されていない場合は、エディターが知らせます。

<a id="image-versions"></a>
### 画像のバージョン

重なった画像を開いて版を選びます。Galleryでは左右の操作、矢印キー、横スワイプでタイルを移動します。メッセージから開くと同じ画像のスタック内に留まります。上下の操作、矢印キー、画像上の縦スワイプで版を切り替えます。移動前にズームアウトしてください。プロンプトのスクロールでは版は変わりません。

画像、プロンプト見出し、折りたたみボタンをクリックすると上下キーが版の切り替えになります。文章やコピーボタンをクリックするとスクロールになります。再生成や編集時も操作は表示されます。版を変える前にマスクを適用または消去してください。生成中は操作が停止します。

選んだ版は保存され、再読み込み後もチャットに表示されます。古い版から再生成・編集すると同じスタックに追加し、後の版も残します。分岐したチャットは独自の選択を保持します。

**生成した画像をキャラクターのギャラリーに自動保存**が有効なら、再生成・編集も元のキャラクターとペルソナのギャラリーを保存先にします。そこでも版をまとめ、各ギャラリーの選択はチャットと独立します。項目は保存画像を共有し追加コピーは作りません。元の項目がソースチャットにリンクしていれば、ギャラリーを開くと古いスタックの欠けた版も復元します。すでにまとめたギャラリーで削除した版は戻りません。

チャットのGalleryでは、タイルの**ギャラリーの画像を削除**かビューアーの削除ボタンで選びます。

- **Delete this version**は表示中の版を削除します。選択中なら残る最新の版を表示します。
- **Delete other versions**は表示中だけを残します。
- **Delete entire stack**は全バージョンと画像添付をチャットから削除します。

保存した版は完全に削除されます。**キャンセル**ならすべて残します。
