# キャラクターライブラリーの整理

右側のライブラリーにある**Characters**(キャラクター)ページには、作成またはインポートしたすべてのキャラクターが並びます。ここでは、検索と並べ替え、フォルダーへのグループ分け、お気に入りの登録、タグでの絞り込み、そして複数のキャラクターのまとめてのエクスポートや削除ができます。

## Charactersページ

**Library → Characters**(ライブラリー → キャラクター)を開きます。ページには、キャラクターがポートレートのカードとして表示されます。上部には次の項目があります。

- **Browse online**(オンラインで探す)をクリックすると[Card Browser](bot-browser.md)が開き、公開サイトでキャラクターを探せます。
- **Import**(インポート)では、キャラクターファイルを取り込みます。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。
- **New character**(新しいキャラクター)をクリックすると、空の状態またはテンプレートから**Create Character**(キャラクターの作成)ウィンドウが開きます。グリッドにある**New character**カードでも同じ操作ができます。
- **Search characters or tag:name**(キャラクターまたはtag:nameを検索)でカードを絞り込めます([検索](#search)を参照)。
- 検索ボックスの隣にある**Tags**(タグ)では、選んだタグでカードを絞り込めます([タグ](#tags)を参照)。
- **Favourites**(お気に入り)と**Recently edited**(最近編集したもの)でカードを絞り込めます。スマートフォンでは、これらは1つの**Filter**(フィルター)一覧にまとまっています。
- 並べ替えメニューには、**A to Z**(AからZ)、**Z to A**(ZからA)、**Newest**(新しい順)、**Oldest**(古い順)、**My order**(自分の並び順)があります。
- 3つのサイズボタンで、カードを小、中、大に切り替えられます。
- **New folder**(新しいフォルダー、フォルダーのアイコン)と**Select**(選択、チェックのアイコン)は、ページタイトルの隣にあります。

カードをクリックすると、キャラクターが開きます。カードの**Chat**(チャット)ボタンをクリックすると、そのキャラクターとのチャットが始まります。キャラクターが多い場合は、下部の**Load more**(さらに読み込む)をクリックします。

### カードの操作

カードにカーソルを合わせて左上の**⋯**をクリックするか、カードを右クリックします。タッチ画面では、カードを長押しします。メニューには次の項目があります。

- **Duplicate**(複製)は、キャラクターのコピーを作ります。
- **Move to folder**(フォルダーに移動)は、キャラクターをフォルダーに入れます。**No folder**(フォルダーなし)を選ぶと、フォルダーから出せます。
- **Export**(エクスポート)は、キャラクターをMarinaraのネイティブ形式でダウンロードします。
- **Select**(選択)は、このカードを選択した状態で選択モードを始めます。
- **Delete**(削除)は、確認後にキャラクターを削除します。

### 自分で決める順番

カードをドラッグして、別のカードの前か後ろにドロップします。並べ替えメニューが**My order**(自分の並び順)に切り替わり、別の並べ替えを選ぶまでその順番が保たれます。元に戻るには、もう一度**My order**を選びます。クラシックパネルの**Manual order**と同じ順番です。

### フォルダー

1. ページタイトルの隣にある**New folder**(新しいフォルダー)をクリックします。**unnamed**という名前のフォルダーがカードの上に表示されます。
2. 名前を変えるには、フォルダーの**⋯**をクリックし、**Rename**(名前を変更)を選びます。
3. カードをフォルダーへドラッグするか、カードのメニューにある**Move to folder**を使います。

フォルダーの名前をクリックすると、折りたたんだり展開したりできます。名前の隣の数字は、中に入っているキャラクターの数です。フォルダーの**⋯**メニューにある**Delete folder**(フォルダーを削除)は、フォルダーだけを削除します。中のキャラクターはページに戻ります。

### 複数のキャラクターのエクスポートと削除

1. ページタイトルの隣にある**Select**(選択)をクリックします。各カードにチェックボックスが表示されます。
2. 対象のカードをクリックします。画面下部のバーに選択数と**Select all**(すべて選択)が表示されます。
3. バーで**Move to folder**、**Export**、**Delete**のいずれかを選びます。

**Export**は、`marinara-characters.zip`という1つのzipファイルをダウンロードします。**Delete**は、最初に確認を求めます。選択モードを終えるには、バーの**X**をクリックするか<kbd>Esc</kbd>を押します。

**Favorites first**(お気に入りを先頭に)の並べ替えと、すべてのキャラクターからタグを削除する操作は、以下で説明するクラシックレイアウトのCharactersパネルにあります。**Settings → Appearance → Theme**(設定 → 外観 → テーマ)の**New layout**(新しいレイアウト(UI刷新のプレビュー))でクラシックレイアウトに切り替え、同じ方法で元に戻せます。

## クラシックレイアウトのCharactersパネル

パネル上部からは次の操作ができます。

- **Download**(ダウンロード)をクリックすると[Card Browser](bot-browser.md)が開き、公開サイトでキャラクターを探せます。
- **Open Library**(ライブラリーを開く)をクリックすると、同じキャラクターをページ全体の大きなグリッドで開きます。
- **New**(新規作成)ボタン(プラスのアイコン)をクリックすると、**Create Character**(キャラクターの作成)ウィンドウが開きます。
- **Import**(インポート)ボタン(ダウンロードのアイコン)をクリックすると、キャラクターのファイルをインポートできます。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。
- **Select**(選択)ボタン(チェックのアイコン)をクリックすると、まとめて操作するための選択モードがオンになります。

キャラクターを開いて編集し、戻ってきたときも、ライブラリー全体の表示では選択中のカード、並び順、スクロール位置がそのまま保たれます。

各行には、アバター、名前、任意のタイトル行、作成者とバージョン、最大3つのタグ、おおよそのトークン数が表示されます。お気に入りには小さな星のバッジが付きます。行にカーソルを合わせると、**Duplicate**(複製)と**Delete**(削除)が表示されます。キャラクターが多いときは、下部の**Load more**(さらに読み込む)をクリックすると次のページを読み込みます。

## 検索

上部の検索ボックスに入力します。プレースホルダーは**Search characters or tag:name**(キャラクターまたはtag:nameを検索)です(クラシックレイアウトでは**Search characters/tags**(キャラクター/タグを検索))。ふつうの文字列は、大文字と小文字を区別せずに、キャラクターの名前、タイトル、説明、タグと照合されます。`knight`と入力すると、これらのどれかに「knight」を含むキャラクターがすべて表示されます。

| 検索 | 見つかるもの |
| --- | --- |
| `male genshin`または`male,genshin` | 両方のタグと完全一致するカード。 |
| `male "Modern AU"` | スペースやカンマを含むタグは引用符で囲みます。 |
| `-tag:"slow burn"` | 検索のほかの部分が一致していても、そのタグを持つカードをすべて隠します。 |
| `-vampire` | 1語のタグの場合も同じです。引用符は省略できます。 |
| `mage -tag:"villain"` | 「mage」に一致するカードのうち、「villain」のタグが付いたものを除いたもの。 |

通常のフレーズ検索もそのまま使えます。同じ検索は、ページ全体のCharacter Libraryでも、ペルソナでも使えます。

## 並べ替え(クラシックレイアウト)

クラシックパネルの並べ替えのドロップダウンには、次の項目があります。

| 選択肢 | 動作 |
| --- | --- |
| **Manual order** | 自分で決めた順に並べます。 |
| **A-Z** | 名前をAからZの順に並べます。 |
| **Z-A** | 名前をZからAの順に並べます。 |
| **Newest** | 作成日が新しいものから並べます。 |
| **Oldest** | 作成日が古いものから並べます。 |
| **Favorites** | お気に入りを先に、残りをその後に並べます。 |

手動で順番を決めるには、行を上下にドラッグするか、行にフォーカスを合わせて<kbd>Alt</kbd>+<kbd>Up</kbd>または<kbd>Alt</kbd>+<kbd>Down</kbd>を押します。どちらの操作でも、並べ替えは**Manual order**(手動の順番)に切り替わります。

## フォルダー(クラシックレイアウト)

フォルダーを使うと、物語やシリーズごとなど、関連するキャラクターをまとめられるので、長い一覧を見渡しやすくなります。使うかどうかは自由で、新しいレイアウトにも同じフォルダーが表示されます。

1. **New Folder**(新しいフォルダー)をクリックします。**unnamed**という名前のフォルダーが表示されます。
2. 名前を変えます。ダブルクリックするか、ダブルタップするか、選択してから<kbd>F2</kbd>を押します。新しい名前を入力して<kbd>Enter</kbd>を押します。
3. キャラクターの行をフォルダーの上へドラッグすると、フォルダーに入ります。フォルダーが1つでもあると、**Drag and drop characters to folders, double-click or double-tap to rename**という補助テキストが表示されます。

キャラクターをフォルダーから出すには、フォルダー内でその行にカーソルを合わせてフォルダーから外すボタンをクリックするか、外へドラッグします。フォルダーをクリックすると開閉できます。名前の隣の数字は、中に入っているキャラクターの数です。

タッチスクリーンでは、行を長押しして持ち上げてから、ドラッグします。普通にスワイプすれば、これまでどおりスクロールします。

複数をまとめて動かすには、1つの行を押さえたまま、別の指でほかの行をタップします。それらが重なっていっしょに運ばれます。そのあと、重ねた行をフォルダーの上で離します。

フォルダーを削除するには、フォルダーにカーソルを合わせてゴミ箱ボタンをクリックします。キャラクターが入っているフォルダーでは、確認を求められます: **Delete "name"? Its N characters will stay in the library and move out of the folder.**空のフォルダーはすぐに削除されます。フォルダーを削除しても、中のキャラクターが削除されることはありません。

## フォルダーをグループチャットの名簿として使う

各フォルダーは、グループチャット用の保存済みの名簿でもあります。複数のキャラクターでチャットを設定するとき、**Add from Folder**(フォルダーから追加)を使うと、フォルダー内のキャラクターを1回の操作ですべて追加できます。[グループチャットとグループでの会話](../chats/group-chats.md)を参照してください。

## お気に入りとタグ

### お気に入り

キャラクターを開き、**Favorite**(お気に入り)の星をクリックしてオンとオフを切り替えます。Charactersページでは、**Favourites**(お気に入り)チップを使うとお気に入りだけが表示されます。クラシックパネルでは、お気に入りに小さな星のバッジが付き、検索ボックスの下にある3つのボタンで一覧を絞り込めます。

- **All**はすべてのキャラクターを表示します。
- **Favs**はお気に入りだけを表示します。
- **Non-favs**はお気に入り以外のキャラクターだけを表示します。

並べ替えのドロップダウンで**Favorites**を選び、お気に入りを先頭に並べることもできます。

### タグ

タグは、`fantasy`や`slow burn`のようなラベルです。キャラクターエディターで追加します。[キャラクターの作成と編集](creating-and-editing-characters.md#metadata-tab)を参照してください。インポートすると、**Imported**(インポート済み)と、**ST**や**CharX**などカードの提供元を示すタグが追加されます。[インポートの設定](import-export.md#import-options)を参照してください。

Charactersページでタグを使って絞り込む手順は次のとおりです。

1. 検索ボックスの隣にある**Tags**(タグ)をクリックします。すべてのタグと、それぞれが付いているキャラクターの数の一覧が開きます。
2. **Search tags**(タグを検索)に入力して探し、使いたいタグをクリックします。複数選ぶと、その**すべて**が付いているキャラクターだけが表示されます。**Untagged**(タグなし)では、タグのないキャラクターを表示します。
3. **Tags**ボタンには、選んだ数が表示されます。一覧の**Clear**(クリア)をクリックすると、選択を解除します。

**Personas**(ペルソナ)ページと**Lorebooks**(ロアブック)ページにも同じ**Tags**ボタンがあり、**Presets**(プリセット)にもあります。どのページでも、引き続き検索ボックスに`tag:name`を入力して絞り込めます。

クラシックパネルでは、キャラクターにタグが付いていると、件数付きの**Tags**(タグ)ボタンが表示されます(例: **Tags (12)**)。クリックすると、タグの一覧全体が展開します。

- タグをクリックすると、絞り込み条件に加わります。複数のタグを選んだ場合は、そのいずれかを持つキャラクターが一致します。
- タグのXをクリックすると、そのタグが付いたすべてのキャラクターからタグを削除します。確認を求められます: **Remove tag "name" from all characters?**
- タグの絞り込みが有効になると、**Clear**(クリア)が表示されます。クリックすると、タグの絞り込みを解除します。

タグを除外したいときは、[検索](#search)で示したように、検索ボックスで`-tag:`を使います。

## 複数のキャラクターのエクスポートと削除(クラシックレイアウト)

1. パネル上部の**Select**(選択)をクリックします。各行にチェックボックスが表示されます。
2. 対象のキャラクターをクリックします。選択した数はパネルのヘッダーに表示されます。
3. 下部の操作バーを使います。

操作バーには2つのボタンがあります。

- **Export**(エクスポート)は、選択したキャラクターをMarinaraのネイティブ形式で、`marinara-characters.zip`という1つのzipファイルとしてダウンロードします。
- **Delete**(削除)は、選択したキャラクターを削除します。最初に確認を求められます: **Delete N characters?**

選択モードでは、選んだキャラクターをまとめてフォルダーへドラッグすることもできます。ファイル形式については、[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。
