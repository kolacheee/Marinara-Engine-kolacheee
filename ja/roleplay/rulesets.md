# Roleplay: ルールセットで遊ぶ

Roleplayのチャットは、Game Modeで使うのと同じ種類の卓上ルールセットで遊べます。不確かなことが起きるとナレーターが判定を求め、Marinaraがキャラクターのシートからダイスを振り、返信がそのロールで何が決まったかを伝えます。Game Modeのゲームを始めずに、roleplayで本物のダイスとキャラクターシートを使いたいときに使います。

Game Mode用にインストールしたルールセットなら、5e (SRD 5.1)など何でも使えます。キャラクターエディターとペルソナエディターでそのルールセット用にすでに作ったシートも使えます。

## チャットでルールセットをオンにする

始める前に: ルールセットをインストールしてください。[ルールセットを入手する](../game/rulesets.md#get-a-ruleset)を参照してください。

1. Roleplayのチャットを開きます。
2. **Chat Settings**(チャット設定)を開き、**Ruleset**(ルールセット)セクションを探します。
3. 一覧からルールセットを選びます。インストール済みのルールセットが並びます。
4. Marinaraがチャットの各メンバーにシートを渡し、追加した数を伝えます。各メンバーはルールセットの下に表示されます。

各メンバーは、キャラクターエディターまたはペルソナエディターにある、そのルールセット用の自分のシートのコピーを受け取ります([ルールセットのシート](../characters/colors-and-stats.md#ruleset-sheets)を参照)。シートがないメンバーには、一覧で**blank sheet**(空のシート)と表示される空のシートが渡され、チャット内で作ります。ペルソナが最初に来ます。チャット内の変更はチャット内にとどまり、キャラクターやペルソナには決して戻りません。

うまくいかなかった場合: インポートしたルールセットでは**Allow custom Agent imports**(カスタムエージェントのインポートを許可)をオンにする必要があります。[ルールセットを入手する](../game/rulesets.md#get-a-ruleset)を参照してください。

### 空のシートを作る

1. **Ruleset**セクションで、メンバーの横にある**Build sheet**(シートを作成)をクリックします。
2. キャラクターシートがシートエディターで開きます。ルールセットにガイド付きビルダーがある場合は、Game Modeやキャラクターエディターと同じく、まずそこで開きます。
3. 選択を済ませ、**Save sheet**(シートを保存)をクリックします。

### 新しいメンバーのシートを追加する

あとからキャラクターがチャットに加わったら、**Add missing sheets**(足りないシートを追加)をクリックします。すでにシートがあるメンバーはそのままです。

### シートを削除する

ナレーター用のカードなど、シートを持つべきでないメンバーからはシートを外せます。

1. **Ruleset**セクションで、メンバーの横にあるごみ箱のアイコンをクリックします。
2. **Remove sheet**(シートを削除)をクリックします。

チャットはこれを覚えるので、**Add missing sheets**や新しいバージョンのルールセットでも、そのメンバーは対象から外れます。もう一度シートを与えるには、**No sheet:**(シートなし)のあとにあるそのメンバーのボタン(例: **Give Mira a sheet**、Miraにシートを与える)をクリックします。

### ルールセットを切り替える、またはオフにする

- **None**(なし)を選ぶと、ルールセットでのプレイをやめます。シートは残るので、同じルールセットをもう一度選べば、やめたところから続きます。
- 別のルールセットを選ぶと、すべてのシートが最初からになります。あるルールセット用のシートは、別のルールセットでは意味を持たないからです。

## プレイ中の判定

ターンはいつもどおり書きます。結果が重要な不確かな行動をキャラクターが試みると、ナレーターは結果を決める代わりに判定を書きます。Marinaraがシートからそれを振り、そのあとナレーターがロールで何が決まったかを書きます。

完成したメッセージには、判定があった場所にダイスカードが表示され、スキル、難易度、ダイス、そして**Success**(成功)または**Failure**(失敗)が並びます。本当には失敗しない普通の行動には判定が付きません。

> **Tip:** モデルによっては判定を求める指示を無視し、結果を自分で決めてしまいます。判定がまったく出ないときは、チャットの**Connection**(接続)にもっと強いモデルを試してください。

**Impersonate**(なりきり)のターンでは判定を振りません。マルチプレイヤーのルームではルールセットで遊べません。

## キャラクターシートを使う

**Ruleset**セクションでメンバーの横にある**Open sheet**(シートを開く)をクリックします。シートはGame Modeが表示するものと同じです。Tracker Panelの上部にある巻物のボタンで、ペルソナのシートが開きます。

- ヒットポイントやストレスなどのプールやトラックの横にある**−**と**+**をクリックすると、値を変えられます。変更は現在のメッセージとともに保存されるので、スワイプやブランチにもついてきます。
- **Edit ruleset sheet**(ルールセットのシートを編集)をクリックしてスコア、スキルのランク、欄、一覧を変更し、**Save sheet**(シートを保存)をクリックします。

ナレーターは毎ターン、シートを読み、返信の中でシートのコマンドを使ってシートを変えます。コマンドはMarinaraが適用し、メッセージからは隠します。休息を取るときは、ターンで「長休憩を取ります」のように伝えます。ナレーターが休息を記録し、シートはルールセットの休息が回復するものを取り戻します。シートの**Rest**(休息)をクリックすることもできます。

## 自分のルールセットを作る

ルールセットビルダーでは、フォームから小さなルールセットを作れます。判定の振り方、シートに載せる内容、ナレーターに伝える内容を設定します。Marinaraにないシステムで遊びたいときに使ってください。作ったルールセットは、インストールしたものと同じように、RoleplayでもGame Modeでも使えます。

始める前に: ビルダーはインポートと同じ方法でルールセットを保存するため、**Allow custom Agent imports**(カスタムエージェントのインポートを許可)をオンにしてください。[ルールセットを入手する](../game/rulesets.md#get-a-ruleset)を参照してください。

1. **Chat Settings → Ruleset**(チャット設定 → ルールセット)で、**New ruleset…**(新しいルールセット…)をクリックします。
2. **Name**(名前)を入力します。
3. **Dice**(ダイス)で、判定の振り方を選びます(下の表を参照)。選ぶと能力値、プール、トラックの初期設定が入り、変更できます。
4. **Difficulties**(難易度)、**Stats**(能力値)、**Skills**(スキル)など、フォームの各項目を変更します。ほとんどのセクションには、タイトルの下に短い説明があります。
5. **Create ruleset**(ルールセットを作成)をクリックします。

Marinaraがルールセットを保存します。ルールセットのないチャットでは、新しいルールセットもオンになります。すでにルールセットがあるチャットは、現在のルールセットとシートを保持します。切り替えるには、一覧で新しいルールセットを選んでください。

選んだ振り方のルールセットがすでにインストールされている場合は、**Dice**セクションにその名前が表示されます。キャラクターのシートはルールセットごとに別々なので、1人につき1枚に保ちたい場合は、新しく作らずに既存のルールセットを使うか編集してください。

| ダイス | 判定の振り方 |
| --- | --- |
| **d20 + modifier**(d20 + 修正値) | d20に能力値とスキルを足し、難易度の数値と比較します。 |
| **2d6 bands**(2d6の結果帯) | 2d6に能力値を足します。10以上は大成功、7から9は部分的成功、6以下は失敗です。 |
| **Dice pool**(ダイスプール) | 能力値とスキルの合計1ポイントにつきダイスを1個振り、目標値に達したダイスを数えます。d6かd10と、目標値を選びます。 |
| **Highest d6**(d6の最大出目) | 1ポイントにつきd6を1個振り、最も高い出目を使います。6は完全成功、4か5は部分的成功、6が2個ならクリティカルです。 |
| **Percentile**(パーセンタイル) | d100を振ります。出目がスキルの数値以下なら成功です。 |
| **Hope and Fear**(希望と恐怖) | d12を2個振って能力値を足します。どちらの出目が高いかで、結果に希望と恐怖のどちらが伴うかが決まります。 |
| **No dice**(ダイスなし) | ダイスは振りません。能力値とスキルを足し、難易度と比較します。 |

### 作ったルールセットを変更する

1. チャットでルールセットをオンにします。
2. **Chat Settings → Ruleset**(チャット設定 → ルールセット)で、**Edit ruleset**(ルールセットを編集)をクリックします。
3. 変更して、**Save new version**(新しいバージョンを保存)をクリックします。

チャットは新しいバージョンに移り、すべてのシートを保持します。能力値、スキル、プール、リストの列の名前を変えても、各キャラクターの内容は残ります。同じルールセットを使う別のチャットでは、そのチャットで**Add missing sheets**(足りないシートを追加)をクリックすると新しいバージョンに移ります。

**Edit ruleset**は、自分で作ったルールセットやファイルからインポートしたルールセットのうち、フォームですべてを扱えるものに表示されます。ビルダーで作ったものや、フォームにある項目だけを使う手書きのファイルが対象です。パッケージやリポジトリーから入れたルールセットには表示されません。戦闘ルールやコメントなど、それ以外の内容があるルールセットはビルダーで開かないため、表示できない内容が失われることはありません。また、最新バージョンで遊んでいるチャットにだけ表示されます。古いバージョンのチャットでは、先に**Add missing sheets**をクリックしてください。

### シートの配置

| フォームの項目 | シートでの表示 |
| --- | --- |
| 行の順序 | 能力値、スキル、プール、トラック、項目、リストのタブは、フォームの順に表示されます。行の持ち手をドラッグするか、持ち手にフォーカスして上下の矢印キーを押すと移動できます。 |
| 能力値やスキルの**Group**(グループ) | 同じグループの能力値やスキルは、1つの見出しの下に表示されます。 |
| **Skill ranks**(スキルランク) | シートで各スキルに選ぶランクと、そのランクが加える値です。d20や2d6では合計値、プールではダイス数、パーセンタイルではポイントに加算します。 |
| **シートのランク表示形式** | 習得した技能とセーヴの横に表示する内容：**判定値 (+2)**、**ランク名**、**点 (●●○)**、**ローマ数字 (II)**、**ランク番号 (2)**。判定とナレーター用のシートは変わりません。 |
| **Practice meter**(熟練度メーター) | 習得済みの各スキルに、次のランクまでの進み具合を0から99%で表示します。物語の中で練習すると上がり、ランクが上がるとリセットされます。シート上で修正できます。**No meter for:**(メーターを付けないスキル:)でグループにチェックを入れると、そのスキルを対象から外せます。 |
| プールやトラックの**Number**(数値)、**Bar**(バー)、**Dots**(点) | 数値だけ、数値とゲージ、または1ポイントにつき1個の点を値の分だけ塗った列を表示します。20個を超える点はバーで表示します。 |
| **Lists**(リスト) | リストごとにタブができます。別のタブ名を入力しなければ、リスト名が使われます。同じタブ名のリストは、1つのタブを共有します。 |
| リストの列 | 各行には名前と、追加した列(**Text**(テキスト)、**Number**(数値)、**Checkbox**(チェックボックス))があります。最初のチェックボックス列は、名前の横のチェックとして表示されます。 |

### ナレーターにルールを伝える

**Prompts**(プロンプト)セクションには、ルールセットについてナレーターに伝える内容を入れます。**Checks**(判定)と**Keeping the sheets**(シートの管理)にはデフォルトが表示され、空欄にするとその内容を使います。改行はスペースになります。名前とプロンプトには角括弧や二重の波括弧を含められません。ナレーターのタグやマクロで使うためです。

| 欄 | 用途 |
| --- | --- |
| **Checks** | 判定を求めるタイミングと、スキルや難易度の選び方です。 |
| **Keeping the sheets** | プレイ中にシートをどう変えるかです。 |
| **Rules reference**(ルール参照) | ハウスルールなど、ナレーターが常に参照できるようにしておく内容です。 |
| **World (Game Mode)**(世界(ゲームモード)) | ルールに合った世界にするため、そのルールセットでGame Modeのゲームを作るときに1度だけ読みます。 |

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| **This chat's ruleset is not installed here, so its checks and sheets are paused.** | ルールセットを入れ直すか、別のものを選んでください。 |
| ナレーターが判定をまったく求めない。 | チャットにもっと強いモデルを使ってください。判定の指示を飛ばすモデルがあります。 |
| 新しいキャラクターにシートがない。 | **Add missing sheets**をクリックしてください。 |
