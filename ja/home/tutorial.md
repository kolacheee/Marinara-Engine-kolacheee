# 初回チュートリアル

チュートリアルは、Marinara Engineを初めて開いたときに始まるガイドツアーです。アプリに内蔵されたアシスタントのProfessor Mariが、アプリの主要な場所を案内します。ツアーをスキップしたり、もう一度見たり、各ステップの内容を確かめたりするときは、このガイドを参照してください。

## チュートリアルをもう一度見る

1. **Settings → General → Confirmations & Help**(設定 → 一般 → 確認とヘルプ)を開きます。
2. **Walkthroughs**(ウォークスルー)にある**Replay the welcome tour**(ようこそツアーをもう一度表示)をクリックします。

ホームの**Things to try**(試してみよう)ウィジェットで**See all**(すべて見る)を開き、**Replay tutorial**(チュートリアルをもう一度)をクリックすることもできます。ツアーが最初のステップからもう一度始まります。

**Walkthroughs**には、ほかにも2つのボタンがあります。**Replay the computer walkthrough**(コンピューターのウォークスルーをもう一度表示)(端末によってはタブレットまたはスマートフォン)では、今使っている端末の種類に合わせた短いツアーをもう一度見られます。**Show chat mode tips again**(チャットモードのヒントをもう一度表示)では、各チャットモードのヒントが再び表示されるようになります。[端末ごとのウォークスルー](#walkthroughs-for-each-device)を参照してください。

## チュートリアルをスキップする

どのカードにもスキップ用のボタンがあります。最初のカードでは**Skip Tutorial**(チュートリアルをスキップ)と表示されます。それ以降のカードでは**Skip**(スキップ)と表示されます。クリックすると、ツアーはその場で終了します。

- **Skip**、**Skip Tutorial**、最後のカードのボタンのどれをクリックしても、ツアーは完了として記録されるので、次からは自動的に始まりません。これらの操作で**Diligent Student**(勤勉な生徒)の実績が解除されることもあります。
- 最後のカードには、アプリ内ガイドの言語を選ぶ一覧があります。選んだ言語が保存されるのは、最後のカードのボタンをクリックした場合だけです。**Skip**では元のままになります。言語は後から**Settings → General → Language → Documentation Language**(設定 → 一般 → 言語 → ドキュメントの言語)で変更できます。

## ツアーのしくみ

ツアーはホームで始まり、カードを1枚ずつ表示します。各カードには、タイトル、短い説明、進み具合を示すドットがあります。リングが、カードで説明している画面の部分を強調し、一部のステップではその部分も自動的に開きます。Libraryのステップではサイドバーの**Library**(ライブラリー)表示が開き(コンピューターではキャラクターページも開きます)、Chatsのステップでは**Chats**(チャット)に切り替わり、Connectionsのステップでは接続ページが開きます。

次のカードへ進むには**Next**(次へ)をクリックします。スマートフォンやタブレットでもカードと強調表示は同じように動作し、タッチ画面で各機能がどこにあるかを説明します。

## リファレンス: ステップ

| # | カードのタイトル | 内容 |
| --- | --- | --- |
| 1 | **Welcome to Marinara Engine!**(Marinara Engineへようこそ!) | Professor Mariが案内を申し出ます。 |
| 2 | **The Library**(ライブラリー) | 右側のサイドバーと、その**Library**表示です。Characters、Personas、Lorebooks、Presets、Regex scriptsが入っています。上部バーの**Library**ボタンで表示と非表示を切り替えます。 |
| 3 | **Your Chats**(チャット) | 同じサイドバーの**Chats**表示と、チャット内の**Chat settings**(チャット設定)です。 |
| 4 | **Three Ways to Chat**(3つのチャット方法) | **Convo**、**Roleplay**、**Game**のタブと、各モードの用途です。 |
| 5 | **Connections: Set This Up First**(接続: 最初に設定しましょう) | 接続ページを開きます。チャットを始める前に接続を追加してください。 |
| 6 | **Agents**(エージェント) | エージェントのページを開きます。ここで任意の機能をインストールできます。 |
| 7 | **Settings (and SillyTavern Imports)**(設定(SillyTavernからのインポートも)) | **Settings**(設定)の**Data**(データ)タブを開きます。ここからSillyTavernのデータをインポートできます。 |
| 8 | **Tabs and Search**(タブと検索) | 上部バーのタブと、検索ボタン(<kbd>Ctrl</kbd>+<kbd>K</kbd>)です。 |
| 9 | **The Docs, and You're Set!**(ドキュメントを確認したら準備完了!) | **Docs**(ドキュメント)ボタンと、ガイドの言語一覧です。 |

スマートフォンやタブレットでは、ツアーに**Handy Gestures**(便利なジェスチャー)のカードが加わり、全部で10ステップになります。Libraryは右上の重なったボタンの中、Chatsは同じページの上部、検索はタイトルの中、DocsはLibraryの中にあります。

## 端末ごとのウォークスルー

Marinaraをある種類の端末(コンピューター、タブレット、スマートフォン)で初めて開くと、別の場所で一通りのツアーを終えていても、その端末向けの短いウォークスルーが始まります。その端末でチャット、Library、検索がどこにあるかを示し、タッチ画面では**Handy Gestures**のカードも表示します。各チャットモードでも、その端末で初めて開いたときに専用のヒントが表示されます。**Settings → General → Confirmations & Help → Walkthroughs**(設定 → 一般 → 確認とヘルプ → ウォークスルー)からもう一度見られます。
