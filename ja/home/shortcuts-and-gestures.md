# キーボードショートカットとタッチ操作

Marinaraはコンピューターのキーや、スマートフォン・タブレットのスワイプと引っ張り操作に対応します。ここにすべてを示します。同じ一覧は**設定 › ショートカット**にもあり、入力中でなければどこでも<kbd>?</kbd>で開けます。

Macでは、特記がない限り<kbd>Ctrl</kbd>は<kbd>⌘</kbd>、<kbd>Alt</kbd>は<kbd>⌥</kbd>（Option）です。

<a id="going-back-and-forward"></a>
## 戻る・進む

Marinaraはブラウザーのように、チャット、キャラクター、ロアブック、プリセット、Library、Docs、Professor Mari、Homeの訪問履歴を覚え、戻る・進むができます。

- **コンピューター：** 左上ロゴ横の**←**と**→**、<kbd>Alt</kbd>+<kbd>←</kbd>と<kbd>Alt</kbd>+<kbd>→</kbd>（Macは<kbd>⌘</kbd>+<kbd>[</kbd>と<kbd>⌘</kbd>+<kbd>]</kbd>）、またはマウス側面のボタンを使います。
- **スマートフォン・タブレット：** 左端からスワイプするか、ブラウザー・Androidの戻るを使います。メニュー、シート、チャット設定、エディター、Libraryページ、Homeの順に最上位を閉じます。

補足：

- 戻ってから新しいページを開くと、進む側の履歴は消えます。
- タブを閉じたページは飛ばします。
- 戻る先がなければ矢印は灰色になり、キーとマウスは通常のブラウザー操作になります。
- 未保存の変更はタブに残ります（[タブ、分割表示、未保存の変更](tabs-and-drafts.md)を参照）。

<a id="keyboard-shortcuts"></a>
## キーボードショートカット

<a id="moving-around"></a>
### 移動

コンピューターか、キーボード付きの横向きタブレットで使えます。

| ショートカット | 動作 |
| ----------------------------------------------------------------------------------- | ------------------------------------- |
| <kbd>Alt</kbd>+<kbd>←</kbd>、またはマウスの戻るボタン                             | 前のページへ戻る |
| <kbd>Alt</kbd>+<kbd>→</kbd>、またはマウスの進むボタン                          | 戻った後に進む |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>←</kbd> または <kbd>Alt</kbd>+<kbd>Page Up</kbd>   | 前のタブ |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>→</kbd> または <kbd>Alt</kbd>+<kbd>Page Down</kbd> | 次のタブ |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd> ～ <kbd>8</kbd>                        | 左から数えたタブへ移動 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>9</kbd>                                        | 最後のタブへ |
| <kbd>Alt</kbd>+<kbd>W</kbd>                                                         | 表示中のタブを閉じる |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd>                                       | 最後に閉じたタブを開く |

ブラウザーが<kbd>Ctrl</kbd>+<kbd>Tab</kbd>、<kbd>Ctrl</kbd>+<kbd>W</kbd>、<kbd>Ctrl</kbd>+<kbd>1</kbd>～<kbd>9</kbd>を使うため、タブ操作は<kbd>Alt</kbd>+<kbd>Shift</kbd>です。LinuxのChromeとFirefoxは<kbd>Alt</kbd>+<kbd>1</kbd>～<kbd>9</kbd>も使います。<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd>がMarinaraへ届くのはFirefoxかインストール版のみで、ほかではタブの右クリックから**閉じたタブを開き直す**を使います。

<a id="everywhere"></a>
### どこでも

| ショートカット | 動作 |
| ------------------------------------------ | ------------------------------------------------------------------------------ |
| <kbd>Ctrl</kbd>+<kbd>K</kbd>               | Searchを開く・閉じる |
| <kbd>Ctrl</kbd>+<kbd>J</kbd>               | Professor Mariを開く（Windows・Linux、入力中以外） |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Enter</kbd> | 検索結果を移動・開く |
| <kbd>Tab</kbd>                             | 検索の補完候補を確定 |
| <kbd>Alt</kbd>+<kbd>M</kbd>                | メッセージ欄のモデル選択 |
| <kbd>?</kbd>                               | **設定 › ショートカット**を開く（入力中以外） |
| <kbd>Esc</kbd>                             | メニュー、ポップオーバー、ダイアログを閉じる |

<a id="message-box"></a>
### メッセージ欄

| ショートカット | 動作 |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| <kbd>Enter</kbd>                                                   | 送信（モードのSend on Enterがオン） |
| <kbd>Shift</kbd>+<kbd>Enter</kbd>                                  | Enter送信時に改行 |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd>                                   | Send on Enterがオフのとき送信 |
| <kbd>↑</kbd>                                                       | 空欄から最後の自分の発言を編集（**上矢印キーで最後のメッセージを編集**が必要） |
| <kbd>↑</kbd> <kbd>↓</kbd>, then <kbd>Tab</kbd> または <kbd>Enter</kbd> | /コマンド、@メンション、:emoji:候補の移動と確定 |

<a id="messages"></a>
### メッセージ

| ショートカット | 動作 |
| -------------------------------- | ----------------------------------------------------------------------------------- |
| <kbd>←</kbd> <kbd>→</kbd>        | 最新発言の前・次の返信（**直感的なスワイプ操作**が必要） |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | メッセージ編集を保存 |
| <kbd>Esc</kbd>                   | 編集を取り消す |
| <kbd>Enter</kbd>                 | 最初のメッセージ検索結果へ |

<a id="editors"></a>
### エディター

| ショートカット | 動作 |
| -------------------------------------------------------- | ---------------------------------------------------------------------- |
| <kbd>Ctrl</kbd>+<kbd>S</kbd>                             | 開いているエディターを保存 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd>         | プロンプト・ファイル編集の字下げを増減 |
| <kbd>Esc</kbd>, then <kbd>Tab</kbd>                      | プロンプト欄を離れる |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> / <kbd>Esc</kbd>            | Game Assetsで全選択・解除 |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>Home</kbd> <kbd>End</kbd> | ハンドルにフォーカス時、サイドバー・分割幅を調整 |

<a id="game-mode"></a>
### Game Mode

| ショートカット | 動作 |
| ------------------------------------------------------ | ------------------------------------ |
| <kbd>↑</kbd> <kbd>↓</kbd> または <kbd>W</kbd> <kbd>S</kbd> | 戦闘行動を選ぶ |
| <kbd>Enter</kbd> または <kbd>Space</kbd>                   | 強調された行動を確定 |

<a id="touch-gestures"></a>
## タッチ操作

| ジェスチャー | 動作 |
| ----------------------------------------- | --------------------------------------------------------------- |
| 左端から内側へスワイプ | 1段階戻る |
| トップバーのタイトルを左右へ | 次・前のタブ |
| トップバーを下へ引く | Search、またはMari側へ引くとProfessor Mari |
| Chats一覧の先頭から下へ引く | 他端末のチャットも含め一覧更新 |
| 最新返信を左右へスワイプ | 返信を切り替え（最後より先は生成前に確認） |
| チャット行を左へスワイプ | 固定、名前変更、タグ、削除 |
| メッセージ、行、タブを長押し | メニューを開く |

<a id="the-edge-swipe-in-the-home-screen-app"></a>
### ホーム画面アプリの端スワイプ

Safariでは左端スワイプはブラウザーの操作で、Marinaraは終了する代わりに1階層戻ります。**Share › Add to Home Screen**で追加したアプリには戻るスワイプがないため、Marinaraが丸い矢印を指に追従させ、十分引くと色を付けます。離すと戻り、端へ戻せば取り消します。右から左の言語では右端から操作します。

<a id="every-gesture-has-a-button"></a>
### すべての操作にボタンがあります

ジェスチャーは必須ではありません。

- **戻る：** ページ上の**‹**か**ホーム**。
- **タブ切り替え：** 右上のタブボタンで**すべてのタブ**。
- **検索：** トップバーの虫眼鏡。
- **チャット更新：** Chatsの**⋯**にある**一覧を更新**（コンピューターでは一覧上の円形矢印）。
- **返信：** 最新返信の**Reply 1 of 3**で別バージョン。
- **チャット操作：** 行を長押し。

<a id="turning-swipes-off"></a>
### スワイプをオフにする

**設定 › ショートカット › タッチジェスチャー**の**タッチ画面のスワイプ操作**をオフにすると、タイトル、返信、チャット行のスワイプを止め、横ドラッグはスクロールのみになります。端から戻る、下へ引く、長押しは使えます。
