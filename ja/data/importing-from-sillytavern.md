# SillyTavernからのインポート

SillyTavernのデータをMarinara Engineに取り込みます。ファイルを1つずつインポートすることも、SillyTavernのフォルダー全体をスキャンしてまとめて取り込むこともできます。

## 引き継げるもの

| SillyTavernのデータ | Marinaraでの扱い |
| --- | --- |
| キャラクター | キャラクター |
| チャットとグループチャット | チャット |
| Presets | Presets(プロンプトのセクションとプリセットのサンプラー設定) |
| World Info | ロアブック(特定の言葉が出てきたときにAIが読むメモ) |
| 背景 | チャットの背景 |
| ペルソナ | ペルソナ(自分の代わりになるプロフィール) |

## 単一ファイルの簡易インポート

1. **Settings → Data → SillyTavern Import**(設定 → データ → SillyTavernインポート)を開きます。
2. ファイルの種類に合うボタンをクリックします。
3. ファイルを選びます。

| ボタン | ファイル |
| --- | --- |
| **Import Character (JSON/PNG)** | `.json`または`.png`のキャラクターカード。 |
| **Import Chat (JSONL)** | `.jsonl`のチャット記録(1行に1件のJSONレコードを書く、SillyTavernがチャットを保存する形式)。 |
| **Import Preset (JSON)** | `.json`のプリセット。 |
| **Import Lorebook (JSON)** | `.json`のWorld Infoファイル。 |

ボタンの上の**Tag imported**(インポート済みをタグ付け)と**Tag source**(出典をタグ付け)は、どちらもデフォルトでオンで、インポートする項目に**Imported**(インポート済み)と**ST**のタグを追加します。付けたくないタグのチェックを外してください。インポートする項目の名前と説明はそのまま保持されます。それ以外に、これらのボタンに設定はありません。キャラクターのインポートでは、元のタグをすべて引き継ぎ、正規表現スクリプトの適用範囲をそのキャラクターに限定します。正規表現スクリプトとは、テキストを検索して置き換えるルールです。この2つを自分で選ぶには、**Library → Characters**(ライブラリー → キャラクター)ページの**Import**を使ってください。[キャラクターカードのインポートとエクスポート](../characters/import-export.md)を参照してください。

キャラクターカードの中にロアブックが入っていると、独立したロアブックとしてインポートするかどうかをブラウザーが確認します。後で使い回せるロアブックとして残すなら**OK**を、キャラクターだけをインポートするなら**Cancel**をクリックします。

**Import Chat (JSONL)**は、ファイルに別のモードが記録されていない限りRoleplayのチャットを作成し、そのチャットを開きます。

### モードを指定したチャットのインポート

モードを選ぶには、チャット一覧の上部にあるインポートボタンを使います。ツールチップは**Import SillyTavern or Marinara chat JSONL**です。開いているモードのタブ(Conversation、Roleplay、Game)にインポートします。[チャットのエクスポートとインポート](../chats/export-import.md)を参照してください。

## SillyTavernフォルダーのインポート

始める前に: ウィザードは、サーバーのコンピューター上のファイルを読み取ります。SillyTavernが別のコンピューターにある場合は、先にそのフォルダー(SillyTavernをインストールしたフォルダー)をMarinaraのコンピューターにコピーしてください。Marinaraのコンピューターでは、ウィザードはそのまま使えます。別のデバイスから使う場合は、管理者用のシークレットを設定し、**Settings → Advanced → Security**に入力してください。[Marinaraのバックアップと復元](backup-and-restore.md)と、[サーバー設定リファレンス](../CONFIGURATION.md)の「Privileged APIs (ADMIN_SECRET)」のセクションを参照してください。

1. **Settings → Data → SillyTavern Import**を開きます。
2. **Import from SillyTavern Folder**をクリックします。
3. SillyTavernのフォルダーを選びます。メインフォルダーを選んでください。通常は`data/`または`public/`のフォルダーがあるフォルダーです。次のいずれかの方法を使います。
   - **Browse**をクリックして、フォルダーを選びます。
   - フォルダー選択画面がない場合(リモートサーバー)は、アプリ内蔵のフォルダーブラウザーが開きます。ここには、サーバーを動かしているユーザーのホームフォルダー内のフォルダーだけが表示されます。**Select This Folder**をクリックします。
   - **SillyTavern Folder Path**にパスを入力します。例: `/home/you/SillyTavern`。サーバーを動かしているユーザーのホームフォルダー内であれば、入力したパスを使えます。サーバーの`IMPORT_ALLOWED_ROOTS`設定がある場合は、代わりに、そこで指定されたフォルダーのどれかの中にある必要があります。
4. **Scan Folder**をクリックします。Marinaraが、カテゴリーごとに見つかった件数を表示します。
5. **Choose exactly what to import**で、取り込みたい項目にチェックを入れます。カテゴリーごとに**All**と**None**のボタンがあり、個々の項目には**Show**と**Hide**のトグルがあります。
6. **Import Selected**をクリックします。進行状況バーに、処理中の項目とカテゴリーごとの件数が表示されます。
7. **Import complete!**と表示されたら、カテゴリーごとの件数を確認し、**Done**をクリックします。件数の下には、作者のメモとペルソナを保持したチャットの数、こちらに対応するペルソナがなかったSillyTavernのユーザー名、取り込まれなかったプリセット設定が、短い一覧で表示されます。

ほとんどの項目は、最初から選択されています。SillyTavern標準のプリセット(`deterministic`、`neutral`、`universal-*`など)は、Marinaraがチェックを外したままにし、バナーでそのことを知らせます。コピーが必要でない限り、チェックは外したままにしてください。

スキャンでキャラクターが見つかると、さらに2つの設定が表示されます。

**Imported character tags**(デフォルトは**All tags**)

- **All tags**は、元のタグを残します。
- **No tags**は、タグを取り込みません。
- **Existing only**は、すでにあるタグだけを残します。

**Imported regex scripts**(デフォルトは**Character only**)

- **Character only**は、スクリプトを各キャラクターに適用します。
- **Global**は、**Library → Regex scripts**(ライブラリー → 正規表現スクリプト)(クラシックレイアウトでは**Presets → Regexes**)へ追加します。そこでチャットをまたいで実行するスクリプトを管理できます。[正規表現スクリプト](../extending/regex-scripts.md#manage-your-scripts)を参照してください。

うまくいかなかった場合:

- 「Could not find SillyTavern data directory.」は、Marinaraがそのフォルダーを読み取れないという意味です。SillyTavernのメインフォルダーを選んでください。
- 「Marinara can only read folders inside your home folder」は、そのフォルダーがサーバーを動かしているユーザーのホームフォルダーの外にあるという意味です。SillyTavernのフォルダーをホームフォルダー内に移すか、サーバーを運用している人に`IMPORT_ALLOWED_ROOTS`設定でその場所を許可してもらってください。この設定がある場合は、選んだフォルダーであっても、指定されたフォルダーのどれかの中にある必要があります。[サーバー設定リファレンス](../CONFIGURATION.md)を参照してください。
- ホームフォルダーの外のパスを入力して**Browse**を使うと、代わりにホームフォルダーでフォルダーブラウザーが開きます。
- 項目が1つ失敗した場合、Marinaraはその項目を飛ばして処理を続け、最後のステップの警告に`Character "Foo": error message`のような形で一覧表示します。

## データの扱い

- 1つのキャラクターに属するチャットファイルは、1つのチャットの分岐としてインポートされます。分岐とは、チャットのコピーを別々に続けるものです。
- グループチャットは、Roleplayのチャットとしてインポートされます。
- インポートした項目には、インポートした日付ではなく、元のファイルの最終更新日が付きます。各チャットメッセージも、SillyTavernで保存された日付を保持します。
- チャットの**Author's Note**(作者のメモ)は、深さとともに引き継がれます。SillyTavernで別の頻度、位置、ロールを使っていた場合も、Marinaraは毎回の返信でその深さに追加し、インポート結果にその旨を表示します。SillyTavernでオフになっていたメモは、オフのままです。
- チャットはSillyTavernで使っていたペルソナに関連付けられます。固定されていたペルソナがあればそれを使い、なければチャットのユーザーと同名のペルソナを使います。ペルソナも同時にインポートするか、先に同じ名前のペルソナを作成してください。一致するものがない場合、チャットにはペルソナが付かず、インポート結果に見つからなかったペルソナの名前が表示されます。
- プリセットは、温度、Top P、Top K、Min P、頻度ペナルティー、存在ペナルティー、推論の強度のサンプラー設定を引き継ぎます。これらはそのプリセットを使うチャットの初期値になり、接続やチャット独自の値があれば、そちらが優先されます。最大応答長とコンテキストサイズは接続の設定のままです。Top Aと反復ペナルティーは対応する設定がないため、取り込まれません。
- **Import Selected**の上の**Tag imported**または**Tag source**のチェックを外さない限り、キャラクター、ペルソナ、ロアブック、プリセット、チャットに**Imported**と**ST**のタグが付きます。名前と説明はそのまま保持されます。

## 引き継がれないもの

ウィザードが読み取るのは、最初の表にあるカテゴリーだけです。アプリ全体の設定、クイックリプライ、インストラクトテンプレートとコンテキストテンプレート、接続プロファイルなど、他のSillyTavernのデータはインポートされません。この修正より前にインポートしたチャットでは、メッセージの日付がインポート時刻になっていました。修正するには、そのチャットを削除してファイルを再インポートしてください(フォルダーからのインポートでは**Skip what's already here**(すでにあるものはスキップ)のチェックを外します)。
