# プロンプトビューアー

プロンプトビューアーはプリセット、ロアブック、キャラクター、ペルソナを並べ、組み上がるプロンプトをMarinaraの送信順で表示します。各部分をクリックしてその場で編集できます。変更は実際のプリセット、ロアブック、カード、ペルソナに保存され、ほかのエディターにもすぐ反映されます。

kolacheのAIO Prompt Viewer and Editor拡張から始まり、現在は新レイアウトに組み込まれています。

<a id="opening-it"></a>
## 開き方

- **コンピューター：** トップバーのSearch直後にあるプロンプトビューアーボタン（🥞）。
- **スマートフォンやタブレット：** トップバーのタブ数からAll Tabsを開き、**+**横のプロンプトビューアーボタン（🥞）をタップします。
- **どこからでも：** Searchで`prompt viewer`と入力します。

専用タブで開きます。タブを切り替えても選択内容と未保存の編集は残り、未保存のまま閉じる場合は確認します。

<a id="the-three-columns"></a>
## 3つの列

| 列 | 用途 |
| --- | --- |
| **Sources** | プリセット、1冊以上のロアブック、キャラクター（グループなら複数）、ペルソナを選びます。項目やフォルダーをチェックしてプロンプトに含めます。**+**は新規作成、鉛筆は設定を開きます。 |
| **プロンプト** | プリセットのセクション、位置と深度に配置したロアブック項目、マーカー内のキャラクターとペルソナをEngineの組み立て順で表示します。**Validate**は未閉鎖のXMLタグや壊れた`{{macros}}`を検出します。セクションをドラッグして順序を変えられます。 |
| **Editor** | 選んだ部分のフィールドです。**保存**で保存し、**元に戻す**で編集を破棄します。 |

スマートフォンや縦向きタブレットでは**Sources / プロンプト / Editor**で切り替えます。ブロックを選ぶとEditorが開きます。

<a id="inspect-summaries-and-settings"></a>
## Inspect、Summaries、Settings

ページ上部のボタンでページ内の各画面を開き、**戻る**で列に戻ります。

- **調べる**はモデルに送る形で表示します。チャットが開いていると、**Include history**はマクロ解決済み・履歴調整済みの正確なプロンプトをEngineに要求します。**Omit history**はチャットのプレースホルダー付きの構造を表示します。テキストかJSONメッセージ一覧としてコピーできます。
- **Summaries**は無効な項目を含め、ライブラリーの全チャット要約をMarkdownかJSONへ書き出します。チャットを開く必要はありません。
- **設定**ではInspectの履歴処理、接続のないチャットの表示ターン数、Prompt列のバッジ、Inspectの色を設定します。

<a id="what-it-does-not-show"></a>
## 表示しない内容

- Prompt列にはエージェントを含めません。InspectはEngineに問い合わせるため含みます。
- 履歴、要約、会話例、エージェントデータはPrompt列ではプレースホルダーです。内容はチャット実行時にのみ存在します。
- グループのターンごとの動作（応答者、「Respond only as…」）は、チャットを開くまで説明のみで、構築されません。
