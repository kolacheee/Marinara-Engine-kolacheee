# Roleplay：按规则集游玩

Roleplay 聊天可以按桌面规则集游玩，和 Game Mode 用的是同一类。遇到不确定的事情时，旁白会要求检定，Marinara 从人物卡掷骰，回复说明这次掷骰定下了什么。想在角色扮演里用真正的骰子和人物卡、又不想开一局 Game Mode 时，就用它。

你为 Game Mode 装过的任何规则集都能用，例如 5e (SRD 5.1)，你在角色编辑器和用户角色编辑器里已经为它建好的人物卡也能用。

## 为聊天开启规则集

开始之前：先安装一个规则集。见[获取规则集](../game/rulesets.md#get-a-ruleset)。

1. 打开 Roleplay 聊天。
2. 打开 **Chat Settings**(聊天设置)，找到 **Ruleset**(规则集) 分区。
3. 从列表里选一个规则集。列表显示你已安装的规则集。
4. Marinara 给聊天里的每个成员一张人物卡，并说明加了几张。每个成员都列在规则集下面。

每个成员会从角色编辑器或用户角色编辑器得到自己那张人物卡在这个规则集下的副本（见[规则集人物卡](../characters/colors-and-stats.md#ruleset-sheets)）。没有人物卡的成员会得到一张空白人物卡，在列表里标为 **blank sheet**(空白人物卡)，可以在聊天里填写。你的用户角色排在最前面。聊天里的改动只留在聊天里，绝不会写回角色或用户角色。

如果没有成功：导入的规则集需要开启 **Allow custom Agent imports**(允许导入自定义智能体)。见[获取规则集](../game/rulesets.md#get-a-ruleset)。

### 填写空白人物卡

1. 在 **Ruleset** 分区里，点击成员旁边的 **Build sheet**(建立人物卡)。
2. 人物卡在人物卡编辑器里打开。规则集带引导式构建器时，会先在那个构建器里打开，和 Game Mode 及角色编辑器里一样。
3. 做好选择，点击 **Save sheet**(保存人物卡)。

### 为新成员添加人物卡

之后有角色加入聊天时，点击 **Add missing sheets**(补齐缺少的人物卡)。已经有人物卡的成员保持原样。

### 移除人物卡

不该有人物卡的成员，例如旁白角色卡，可以拿掉它的人物卡。

1. 在 **Ruleset** 分区里，点击成员旁边的垃圾桶图标。
2. 点击 **Remove sheet**(移除人物卡)。

聊天会记住这一点，所以 **Add missing sheets** 和更新版本的规则集都会跳过这名成员。想再给他一张人物卡，就点击 **No sheet:**(没有人物卡) 后面那个以他命名的按钮，例如 **Give Mira a sheet**(给 Mira 一张人物卡)。

### 更换或关闭规则集

- 选择 **None**(无) 就不再按规则集游玩。人物卡会保留，所以再次选择同一个规则集时会从上次停下的地方继续。
- 换用别的规则集会让人物卡全部重新开始，因为为某个规则集做的人物卡对另一个规则集没有意义。

## 游玩中的检定

你照常写自己的回合。当角色尝试结果重要的不确定行动时，旁白会写一次检定，而不是直接决定结果。Marinara 从人物卡掷这次检定，然后由旁白写出掷骰定下了什么。

完成的消息会在检定发生的位置显示一张骰子卡片，包含技能、难度、骰子，以及 **Success**(成功) 或 **Failure**(失败)。不会真正失败的普通行动不会有检定。

> **提示：** 有些模型会忽略要求检定的指令，自己决定结果。如果一个检定都不出现，就给聊天的 **Connection**(连接) 换一个更强的模型。

**Impersonate**(代写) 回合不掷检定。多人模式房间不能按规则集游玩。

## 使用人物卡

在 **Ruleset** 分区里点击某个成员旁边的 **Open sheet**(打开人物卡)。这张人物卡和 Game Mode 显示的是同一张。Tracker Panel 顶部的卷轴按钮会打开你用户角色的人物卡。

- 点击资源池或轨道旁边的 **−** 和 **+**，例如生命值或压力，就能改动它。改动随当前这条消息保存，所以会跟着备选回复和分支走。
- 点击 **Edit ruleset sheet**(编辑规则集人物卡)，可以修改数值、技能等级、字段和列表，然后点击 **Save sheet**(保存人物卡)。

旁白在每个回合都会读人物卡，并用回复里的人物卡命令修改它们，Marinara 会执行这些命令，并把它们从消息里隐藏。要休息，就在你的回合里说明，例如“我们长休一次”。旁白会记录休息，人物卡会恢复规则集的休息所恢复的内容。也可以在人物卡上点击 **Rest**(休息)。

## 制作自己的规则集

规则集构建器通过表单创建小型规则集：检定怎么掷骰、人物卡包含什么，以及告诉旁白哪些规则。Marinara 没有你想用的系统时，就用它。自己制作的规则集和安装的规则集一样，都能在 Roleplay 和 Game Mode 里使用。

开始之前：开启 **Allow custom Agent imports**，因为构建器保存规则集的方式与导入相同。见[获取规则集](../game/rulesets.md#get-a-ruleset)。

1. 在 **Chat Settings → Ruleset**(聊天设置 → 规则集) 里点击 **New ruleset…**(新建规则集…)。
2. 填写 **Name**(名称)。
3. 在 **Dice**(骰子) 下选择检定的掷骰方式（见下表）。选择后会填入初始属性、资源池和轨道，可以自行修改。
4. 修改 **Difficulties**(难度)、**Stats**(属性)、**Skills**(技能) 和表单里的其他内容。大多数分区的标题下都有一行说明。
5. 点击 **Create ruleset**(创建规则集)。

Marinara 会保存规则集。如果聊天还没有规则集，也会启用新规则集。已有规则集的聊天会保留原有规则集和人物卡；要切换，从列表里选择新规则集。

如果已安装的某个规则集使用你选的掷骰方式，**Dice** 分区会显示它的名字。每个角色在每套规则集里都有独立的人物卡，所以想让每个角色只保留一张人物卡，就使用或编辑已有规则集，不必另建。

| 骰子 | 检定的掷骰方式 |
| --- | --- |
| **d20 + modifier**(d20 + 修正值) | d20 加上属性和技能，与难度数值比较。 |
| **2d6 bands**(2d6 分段判定) | 2d6 加上属性：10 及以上为强成功，7 到 9 为弱成功，6 及以下为失败。 |
| **Dice pool**(骰池) | 属性和技能每点各掷一颗骰子，统计达到目标点数的骰子数量。可以选择 d6 或 d10，以及目标点数。 |
| **Highest d6**(取最高 d6) | 每点掷一颗 d6，取最高点数：6 为完全成功，4 或 5 为部分成功，两颗 6 为大成功。 |
| **Percentile**(百分骰) | 掷一颗 d100。点数不高于技能数值即成功。 |
| **Hope and Fear**(希望与恐惧) | 两颗 d12 加上属性。点数较高的骰子决定结果伴随希望还是恐惧。 |
| **No dice**(无骰) | 不掷骰子。将属性和技能相加，再与难度比较。 |

### 修改自己制作的规则集

1. 为一个聊天启用该规则集。
2. 在 **Chat Settings → Ruleset** 里点击 **Edit ruleset**(编辑规则集)。
3. 修改后点击 **Save new version**(保存新版本)。

聊天会转到新版本，并保留全部人物卡。重命名属性、技能、资源池或列表列时，会保留每个角色在其中的内容。使用同一规则集的其他聊天，会在你点击该聊天里的 **Add missing sheets** 时转到新版本。

自己制作或从文件导入的规则集，只要表单能完整容纳，就会出现 **Edit ruleset**：包括构建器制作的规则集，或只使用表单所列内容的手写文件。来自包或仓库的规则集不会出现这个按钮。构建器不会打开含有额外内容（例如战斗规则或注释）的规则集，因此不会丢掉它无法显示的部分。按钮也只出现在使用最新版本的聊天里；聊天使用旧版时，先点击 **Add missing sheets**。

### 安排人物卡布局

| 表单中的设置 | 人物卡上的效果 |
| --- | --- |
| 行的顺序 | 属性、技能、资源池、轨道、字段和列表选项卡按表单顺序显示。拖动行的手柄即可移动，也可以让手柄获得焦点后按上下方向键。 |
| 属性或技能的 **Group**(分组) | 同组的属性或技能显示在同一个标题下。 |
| **Skill ranks**(技能等级) | 在人物卡上为每项技能选择的等级，以及各级的加值：d20 或 2d6 增加总点数，骰池增加骰子数，百分骰增加技能值。 |
| **人物卡中的等级显示为** | 人物卡在每个已训练技能和豁免旁显示的内容：**检定值（+2）**、**等级名称**、**圆点（●●○）**、**罗马数字（II）** 或 **等级数字（2）**。检定和旁白看到的人物卡副本保持不变。 |
| **Practice meter**(熟练进度) | 每项受训技能显示距下一级的进度，从 0 到 99%。故事中的练习会提升进度，升级后重新开始。可以在人物卡上修正。在 **No meter for:**(以下技能不显示进度：) 下勾选一个分组，即可排除其中的技能。 |
| 资源池或轨道上的 **Number**(数字)、**Bar**(进度条) 或 **Dots**(圆点) | 只显示数字，在数字旁显示进度条，或显示一排圆点，每点数值填满一个圆点。超过 20 个圆点时改为进度条。 |
| **Lists**(列表) | 每个列表都有自己的选项卡，默认以列表命名，也可以另填选项卡名称。选项卡名称相同的列表共用一个选项卡。 |
| 列表的列 | 每行都有名称，以及你添加的列：**Text**(文本)、**Number** 或 **Checkbox**(复选框)。第一个复选框列会显示为每个名称旁的勾选框。 |

### 向旁白说明规则

**Prompts**(提示词) 分区存放要告诉旁白的规则集说明。**Checks**(检定) 和 **Keeping the sheets**(维护人物卡) 会显示默认内容，留空即可使用。换行会变成空格。名称和提示词不能包含方括号或双花括号，因为旁白的标签和宏要用它们。

| 输入框 | 用途 |
| --- | --- |
| **Checks** | 何时要求检定，以及如何选择技能和难度。 |
| **Keeping the sheets** | 游玩过程中如何修改人物卡。 |
| **Rules reference**(规则参考) | 自定规则，以及旁白应始终能参考的其他内容。 |
| **World (Game Mode)**(世界（Game Mode）) | 按该规则集创建 Game Mode 游戏时读取一次，让世界适合这些规则。 |

## 故障排查

| 症状 | 解决办法 |
| --- | --- |
| **This chat's ruleset is not installed here, so its checks and sheets are paused.** | 重新安装这个规则集，或者换一个。 |
| 旁白从不要求检定。 | 给聊天换一个更强的模型。有些模型会跳过检定的指令。 |
| 新角色没有人物卡。 | 点击 **Add missing sheets**。 |
