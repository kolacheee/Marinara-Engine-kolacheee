# 管理聊天列表

聊天位于右侧栏的 **Chats**(聊天) 下。点击右上角的 **Library**(资料库) 可显示或隐藏侧栏，再用侧栏顶部的切换按钮选择 **Chats**（另一侧是 **Library**）。在手机或平板上，点击右上角的叠层按钮；侧栏会覆盖在页面上，同样带有这个切换按钮。在聊天列表里可以新建、查找、排序、整理和删除聊天。

## 聊天列表与模式选项卡

顶部有 **Import**(导入)、**New folder**(新建文件夹)、**Select chats**(选择聊天) 和 **New**(新建)。在手机上，除了 **New**，其他按钮都在它旁边的 **⋯** 菜单里。按钮下方有三个模式选项卡，每个都显示其中的聊天数量（在手机上，第一个显示为 **Conversation**(对话)）。每个选项卡只列出对应模式的聊天。

| 选项卡 | 模式 |
| --- | --- |
| **Convo** | Conversation(对话模式)：即时通讯式的聊天。 |
| **Roleplay** | Roleplay(角色扮演)：带角色和世界状态追踪的场景。 |
| **Game** | Game：由 AI 主持的单人 RPG。 |

每一行显示聊天名称和其中角色的头像。在 Conversation 聊天里，头像上的彩色小点表示那个角色的状态。红色角标是未读消息的数量。带一个小分支图标和数字的行，表示这个聊天有好几个分支，它们归在同一行里。见[聊天分支](branches.md)。在电脑上，把鼠标指向某一行，会显示聊天预览以及 **Rename chat**(重命名聊天) 和 **Chat tags**(聊天标签) 按钮。

置顶的聊天排在列表最前。要置顶一个聊天，右键点击它（触屏上向左滑动），然后选择 **Pin**(置顶)。

## 新建聊天

开始之前：在 **Connections**(连接) 里至少添加一个账号。见[连接 AI 服务商](../connections/connecting-to-a-provider.md)。

1. 点击你想要的模式选项卡。
2. 点击列表顶部的 **New**(新建)。它的提示文字会随选项卡显示为 **New Conversation**、**New Roleplay** 或 **New Game**。也可以从主页的 **Conversation**、**Roleplay** 或 **Game** 开始聊天。

Marinara 会创建并打开这个聊天，旁边同时打开 **Chat Settings**(聊天设置) 和一个设置向导。完成设置之前，聊天不会出现在列表里。如果离开设置时选择保留，它会显示为 **Setup not finished**(设置未完成)，方便之后回来继续。聊天的初始名称是 **New Conversation**、**New Roleplay** 或 **New Game**。如果你为 Conversation 或 Roleplay 保存过一个加了星标的默认设置方案，Marinara 会把它套用到新聊天上。见[设置方案](settings-profiles.md)。

如果没有成功：还没有保存任何账号时，打开的不是聊天，而是 **Add account**(添加账号) 窗口。选一个服务，点击 **Connect**(连接)，然后选择一个模型。完整步骤见[连接 AI 服务商](../connections/connecting-to-a-provider.md)。

## 导入聊天

可以导入来自 SillyTavern 或 Marinara 的 `.jsonl` 聊天记录。

1. 点击聊天要落入的那个模式选项卡。
2. 点击列表顶部的 **Import**(导入) 按钮（向下的箭头）。它的标签是 **Import SillyTavern or Marinara chat JSONL**。
3. 选择你的 `.jsonl` 文件。

Marinara 会创建并打开这个聊天，并显示 **Imported N messages**。导出格式和批量导出见[导出与导入聊天](export-import.md)。

如果没有成功：屏幕底部会出现一条简短的消息 **Import failed**，并写明原因。只接受 `.jsonl` 文件。

## 给聊天改名

聊天名称只给你自己看，不会发给模型。

1. 打开聊天，再打开 **Chat Settings**。
2. 在 **Chat Name**(聊天名称) 中点击当前名称。
3. 输入新名称，然后按 <kbd>Enter</kbd> 或点击对勾。

怎么打开这个面板，见[聊天设置总览](chat-settings.md)。

## 删除聊天

1. 右键点击聊天那一行，选择 **Delete**(删除)。在触屏上，向左滑动或长按那一行，再点击 **Delete**。
2. 在 **Delete Chat**(删除聊天) 对话框里点击 **Delete**(删除)。

删除是永久的。它也会中止这个聊天里仍在生成的回复。要一次删除多个，见[选中多个聊天](#selecting-multiple-chats)。

如果这个聊天有好几个分支，对话框会说明有几个，并给出两个选择：

- **Delete This Branch Only**(只删除这个分支) 删掉你点击的那个分支。
- **Delete All N branches**(删除全部 N 个分支) 删掉这一组里的每个分支。

想在不删除聊天的前提下管理分支，见[聊天分支](branches.md)。

这些对话框由全应用范围的设置 **Confirm before deleting**(删除前确认) 控制。它默认开启，在 **Settings → General → Confirmations & Help**(设置 → 常规 → 确认提示与帮助) 里。

## 聊天文件夹

文件夹用来在一个模式选项卡内给聊天分组。

1. 打开一个至少有一个聊天的选项卡。
2. 点击 **New folder**(新建文件夹)（列表顶部的文件夹按钮）。文件夹会命名为 **unnamed**(之后依次是 **unnamed 2**、**unnamed 3**)。

| 想做什么 | 怎么做 |
| --- | --- |
| 给文件夹改名 | 双击它或在触屏上点两下，或者聚焦它再按 <kbd>F2</kbd>。空名称会被忽略。 |
| 删除文件夹 | 点击文件夹那一行上的垃圾桶按钮。文件夹里有聊天时，会出现 **Delete Folder**(删除文件夹) 对话框。聊天会移到顶层，不会被删除。 |
| 调整文件夹顺序 | 把文件夹上下拖动。排序菜单会切换为 **Custom**(自定义)。 |
| 把聊天放进文件夹 | 把聊天那一行拖到文件夹上。在触摸屏上，要先长按聊天大约半秒。 |
| 把聊天移出文件夹 | 把它拖到文件夹下方的空白区域。 |

选中了多个聊天时，拖动其中一个会带着整批一起移动。不在文件夹里的聊天排在文件夹下方。

## 搜索、排序和筛选

### 按名称查找聊天

每个选项卡都有一个搜索框，占位文字是 **Search conversations**、**Search roleplays** 或 **Search games**。输入一个词即可。它匹配聊天名称、标签和角色名称，不匹配消息正文。

### 按标签筛选

点击 **Tags**(标签)（搜索框旁的标签按钮）。选择一个或多个标签，或 **Untagged**(无标签)。按钮会显示已选数量。一个聊天及其分支只计一次。要给聊天添加标签，使用那一行上的 **Chat tags**，或右键菜单、滑动菜单里的 **Tags**。

### 在所有聊天中查找消息

按 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>（Mac 上是 <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>），或用顶栏的搜索按钮查找这项功能。它会搜索所有聊天，并可以按模式、角色、发送者和日期筛选。

### 排序

排序菜单（**Sort chats**(聊天排序)）有这些选项：

| 选项 | 顺序 |
| --- | --- |
| **Custom** | 你的文件夹顺序。 |
| **Manual order**(手动排序) | 按你拖动排好的顺序排列聊天。用键盘时，聚焦一个聊天后按 <kbd>Alt</kbd>+<kbd>Up</kbd> 或 <kbd>Alt</kbd>+<kbd>Down</kbd>。 |
| **Recent**(最近) | 最近活跃的排在最前。这是默认值。 |
| **Newest**(最新) | 最近创建的排在最前。 |
| **Oldest**(最早) | 最早创建的排在最前。 |
| **A to Z** 和 **Z to A** | 按名称排序。 |

列表最初显示 40 个聊天，滚动到接近末尾时会再加载 40 个。

## 列表何时更新

为了保持应用流畅，聊天列表不会不停地重新加载：

- 在本设备上创建、修改或删除聊天时，列表会立即更新。
- 其他设备上的更改（比如在手机上新建了聊天），会在你从其他应用或浏览器标签页回到应用时显示：列表会在那一刻刷新一次。
- 服务器无法主动向设备推送更改。如果两台设备同时打开应用，要切到别处再回来，才能看到另一台设备上的更改。

## 选中多个聊天

1. 点击列表顶部的对勾按钮（**Select chats**(选择聊天)）。
2. 逐个点击你想要的聊天。这时点击不会打开聊天，各行会显示一个复选框。
3. 使用底部的操作栏，它会显示选中了多少个聊天。

**Export**(导出) 会把选中的聊天下载成一个 `.zip` 文件，里面是一个个 `.jsonl` 文件。**Delete** 会先弹出 **Delete Chats**(删除聊天) 对话框请你确认，然后删除它们。再点一次对勾按钮就会退出选择模式。切换选项卡也会清空选择。

## 主页上的最近聊天

主页上有一个 **Recent chats**(最近聊天) 小组件，列出你最近的聊天。每个聊天显示名称、模式角标和最后一条消息。点击某个聊天即可打开它。还没有任何聊天时，它会显示 **Your chats will show here**。见[主页小组件](../home/welcome.md#home-widgets)。
