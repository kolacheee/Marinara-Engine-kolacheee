# 标签页、分屏视图和未保存的改动

在新布局里，每个打开的聊天、角色、用户角色、世界书、预设和应用都有自己的标签页，方便随时切换。本指南介绍如何移动标签页、给标签页分组、并排查看两个页面，以及未保存的改动会如何处理。

## 找到标签页

- **电脑和横屏平板：**标签页位于顶部栏。点击一个标签页就能切回去。
- **手机和竖屏平板：**点击右上角的数字按钮。**All Tabs**(所有标签页) 会把每个标签页显示为一张卡片。点击卡片即可打开，或点击 **Done**(完成) 返回。

- Characters、Presets 或 Settings 等 **Library 区域**本身不创建标签，因为在 Library 点一下即可打开。要固定在顶栏，可在电脑上从 Library 列表拖到所需标签位置。它会像其他标签一样保留到关闭。
- 在手机上向左或向右**滑动顶部栏**，就能切换到下一个或上一个标签页。

- **聊天标签**先显示模式颜色的符号和缩写：Conversation 用 **CO**，Roleplay 用 **RP**，Game 用 **GM**，然后是聊天名称。同名同模式的聊天加编号，如“Luna · 2”。
- **其他标签**显示类别符号（角色、世界书、用户角色等）和名称。同名聊天和角色保留原名，由符号区分；同类别同名标签也会编号。

## 标签页保留工作位置

返回标签页会回到离开时的位置：

- **编辑器**打开相同页面、区段或条目，包括预设页面和 Prompt order、带搜索和排序的世界书条目、角色或用户角色的图库或立绘标签，以及卡片新增区段。
- **滚动位置**也会在编辑器、列表和聊天中恢复。向上翻过的聊天会打开在该处，而不是最新消息。
- 有意打开指定位置时，例如 Professor Mari 展示某个字段，仍会跳到该位置。

位置保留到关闭标签或刷新页面。

## 移动、分组和关闭标签页

在电脑上右键点击标签页，或在触屏上长按标签页，即可打开菜单：

- **Move left**(左移) 和 **Move right**(右移) 会将标签页移动一位。在电脑上也可以直接拖动。
- **添加到新分组**(添加到新分组) 会把标签页放进一个分组。在电脑上，你也可以把一个标签页拖到另一个标签页上并稍作停留：等那个标签页亮起后松开，两个标签页就会组成一个分组（在分组上松开则加入该分组）。直接快速松开只会移动标签页。松开时按住 Shift 会立即分组。停留在分组内的标签页时，该组的标签页会显示在顶部栏下方的第二行。点击分组名称即可重命名或关闭分组。 该行像 Vivaldi 标签堆叠一样占用完整一行。开头显示分组名和标签数量，点击可重命名、取消分组或关闭。手机或竖向平板的 **所有标签页** 将各组标签集中显示在组名下。
- **Close tab**(关闭标签页) 会关闭当前标签页，**Close other tabs**(关闭其他标签页) 会关闭其余标签页。
- **Reopen closed tab**(重新打开已关闭的标签页) 会重新打开最后关闭的标签页。

在手机上，点击 **All Tabs** 中卡片上的 **X** 就能关闭标签页。

## 分屏视图：同时查看两个页面

在电脑上，可以并排显示两个页面，比如一边查看聊天，一边编辑角色。

1. 将标签页拖到页面最左侧或最右侧的边缘。也可以拖动 Home(主页)、Library(资料库) 中的某个分区、Chats(聊天) 列表中的聊天或 **Docs**(文档) 按钮。
2. 松开后，页面就会分屏：拖动的内容显示在那一侧，原先的页面显示在旁边。

也可以右键点击标签页（触屏上长按），选择 **Open in split view**(在分屏视图中打开)。

两侧各自独立工作：一侧可以流式接收回复，同时在另一侧编辑。任意一侧保存的改动都会立即显示在另一侧。

- **副侧的栏**会显示该侧的内容；如果是聊天，还会显示 **Chat settings**(聊天设置) 按钮，后面是 **Swap sides**(交换两侧)、**Show only this page**(仅显示此页面) 和 **Close split view**(关闭分屏视图)。
- **标签页：**顶部栏的标签页、Chats 列表和 Library 都会在主侧打开内容。显示在副侧的标签页会有标记；点击它即可交换两侧内容。关闭任意一侧的标签页都会结束分屏。
- **大小：**拖动两侧之间的分隔线即可调整。双击分隔线可让两侧等宽。分隔线获得焦点时，也可以用方向键移动。
- **副侧较窄时：**宽度低于约 900 像素时会切换到平板布局，低于约 560 像素时会切换到手机布局。
- **Settings**(设置) 始终在主侧打开。

分屏视图需要足够的空间来放下两个页面。手机不会分屏。横屏平板关闭侧面板后就能分屏。窗口太窄时，第二个页面会暂时收起，空间足够时会恢复分屏。

## 未保存的改动

编辑角色、用户角色、世界书、预设、智能体、连接或正则脚本时，如果没有保存就离开（切换到其他标签页、聊天、Home 或 Library 中的某个分区），改动会留在原标签页里，不会先弹窗询问：

- 标签页名称旁会出现一个小**圆点**，顶部栏和 **All Tabs** 中都能看到，重新加载后也会保留。
- 回到标签页就能继续编辑，改动仍未保存。点击 **Save**(保存) 即可保存这些改动。
- 停止输入约一秒后，改动也会保存在当前浏览器里（持续输入时，保存间隔不超过五秒），所以重新加载、崩溃或关闭标签页最多只会丢失片刻的输入。重新加载后，编辑器会显示一个带有 **Restore**(恢复) 和 **Discard**(放弃) 的提示栏。

如果开始编辑后，同一张卡片在另一台设备上保存过，**Restore** 只会恢复你改过的字段，其余字段保留较新版本的内容。

### 关闭有未保存改动的标签页

关闭当前正在使用的编辑器时，会询问要 **Save**、**Don't save**(不保存) 还是 **Keep editing**(继续编辑)。关闭留有未保存改动的其他标签页时，会提供以下选项：

- **Open to save**(打开以保存) 会切换到该标签页，方便点击 **Save**。
- **Don't save** 会丢弃改动并关闭标签页。
- **Keep tab**(保留标签页) 会保留当前状态。

**Close other tabs** 和 **Close group**(关闭分组) 都不会关闭留有未保存改动的标签页，并会告知保留了多少个。

删除角色、用户角色、世界书、预设、智能体或正则脚本时，会关闭对应的标签页，并丢弃其中尚未保存的改动。

### 编辑消息

正在编辑的消息也会保留。如果还没点击 **Save** 或 **Cancel**(取消) 就切换到其他聊天或标签页，回来时编辑器仍会打开，并保留输入的文本。
