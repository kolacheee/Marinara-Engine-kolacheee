# 首次使用的引导教程

引导教程是一段导览，第一次打开 Marinara Engine 时就会开始。内置助手 Professor Mari 会带你把应用的主要部分逛一遍。用这份指南可以跳过教程、重看教程，或者了解每一步讲了什么。

## 重看引导教程

1. 打开 **Settings → General → Confirmations & Help**(设置 → 常规 → 确认提示与帮助)。
2. 在 **Walkthroughs**(操作指引) 下，点击 **Replay the welcome tour**(重看欢迎导览)。

也可以点击主页上 **Learn the engine**(了解引擎) 小组件里的 **Replay tutorial**(重看教程)。教程会从第一步重新开始。

**Walkthroughs** 还有两个按钮。**Replay the computer walkthrough**(重看电脑操作指引)（或平板、手机）会重看当前设备类型的简短操作指引，**Show chat mode tips again**(再次显示聊天模式提示) 会重新显示各聊天模式的提示。见[各类设备的操作指引](#walkthroughs-for-each-device)。

## 跳过引导教程

每张卡片上都有跳过按钮。第一张卡片上写的是 **Skip Tutorial**(跳过教程)，之后的卡片上写的是 **Skip**(跳过)。点击它就会立刻结束教程。

- **Skip**、**Skip Tutorial** 和最后一张卡片上的按钮都会把教程标记为已完成，之后它不会再自动开始。它们还可能解锁 **Diligent Student** 成就。
- 最后一张卡片上有一个列表，用来选择应用内指南的语言。只有最后一张卡片上的按钮会保存这个选择；**Skip** 会保持原样。之后可以在 **Settings → General → Language → Documentation Language**(设置 → 常规 → 语言 → 文档语言) 里修改。

## 教程是怎么进行的

教程从主页开始，一次只显示一张卡片。每张卡片包含一个标题、一段简短说明和一排进度圆点。光环会高亮出卡片正在讲的屏幕区域，有些步骤还会替你打开它：资料库这一步会打开侧边栏的 **Library**(资料库) 视图（在电脑上还会打开角色页面），聊天这一步会切换到 **Chats**(聊天)，连接这一步会打开连接页面。

点击 **Next**(下一步) 进入下一张卡片。在手机或平板上，卡片和高亮的工作方式相同，并会说明各项功能在触屏设备上的位置。

## 参考：各个步骤

| # | 卡片标题 | 讲解内容 |
| --- | --- | --- |
| 1 | **Welcome to Marinara Engine!** | Professor Mari 提出带你四处看看。 |
| 2 | **The Library** | 右侧的侧边栏及其 **Library** 视图：角色、用户角色、世界书、预设和正则脚本。顶栏里的 **Library** 按钮可以打开或隐藏它。 |
| 3 | **Your Chats** | 同一个侧边栏的 **Chats** 视图，以及聊天里的 **Chat settings**(聊天设置)。 |
| 4 | **Three Ways to Chat** | **Convo**、**Roleplay** 和 **Game** 选项卡，以及各模式的用途。 |
| 5 | **Connections: Set This Up First** | 打开连接页面。聊天前先添加一个连接。 |
| 6 | **Agents** | 打开智能体页面，在这里安装可选功能。 |
| 7 | **Settings (and SillyTavern Imports)** | 打开 **Settings**(设置) 的 **Data**(数据) 选项卡，从 SillyTavern 导入数据的功能就在这里。 |
| 8 | **Tabs and Search** | 顶栏里的标签页和搜索按钮（<kbd>Ctrl</kbd>+<kbd>K</kbd>）。 |
| 9 | **The Docs, and You're Set!** | **Docs**(文档) 按钮，以及指南的语言列表。 |

在手机或平板上，教程会多一张 **Handy Gestures**(便捷手势) 卡片（共十步）。资料库在右上角的堆叠按钮里，聊天在同一页面的顶部，点击标题可打开搜索，文档则在资料库里。

## 各类设备的操作指引

在每种设备（电脑、平板、手机）上首次打开 Marinara 时，都会显示一段简短的操作指引，即使你已经在其他设备上完成了完整教程。它会介绍聊天、资料库和搜索在这类设备上的位置，触屏设备上还会显示 **Handy Gestures** 卡片。在这台设备上首次打开各个聊天模式时，也会显示对应的提示。可以在 **Settings → General → Confirmations & Help → Walkthroughs**(设置 → 常规 → 确认提示与帮助 → 操作指引) 里重看。
