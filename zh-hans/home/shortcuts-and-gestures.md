# 键盘快捷键与触屏手势

电脑可用键盘，手机或平板可用滑动和下拉操作。这里列出全部操作，**设置 › 快捷键** 也有相同列表。不在输入框打字时，任意位置按 <kbd>?</kbd> 即可打开该页。

Mac 上，除非另有说明，这里的 <kbd>Ctrl</kbd> 指 <kbd>⌘</kbd>，<kbd>Alt</kbd> 指 <kbd>⌥</kbd>（Option）。

<a id="going-back-and-forward"></a>
## 后退与前进

Marinara 像浏览器一样记住访问的页面：聊天、角色、世界书、预设、Library 区域、Docs、Professor Mari 和 Home。可以逐步后退或前进。

- **电脑：** 点击左上标志旁 **←**、**→**，按 <kbd>Alt</kbd>+<kbd>←</kbd>、<kbd>Alt</kbd>+<kbd>→</kbd>（Mac 为 <kbd>⌘</kbd>+<kbd>[</kbd>、<kbd>⌘</kbd>+<kbd>]</kbd>），或用鼠标侧面的前后退键。
- **手机和平板：** 从左边缘向内滑，或用浏览器、Android 返回键。每步关闭最上层：菜单、面板、聊天设置、编辑器、Library 页面，再返回 Home。

注意：

- 后退后打开新页会丢弃前进记录，和浏览器一样。
- 已关闭标签的页面会跳过。
- 无处可退时箭头变灰，按键和鼠标恢复浏览器默认行为。
- 未保存编辑留在原标签，和切换标签一样（见[标签、分屏和未保存更改](tabs-and-drafts.md)）。

<a id="keyboard-shortcuts"></a>
## 键盘快捷键

<a id="moving-around"></a>
### 导航

适用于电脑或连接键盘的横向平板。

| 快捷键 | 作用 |
| ----------------------------------------------------------------------------------- | ------------------------------------- |
| <kbd>Alt</kbd>+<kbd>←</kbd>，或鼠标后退键                             | 返回上一页 |
| <kbd>Alt</kbd>+<kbd>→</kbd>，或鼠标前进键                          | 后退后再次前进 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>←</kbd> 或 <kbd>Alt</kbd>+<kbd>Page Up</kbd>   | 上一个标签 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>→</kbd> 或 <kbd>Alt</kbd>+<kbd>Page Down</kbd> | 下一个标签 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd> 至 <kbd>8</kbd>                        | 按从左起编号切换标签 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>9</kbd>                                        | 最后一个标签 |
| <kbd>Alt</kbd>+<kbd>W</kbd>                                                         | 关闭当前标签 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd>                                       | 重开刚关闭的标签 |

标签使用 <kbd>Alt</kbd>+<kbd>Shift</kbd>，因为浏览器保留 <kbd>Ctrl</kbd>+<kbd>Tab</kbd>、<kbd>Ctrl</kbd>+<kbd>W</kbd> 和 <kbd>Ctrl</kbd>+<kbd>1</kbd> 至 <kbd>9</kbd> 操作自身标签，Linux 的 Chrome 和 Firefox 还保留 <kbd>Alt</kbd>+<kbd>1</kbd> 至 <kbd>9</kbd>。<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> 只在 Firefox 或已安装应用中传给 Marinara，其他情况用标签右键菜单的 **重新打开已关闭的标签页**。

<a id="everywhere"></a>
### 全局

| 快捷键 | 作用 |
| ------------------------------------------ | ------------------------------------------------------------------------------ |
| <kbd>Ctrl</kbd>+<kbd>K</kbd>               | 打开或关闭 Search |
| <kbd>Ctrl</kbd>+<kbd>J</kbd>               | 打开 Professor Mari（Windows、Linux，输入时除外） |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>Enter</kbd> | 浏览并打开搜索结果 |
| <kbd>Tab</kbd>                             | 接受搜索补全 |
| <kbd>Alt</kbd>+<kbd>M</kbd>                | 打开输入框模型选择器 |
| <kbd>?</kbd>                               | 打开 **设置 › 快捷键**（输入时除外） |
| <kbd>Esc</kbd>                             | 关闭菜单、浮层或对话框 |

<a id="message-box"></a>
### 消息输入框

| 快捷键 | 作用 |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| <kbd>Enter</kbd>                                                   | 发送（该模式开启 Send on Enter） |
| <kbd>Shift</kbd>+<kbd>Enter</kbd>                                  | Enter 发送时换行 |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd>                                   | Send on Enter 关闭时发送 |
| <kbd>↑</kbd>                                                       | 空输入框编辑自己的最新消息（需 **上方向键编辑最后一条消息**） |
| <kbd>↑</kbd> <kbd>↓</kbd>, then <kbd>Tab</kbd> 或 <kbd>Enter</kbd> | 浏览并接受 /命令、@提及或 :emoji: 建议 |

<a id="messages"></a>
### 消息

| 快捷键 | 作用 |
| -------------------------------- | ----------------------------------------------------------------------------------- |
| <kbd>←</kbd> <kbd>→</kbd>        | 最新消息的上一或下一回复（需 **直观的候选回复导航**） |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | 保存消息编辑 |
| <kbd>Esc</kbd>                   | 取消消息编辑 |
| <kbd>Enter</kbd>                 | 跳到首个消息搜索结果 |

<a id="editors"></a>
### 编辑器

| 快捷键 | 作用 |
| -------------------------------------------------------- | ---------------------------------------------------------------------- |
| <kbd>Ctrl</kbd>+<kbd>S</kbd>                             | 保存当前编辑器 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd>         | 提示词或文件编辑器增加、减少缩进 |
| <kbd>Esc</kbd>, then <kbd>Tab</kbd>                      | 离开提示词框 |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> / <kbd>Esc</kbd>            | Game Assets 全选或清除选择 |
| <kbd>←</kbd> <kbd>→</kbd> <kbd>Home</kbd> <kbd>End</kbd> | 焦点在拖柄时调整侧边栏或分屏分隔线 |

<a id="game-mode"></a>
### Game Mode

| 快捷键 | 作用 |
| ------------------------------------------------------ | ------------------------------------ |
| <kbd>↑</kbd> <kbd>↓</kbd> 或 <kbd>W</kbd> <kbd>S</kbd> | 切换战斗行动 |
| <kbd>Enter</kbd> 或 <kbd>Space</kbd>                   | 选择高亮战斗行动 |

<a id="touch-gestures"></a>
## 触屏手势

| 手势 | 作用 |
| ----------------------------------------- | --------------------------------------------------------------- |
| 从左边缘向内滑 | 后退一步 |
| 左右滑动顶栏标题 | 下一个或上一个标签 |
| 向下拉顶栏 | 打开 Search，拉向 Mari 则打开 Professor Mari |
| 从 Chats 列表顶部下拉 | 重载列表，包含其他设备新建聊天 |
| 左右滑动最新回复 | 切换回复（超出末条时先询问再生成） |
| 左滑聊天行 | 置顶、重命名、标签和删除 |
| 长按消息、聊天行或标签 | 打开菜单 |

<a id="the-edge-swipe-in-the-home-screen-app"></a>
### 主屏幕应用的边缘滑动

Safari 的左缘滑动由浏览器处理，Marinara 让每次只退一层而不离开应用。通过 **Share › Add to Home Screen** 添加的应用没有自身返回手势，Marinara 会绘制跟随手指的圆箭头，拉到足够距离后变色。松开后退，滑回边缘取消。右向左语言从右缘开始。

<a id="every-gesture-has-a-button"></a>
### 每种手势都有按钮

无需依赖手势：

- **返回：** 页顶 **‹** 或 **主页**。
- **切换标签：** 右上标签按钮显示 **所有标签页**。
- **搜索：** 顶栏放大镜。
- **刷新聊天：** Chats 列表 **⋯** 菜单的 **刷新列表**（电脑用列表顶端圆箭头）。
- **回复：** 最新回复的 **Reply 1 of 3** 显示其他版本。
- **聊天操作：** 长按该行。

<a id="turning-swipes-off"></a>
### 关闭滑动

在 **设置 › 快捷键 › 触控手势** 关闭 **触屏滑动手势**，会停用标题、回复和聊天行滑动，横拖只滚动。边缘返回、下拉和长按仍可用。
