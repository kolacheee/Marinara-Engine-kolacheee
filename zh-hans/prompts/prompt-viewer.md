# 提示词查看器

提示词查看器把预设、世界书、角色和用户角色并排展示，并按 Marinara 的发送顺序显示它们组成的提示词。点击任一部分可直接编辑。修改会保存到实际的预设、世界书、角色卡或用户角色，其他编辑器会立即显示。

它最初是 kolache 的 AIO Prompt Viewer and Editor 扩展，现在已集成到新布局。

<a id="opening-it"></a>
## 打开方式

- **电脑：** 顶栏 Search 后面的提示词查看器按钮（🥞）。
- **手机或平板：** 点击顶栏标签数量打开 All Tabs，再点击 **+** 旁的提示词查看器按钮（🥞）。
- **任何位置：** 打开 Search，输入 `prompt viewer`。

它在独立标签页打开。切换标签会保留选择和未保存的编辑；有未保存编辑时，关闭前会询问。

<a id="the-three-columns"></a>
## 三个栏位

| 栏位 | 用途 |
| --- | --- |
| **Sources** | 选择预设、一本或多本世界书、角色（群聊可选多个）和用户角色。勾选条目或文件夹以加入提示词。**+** 新建项目，铅笔打开设置。 |
| **提示词** | 按 Engine 组装顺序显示所选内容：预设区段、位于各自位置与深度的世界书条目、标记内的角色和用户角色。**Validate** 查找未闭合 XML 标签和损坏的 `{{macros}}`。拖动区段可调整预设顺序。 |
| **Editor** | 所点部分的字段。**保存** 保存回原项目，**还原** 放弃编辑。 |

手机或竖向平板通过 **Sources / 提示词 / Editor** 切换栏位，点击区块会进入 Editor。

<a id="inspect-summaries-and-settings"></a>
## Inspect、Summaries 和 Settings

页面顶部按钮在页面内打开这些视图，**返回** 返回三栏。

- **检查** 显示实际发送给模型的提示词形式。打开聊天时，**Include history** 向 Engine 请求精确提示词（宏已解析、历史已裁剪到合适大小）；**Omit history** 显示结构，以占位符替代聊天。可复制为文本或 JSON 消息列表。
- **Summaries** 将资料库全部聊天摘要导出为 Markdown 或 JSON，包含已禁用条目，无需打开聊天。
- **设置** 设置 Inspect 如何处理历史、未连接聊天显示多少回合、Prompt 栏显示哪些徽章，以及 Inspect 的颜色。

<a id="what-it-does-not-show"></a>
## 不显示的内容

- Prompt 栏省略智能体；Inspect 会向 Engine 请求，因此包含智能体。
- 历史、摘要、对话示例和智能体数据在 Prompt 栏只是占位符：聊天运行时才有实际内容。
- 群聊每回合的行为（谁回复、“Respond only as…”）在打开聊天前只有说明，不会实际组装。
