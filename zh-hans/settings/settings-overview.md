# 设置总览

查找某个控件位于 **Settings**(设置) 的哪一部分，设置 **General**(常规) 选项卡，并了解设置如何在多台设备之间同步。

## 打开设置

打开 **Library → Settings**(资料库 → 设置)：点击右上角的 **Library**(资料库)，再点击资料库列表下方的 **Settings**。也可以按 <kbd>Ctrl</kbd>+<kbd>K</kbd>（Mac 上为 <kbd>⌘</kbd>+<kbd>K</kbd>），输入 `streaming` 或 `font` 之类的设置名称，直接跳到该设置。手机上，设置位于右上角堆叠图标按钮打开的资料库里。

页面顶部的 **Search all settings**(搜索所有设置) 可以按名称查找设置。输入 `delete`、`streaming` 或 `quotes` 之类的词，Marinara 就会跳到对应的部分。它同时匹配你的界面语言和英语中的名称。

设置有九个选项卡。选项卡下方的一排按钮可以跳到当前选项卡的各个部分。在这些指南中，**Settings → Chatting → Message Box**(设置 → 聊天中 → 消息输入框) 这样的路径指的是：**Chatting**(聊天中) 选项卡中的 **Message Box**(消息输入框) 部分。

### 语言

| 设置 | 作用 |
| --- | --- |
| **Language** | 设置界面语言。它不会改变模型提示词或聊天内容。尚未翻译的文字会以英语显示。阿拉伯语采用从右到左的排版。默认值：英语。 |
| **Documentation Language** | 设置内置指南的语言。见下文。默认值：英语。 |

界面语言有阿拉伯语、简体中文、英语、法语、德语、印地语、日语、韩语、波兰语、巴西葡萄牙语、俄语和西班牙语。想改进译文或添加新语言，请参见[界面本地化](../development/localization.md)。

对于 **Documentation Language**(文档语言)，英语是内置的。选择其他语言后点击 **Download & Replace**(下载并替换)。Marinara 会下载一次该语言包，并删除之前的语言包，因此本地只保留一种已下载的语言。尚未翻译的指南会以英语打开，并带有一个小的 `EN` 标记。文档搜索使用当前生效的语言。你的选择在更新后仍然保留；译文有变化时，语言包会在更新后刷新。如果已下载的指南丢失或损坏，会出现 **Fix documentation**(修复文档) 按钮。它会重新下载语言包；如果无法连接下载源，则把指南恢复为英语。

### 通知

Marinara 为通知播放内置提示音。想使用你自己的声音：

1. 打开 **Settings → General → Notifications**。
2. 点击 **Custom sound**(自定义声音) 下的 **Choose sound**(选择声音)：支持 MP3、WAV、OGG、M4A、MP4 或 WebM，最大 10 MB。

这个声音会在连接到此服务器的每台设备上播放。你可以预览、替换或删除它。如果无法读取该文件，Marinara 会播放内置提示音。该文件属于备份和档案导出的一部分。

**Background Notifications**(后台通知) 负责角色自行发送的对话消息。**Generation Completion Notifications**(生成完成通知) 负责你在 Conversation、Roleplay 和 Game Mode 中自行发起的回复。两者都在 Marinara 已打开但不在焦点时生效。它们从不显示消息内容。 **Notification position**(通知位置) 决定错误消息和其他通知显示在顶部还是底部。

<a id="get-notifications-on-your-phone-while-marinara-is-closed"></a>
#### Marinara 关闭时也接收手机通知

**推送通知（ntfy）** 在全部标签和 Android 应用关闭时仍能送达。服务器通过免费 ntfy 服务发送，它有 Android 和 iPhone 应用。

先安装 ntfy。需要在服务器所在电脑打开 Marinara，或在此设备保存管理员密钥。见[远程访问](../REMOTE_ACCESS.md)。

1. 在 **设置 → General → 通知** 开启 **发送推送通知**。Marinara 会生成随机 **主题**，作为通知私人频道。
2. 手机点 **在 ntfy 中打开**，或 **复制** 后在 ntfy 订阅该主题。
3. 点 **发送测试通知**，手机会显示“Marinara test notification”。

两个开关选择通知内容：

- **角色主动发送的消息**：Conversation 角色主动消息，没有设备打开时服务器也会编写。
- **你发起的回复，且在完成前关闭了 Marinara**：仅在保存前关闭或离开页面时通知。应用打开时由原有通知负责。

通知显示作者和“Open Marinara to read it.”。开启 **显示消息预览** 则发送回复开头最多 200 字符。点通知在 **要打开的地址** 打开聊天，初始是开启通知时的地址；手机使用其他地址时应修改。

> **注意：** `ntfy.sh` 的标题和预览经过公共服务器，知道主题的人都可读取。泄漏时点 **新主题**。若需完全留在自有设备，可运行 ntfy 服务器，在 **ntfy 服务器** 填地址，局域网服务器也可用。

测试失败时 Marinara 会说明原因，通常是服务器无法访问 **ntfy 服务器** 地址。

### Text Formatting

这些规则改变聊天文字的处理方式，位于 **Settings → Chatting → Text Formatting**(设置 → 聊天中 → 文本格式)。**Bold dialogue in quotes**(引号内对白加粗) 和 **Convert LaTeX symbols**(转换 LaTeX 符号) 只改变文字的显示效果，已保存的消息保持不变。**Quote style**(引号样式) 则会改写你输入并保存的文字中的引号。

| 设置 | 作用 |
| --- | --- |
| **Bold dialogue in quotes** | 把引号内的文字显示为粗体。默认开启。 |
| **Convert LaTeX symbols** | 把 LaTeX 数学命令显示为符号。代码不受影响。默认开启。 |
| **Force Solid Colors for Inline Names**(行内名称强制使用纯色) | 将消息内的角色名称显示为纯色，而不是渐变色。 |
| **Quote style** | **Straight** 保留普通引号（默认）。**Typographic** 把它们改写为弯引号和弯撇号。 |

#### 引号内对白加粗

开启后，`"I missed you," she said.` 中引号内的文字会显示为粗体。关闭它则保留对白的颜色，但不加粗。

#### 转换 LaTeX 符号

有些模型用 LaTeX 命令书写数学式。开启后，`\rightarrow`、`\neq`、`\times` 和 `\alpha` 会分别显示为 `→`、`≠`、`×` 和 `α`。

#### 在消息中加载其他网站的图片

这个开关位于 **Settings → Advanced → Security**(设置 → 高级 → 安全)。默认关闭。关闭时，消息、开场白或卡片预览中来自其他网站的图片会显示该网站的名称和一个 **Load image**(加载图片) 按钮。这样，消息不会自行连接其他网站。选择 **Load image** 即可显示该图片。Marinara 会在你所有的设备上记住你的选择。开启此设置后，所有图片会立即显示。保存在 Marinara 中的图片，例如图库图片、头像和立绘，始终会显示。

## 设置如何在多台设备之间同步

Marinara 把大部分设置保存在服务器上，因此它们会跟着你在不同浏览器和设备之间走。

1. 你在 **Settings** 中更改一项设置。
2. 大约一秒后，Marinara 把它保存到服务器。
3. 打开同一服务器的另一个浏览器会加载这些设置。

最新的改动优先。如果你在改动后不久就在第二台设备上打开 Marinara，那边较旧的副本可能会覆盖你的改动。切换设备前，请稍等片刻。

有两项设置永远不会同步。请在每台设备上，于 **Settings → Appearance → Fonts & Text Size** 中分别设置：

- **Display Size**，即界面文字大小
- **Chat Font Size**，即聊天文字大小

参见[外观设置](../appearance/appearance-settings.md)。如果无法连接服务器，应用会继续使用本地设置，并在你下次改动设置时再次尝试。
