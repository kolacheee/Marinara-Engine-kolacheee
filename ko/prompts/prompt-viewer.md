# 프롬프트 뷰어

프롬프트 뷰어는 프리셋, 로어북, 캐릭터, 페르소나를 나란히 놓고 이들이 만드는 프롬프트를 Marinara가 보내는 순서로 보여 줍니다. 부분을 클릭해 바로 편집하세요. 변경은 실제 프리셋, 로어북, 카드, 페르소나에 저장되므로 다른 편집기에도 즉시 나타납니다.

kolache의 AIO Prompt Viewer and Editor 확장으로 시작해 이제 새 레이아웃에 포함되었습니다.

<a id="opening-it"></a>
## 열기

- **컴퓨터:** 상단 바의 Search 바로 뒤에 있는 프롬프트 뷰어 버튼(🥞).
- **휴대폰이나 태블릿:** 상단 바의 탭 수로 All Tabs를 열고 **+** 옆의 프롬프트 뷰어 버튼(🥞)을 누르세요.
- **어디서든:** Search를 열어 `prompt viewer`를 입력하세요.

자체 탭으로 열립니다. 탭을 전환해도 선택과 미저장 편집이 유지되며, 미저장 편집이 있으면 닫기 전에 확인합니다.

<a id="the-three-columns"></a>
## 세 열

| 열 | 용도 |
| --- | --- |
| **Sources** | 프리셋, 하나 이상의 로어북, 캐릭터(그룹이면 여러 명), 페르소나를 선택합니다. 항목이나 폴더를 체크해 프롬프트에 넣습니다. **+**는 새 항목을 만들고 연필은 설정을 엽니다. |
| **프롬프트** | 프리셋 섹션, 위치와 깊이에 맞춘 로어북 항목, 마커 안의 캐릭터와 페르소나를 Engine 조립 순서로 표시합니다. **Validate**는 닫히지 않은 XML 태그와 깨진 `{{macros}}`를 찾습니다. 섹션을 끌어 프리셋 순서를 바꾸세요. |
| **Editor** | 클릭한 부분의 필드입니다. **저장**는 저장하고 **되돌리기**는 편집을 버립니다. |

휴대폰이나 세로 태블릿에서는 **Sources / 프롬프트 / Editor**로 열을 바꿉니다. 블록을 누르면 Editor로 이동합니다.

<a id="inspect-summaries-and-settings"></a>
## Inspect, Summaries, Settings

상단 버튼이 이 화면들을 페이지 안에서 열고 **뒤로**이 열 보기로 돌아갑니다.

- **조사**는 모델에 보낼 프롬프트를 보여 줍니다. 채팅이 열려 있으면 **Include history**가 매크로를 해석하고 기록을 크기에 맞춘 정확한 프롬프트를 요청합니다. **Omit history**는 채팅 자리표시자로 구조를 보여 줍니다. 텍스트나 JSON 메시지 목록으로 복사하세요.
- **Summaries**는 꺼진 항목까지 라이브러리의 모든 채팅 요약을 Markdown이나 JSON으로 내보냅니다. 채팅을 열 필요가 없습니다.
- **설정**는 Inspect의 기록 처리, 연결 없는 채팅의 턴 수, Prompt 열의 배지와 Inspect 색상을 정합니다.

<a id="what-it-does-not-show"></a>
## 표시하지 않는 내용

- Prompt 열은 에이전트를 빼지만 Inspect는 Engine에 요청하므로 포함합니다.
- 기록, 요약, 대화 예시, 에이전트 데이터는 Prompt 열의 자리표시자입니다. 실제 내용은 채팅이 실행될 때만 존재합니다.
- 그룹의 턴별 동작(응답자, “Respond only as…”)은 채팅을 열기 전에는 설명만 있고 구성되지는 않습니다.
