# 채팅 목록 관리

채팅은 오른쪽 사이드바의 **Chats**(채팅)에 모여 있습니다. 오른쪽 위의 **Library**(라이브러리)를 클릭해 사이드바를 표시하거나 숨기고, 사이드바 위쪽 전환 버튼에서 **Chats**를 고르세요(반대쪽은 **Library**입니다). 휴대폰이나 태블릿에서는 오른쪽 위의 겹친 모양 버튼을 탭하세요. 같은 전환 버튼이 있는 사이드바가 페이지 위로 펼쳐집니다. Chats 목록에서 채팅을 시작하고, 찾고, 정렬하고, 정리하고, 삭제할 수 있습니다.

## 채팅 목록과 모드 탭

위쪽에는 **Import**, **New folder**, **Select chats**(채팅 선택), **New**가 있습니다. 휴대폰에서는 **New**를 제외한 나머지가 그 옆의 **⋯** 메뉴에 있습니다. 그 아래에는 모드 탭이 3개 있으며, 각 탭에 채팅 개수가 표시됩니다(휴대폰에서는 첫 번째 탭이 **Conversation**으로 표시됩니다). 각 탭에는 그 모드의 채팅만 표시됩니다.

| 탭 | 모드 |
| --- | --- |
| **Convo** | Conversation(대화): 메신저처럼 주고받는 채팅입니다. |
| **Roleplay** | Roleplay(롤플레이): 캐릭터와 세계 상태를 함께 따라가는 장면입니다. |
| **Game** | Game: AI가 진행하는 1인용 RPG입니다. |

각 줄에는 채팅 이름과 참여 캐릭터의 아바타가 표시됩니다. Conversation 채팅에서는 아바타에 붙은 색점으로 그 캐릭터의 상태를 알 수 있습니다. 빨간 배지는 읽지 않은 메시지 개수입니다. 작은 분기 아이콘과 숫자가 붙은 줄은 분기가 여러 개인 채팅을 한 줄로 묶은 것입니다. [채팅 분기](branches.md)를 참고하세요. 컴퓨터에서는 줄에 마우스를 올리면 채팅 미리보기와 **Rename chat**(채팅 이름 변경), **Chat tags**(채팅 태그) 버튼이 나타납니다.

고정한 채팅은 목록 맨 앞에 표시됩니다. 채팅을 고정하려면 마우스 오른쪽 버튼으로 클릭하고(터치 화면에서는 왼쪽으로 스와이프하고) **Pin**(고정)을 고르세요.

## 채팅 시작하기

시작하기 전에: **Connections**(연결)에서 계정을 하나 이상 추가하세요. [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

1. 원하는 모드의 탭을 클릭하세요.
2. 목록 위쪽의 **New**(새로 만들기)를 클릭하세요. 툴팁은 탭에 따라 **New Conversation**(새 대화), **New Roleplay**(새 롤플레이), **New Game**(새 게임) 중 하나입니다. 홈의 **Conversation**(대화), **Roleplay**, **Game**에서도 채팅을 시작할 수 있습니다.

Marinara가 채팅을 만들고 엽니다. 그 옆에 **Chat Settings**(채팅 설정)와 설정 마법사가 함께 열립니다. 설정을 마치기 전에는 채팅이 목록에 표시되지 않습니다. 설정을 나갈 때 보관하기로 선택하면 **Setup not finished**(설정이 완료되지 않음)로 표시되어 나중에 돌아올 수 있습니다. 채팅의 처음 이름은 **New Conversation**, **New Roleplay**, **New Game** 중 하나입니다. Conversation이나 Roleplay용 기본 설정 프로필을 별표로 저장해 두었다면 Marinara가 새 채팅에 그 프로필을 적용합니다. [설정 프로필](settings-profiles.md)을 참고하세요.

작동하지 않는 경우: 저장된 계정이 없으면 채팅 대신 **Add account**(계정 추가) 창이 열립니다. 서비스를 고르고 **Connect**(연결)를 클릭한 다음 모델을 고르세요. 전체 단계는 [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)에 있습니다.

## 채팅 가져오기

SillyTavern이나 Marinara의 `.jsonl` 채팅 기록을 가져올 수 있습니다.

1. 가져온 채팅이 들어갈 모드의 탭을 클릭하세요.
2. 목록 위쪽의 **Import**(가져오기) 버튼(다운로드 화살표)을 클릭하세요. 버튼의 라벨은 **Import SillyTavern or Marinara chat JSONL**입니다.
3. `.jsonl` 파일을 고르세요.

Marinara가 채팅을 만들어 열고 **Imported N messages**(메시지 N개를 가져왔습니다)를 표시합니다. 내보내기 형식과 일괄 내보내기는 [채팅 내보내기와 가져오기](export-import.md)를 참고하세요.

작동하지 않는 경우: 화면 아래쪽에 **Import failed**(가져오기 실패)라는 짧은 메시지가 이유와 함께 표시됩니다. `.jsonl` 파일만 가져올 수 있습니다.

## 채팅 이름 바꾸기

채팅 이름은 나에게만 보입니다. 모델에는 전달되지 않습니다.

1. 채팅을 연 다음 **Chat Settings**를 여세요.
2. **Chat Name**(채팅 제목)에서 현재 이름을 클릭하세요.
3. 새 이름을 입력한 뒤 <kbd>Enter</kbd>를 누르거나 체크 표시를 클릭하세요.

패널을 여는 방법은 [채팅 설정](chat-settings.md)을 참고하세요.

## 채팅 삭제하기

1. 채팅 줄을 마우스 오른쪽 버튼으로 클릭하고 **Delete**를 고르세요. 터치 화면에서는 줄을 왼쪽으로 스와이프하거나 길게 누른 다음 **Delete**를 탭하세요.
2. **Delete Chat**(채팅 삭제) 창에서 **Delete**(삭제)를 클릭하세요.

삭제는 되돌릴 수 없습니다. 그 채팅에서 아직 작성 중이던 답변도 함께 멈춥니다. 한 번에 여러 개를 삭제하려면 [채팅 여러 개 선택하기](#selecting-multiple-chats)를 참고하세요.

채팅에 분기가 여러 개 있으면 창에 분기 개수가 표시되고, 두 가지 선택지가 나옵니다.

- **Delete This Branch Only**(이 분기만 삭제)는 클릭한 분기를 지웁니다.
- **Delete All N branches**는 묶음 안의 모든 분기를 지웁니다.

채팅을 지우지 않고 분기를 관리하려면 [채팅 분기](branches.md)를 참고하세요.

이 확인 창은 앱 전체 설정인 **Confirm before deleting**(삭제 전 확인하기)이 제어합니다. 기본값은 켜짐입니다. **Settings → General → Confirmations & Help**(설정 → 일반 → 확인 및 도움말)에 있습니다.

## 채팅 폴더

폴더는 한 모드 탭 안에서 채팅을 묶습니다.

1. 채팅이 하나 이상 있는 탭을 여세요.
2. **New folder**(새 폴더)를 클릭하세요(목록 위쪽의 폴더 버튼입니다). 폴더 이름은 **unnamed**가 됩니다(그다음은 **unnamed 2**, **unnamed 3**).

| 하려는 일 | 방법 |
| --- | --- |
| 폴더 이름 바꾸기 | 폴더를 더블 클릭하거나 두 번 탭하세요. 또는 폴더에 포커스를 두고 <kbd>F2</kbd>를 누르세요. 빈 이름은 무시됩니다. |
| 폴더 삭제 | 폴더 줄의 휴지통 버튼을 클릭하세요. 폴더에 채팅이 들어 있으면 **Delete Folder**(폴더 삭제) 창이 나타납니다. 채팅은 최상위로 옮겨지며 삭제되지 않습니다. |
| 폴더 순서 바꾸기 | 폴더를 위아래로 끌어 놓으세요. 정렬 메뉴가 **Custom**(사용자 지정)으로 바뀝니다. |
| 채팅을 폴더에 넣기 | 채팅 줄을 폴더 위로 끌어 놓으세요. 터치 화면에서는 먼저 채팅을 0.5초 정도 길게 누르세요. |
| 채팅을 폴더에서 빼기 | 채팅을 폴더 아래의 빈 영역으로 끌어 놓으세요. |

채팅을 여러 개 선택한 상태에서 하나를 끌면 선택한 채팅 전체가 함께 이동합니다. 폴더에 들어 있지 않은 채팅은 폴더 아래에 나열됩니다.

## 검색, 정렬, 필터

### 이름으로 채팅 찾기

탭마다 검색란이 있습니다. 플레이스홀더는 탭에 따라 **Search conversations**(대화 검색...), **Search roleplays**(롤플레이 검색...), **Search games**(게임 검색...) 중 하나입니다. 단어를 입력하세요. 채팅 이름, 태그, 캐릭터 이름과 일치하는 채팅을 찾으며, 메시지 본문은 검색하지 않습니다.

### 태그로 거르기

**Tags**(태그)를 클릭하세요(검색란 옆의 태그 버튼입니다). 태그를 하나 이상 고르거나 **Untagged**(태그 없음)를 고르세요. 버튼에 선택한 개수가 표시됩니다. 채팅과 그 분기는 하나로 셉니다. 채팅에 태그를 추가하려면 채팅 줄의 **Chat tags**나 마우스 오른쪽 클릭 또는 스와이프 메뉴의 **Tags**를 쓰세요.

### 모든 채팅에서 메시지 찾기

<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>를 누르거나(Mac에서는 <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>), 상단 바의 검색 버튼으로 이 기능을 찾으세요. 모든 채팅을 검색하며, 모드, 캐릭터, 보낸 사람, 날짜로 거를 수 있습니다.

### 정렬

정렬 메뉴(**Sort chats**)에는 다음 선택지가 있습니다.

| 선택지 | 순서 |
| --- | --- |
| **Custom** | 내가 정한 폴더 순서입니다. |
| **Manual order**(수동 정렬) | 채팅을 끌어 놓은 순서입니다. 키보드에서는 채팅에 포커스를 두고 <kbd>Alt</kbd>+<kbd>Up</kbd>이나 <kbd>Alt</kbd>+<kbd>Down</kbd>을 누르세요. |
| **Recent**(최근) | 최근에 활동한 채팅이 먼저 옵니다. 기본값입니다. |
| **Newest**(최신순) | 최근에 만든 채팅이 먼저 옵니다. |
| **Oldest**(오래된순) | 가장 오래된 채팅이 먼저 옵니다. |
| **A to Z**(오름차순)와 **Z to A**(내림차순) | 이름순입니다. |

목록에는 처음에 채팅 40개가 표시되며, 끝부분까지 스크롤하면 다음 40개가 추가됩니다.

## 목록 갱신 시점

앱 속도를 유지하기 위해 Chats 목록은 계속해서 다시 불러오지 않습니다.

- 이 기기에서 채팅을 만들거나 바꾸거나 삭제하면 바로 갱신됩니다.
- 다른 기기에서 바꾼 내용(예: 휴대폰에서 시작한 채팅)은 다른 앱이나 브라우저 탭에서 이 앱으로 돌아올 때 표시됩니다. 그 순간 목록을 한 번 새로 고칩니다.
- 서버는 기기로 변경 내용을 푸시할 수 없습니다. 두 기기에서 나란히 열어 두었다면 앱을 벗어났다가 돌아와야 다른 기기의 변경 내용이 표시됩니다.

## 채팅 여러 개 선택하기

1. 목록 위쪽의 체크 표시 버튼(**Select chats**)을 클릭하세요.
2. 원하는 채팅을 하나씩 클릭하세요. 채팅이 열리지 않고 줄에 체크박스가 표시됩니다.
3. 아래쪽 막대를 쓰세요. 막대에는 선택한 채팅 개수가 표시됩니다.

**Export**(내보내기)는 선택한 채팅을 `.jsonl` 파일들이 담긴 `.zip` 파일 하나로 다운로드합니다. **Delete**는 **Delete Chats**(채팅 삭제) 창에서 확인을 받은 뒤 채팅을 지웁니다. 선택 모드를 끝내려면 체크 표시 버튼을 다시 클릭하세요. 탭을 바꿔도 선택이 해제됩니다.

## 홈 화면의 최근 채팅

홈 화면에는 가장 최근 채팅을 보여 주는 **Recent chats**(최근 채팅) 위젯이 있습니다. 채팅마다 이름, 모드 배지, 마지막 메시지가 표시됩니다. 채팅을 클릭하면 그 채팅이 열립니다. 채팅이 하나도 없으면 위젯에 **Your chats will show here**(채팅이 여기에 표시됩니다)라고 표시됩니다. [홈 위젯](../home/welcome.md#home-widgets)을 참고하세요.
