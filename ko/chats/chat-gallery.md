# 채팅 갤러리

**Gallery**(갤러리)에는 채팅의 그림과 동영상이 보관됩니다. 일러스트, 셀카, 생성한 배경, 스토리보드 프레임과 직접 업로드한 파일이 여기에 들어갑니다. **Chat Settings**(채팅 설정)의 한 섹션이며, 컴퓨터에서는 별도 창으로 띄울 수 있습니다([채팅 설정 개요](chat-settings.md#popping-a-section-out-into-its-own-window) 참고).

채팅의 Gallery는 해당 채팅에 속합니다. 캐릭터가 어느 채팅에 있든 계속 보관할 그림은 캐릭터 자체의 Gallery에 넣으세요. [캐릭터와 페르소나 갤러리](../characters/galleries.md)를 참고하세요.

## 이미지와 동영상

**Gallery**에는 **Images**(이미지)와 **Videos**(동영상) 탭이 있습니다. 각 탭에는 보관된 항목 수가 표시됩니다. **Videos** 탭에는 **Roleplay**(롤플레이)와 **Game Mode**(게임 모드) 채팅의 장면 동영상, **Conversation**(대화) 채팅의 동영상 메시지가 보관됩니다.

섹션 상단의 작업 버튼은 해당 기능을 그 채팅에서 사용할 수 있을 때만 나타납니다.

- **Illustrate**(이미지 생성): Illustrator 에이전트를 한 번 실행해 장면 이미지를 만듭니다. [Illustrator 에이전트](../media/illustrator-agent.md)를 참고하세요.
- **Selfie**(셀카): Conversation 모드에서 캐릭터 셀카를 생성합니다.
- **Background**(배경): 현재 장면의 배경을 생성하고 적용합니다. [Illustrator가 만든 배경](../media/scene-backgrounds.md#paint-a-background-now)을 참고하세요.
- **Video**(비디오): 가장 최근 일러스트로 장면 동영상을 만듭니다. Conversation 모드에서는 대신 캐릭터의 동영상 메시지를 보냅니다. [동영상 메시지](../conversation/selfies.md#video-messages)를 참고하세요.
- **Create storyboard**(스토리보드 만들기): Storyboard가 활성화되어 있으면 가장 최근 Game Mode 턴이나 완료된 Roleplay 에피소드의 키프레임을 생성합니다.
- **Browse Images**: 저장된 이미지 중 삽입할 이미지를 찾아보는 창을 엽니다.
- **View storyboard**(스토리보드 보기): 가장 최근 Game Mode 스토리보드를 엽니다.

버튼 아래에는 **Upload Images**(이미지 업로드) 영역이 있습니다. 이 영역에 이미지를 끌어다 놓으면 직접 준비한 그림을 이 채팅의 Gallery에 추가할 수 있습니다.

### 이미지별 작업

**Images** 탭의 이미지 위로 포인터를 옮기거나 모바일에서 이미지를 탭하면 다음 작업이 표시됩니다.

- 이미지를 전체 크기로 엽니다(**Open gallery image**(갤러리 이미지 열기)).
- **Pin to chat**(채팅에 고정): 이미지를 채팅 위에 떠 있는 그림으로 고정합니다. 끌어서 이동하고 모서리 핸들로 크기를 조절하세요. 이 브라우저에서 페이지를 다시 불러와도 위치와 크기가 유지됩니다. 닫기 버튼 옆의 잠금 버튼을 누르면 잠금을 풀 때까지 이동하거나 크기를 바꿀 수 없습니다.
- **Download image**(이미지 다운로드): 이미지를 기기에 저장합니다.
- **Animate illustration**(삽화 애니메이션 만들기): 해당 이미지를 장면 동영상으로 만듭니다.
- **Copy prompt**(프롬프트 복사): 저장된 이미지 프롬프트를 복사합니다. 이미지에 저장된 프롬프트가 없으면 **No prompt saved**(저장된 프롬프트 없음)가 표시되고 버튼이 비활성화됩니다.
- 그림 왼쪽 위 모서리의 태그 버튼: **Use as background**는 이미지를 배경으로 표시하고 `John's bedroom`처럼 어떤 장소가 담겨 있는지 묻습니다.
- **Add to a character's or persona's gallery**(사람 모양 버튼): 그림을 해당 캐릭터나 페르소나 자체의 갤러리에 보관해 이 채팅이 없어져도 남도록 합니다. 배경 표시와 장소 정보도 함께 저장되며, 이후 해당 캐릭터가 있는 모든 채팅에서 사용할 수 있습니다. [캐릭터를 따라다니는 배경](../roleplay/backgrounds.md#backgrounds-that-follow-a-character)을 참고하세요.
- **Delete gallery image**(갤러리 이미지 삭제): 확인 후 이미지를 삭제합니다.

### 이미지 재생성하기

생성된 이미지가 속한 답변을 재생성하지 않고도 이미지만 다시 만들 수 있습니다. 일러스트, 셀카, 스토리보드 프레임처럼 채팅 Gallery에 저장된 프롬프트가 있는 이미지에서 사용할 수 있습니다.

1. Gallery나 이미지가 포함된 메시지에서 이미지를 전체 크기로 여세요.
2. **Regenerate image**(이미지 재생성)를 클릭하세요(그림 오른쪽 위의 원형 화살표 버튼).
3. 그림 아래에서 원하는 내용을 바꾸세요. **Prompt**(프롬프트), **Negative prompt**(부정 프롬프트), 이미지에 캐릭터별 프롬프트가 있었다면 **Character prompts**(캐릭터 프롬프트) 아래의 캐릭터별 입력란, 이미지 모델을 수정할 수 있습니다.
4. **Generate image**(이미지 생성)를 클릭하거나, 이미지를 그대로 두려면 **Cancel**(취소)을 클릭하세요.

메시지에서는 새 이미지가 이전 이미지를 대체합니다. 이전 이미지는 Gallery에 남으므로 다시 고정할 수 있습니다. 참조 이미지는 캐릭터의 현재 아바타에서 다시 보냅니다. 일부 오래된 이미지는 부정 프롬프트와 캐릭터 프롬프트가 저장되어 있지 않으며, 이 경우 편집기에 안내가 표시됩니다.
