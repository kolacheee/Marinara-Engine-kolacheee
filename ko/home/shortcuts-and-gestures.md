# 키보드 단축키와 터치 제스처

Marinara는 컴퓨터에서 키보드, 휴대폰과 태블릿에서 스와이프·당기기를 지원합니다. 이 가이드와 **설정 › 단축키**에 모두 나옵니다. 입력 칸에서 쓰는 중이 아니라면 어디서든 <kbd>?</kbd>로 엽니다.

Mac에서는 별도 안내가 없으면 <kbd>Ctrl</kbd>는 <kbd>⌘</kbd>, <kbd>Alt</kbd>는 <kbd>⌥</kbd>(Option)입니다.

<a id="going-back-and-forward"></a>
## 뒤로 가기와 앞으로 가기

브라우저처럼 채팅, 캐릭터, 로어북, 프리셋, Library 섹션, Docs, Professor Mari, Home 방문을 기억해 뒤로 갔다 다시 앞으로 갈 수 있습니다.

- **컴퓨터:** 왼쪽 위 로고 옆 **←**, **→**, <kbd>Alt</kbd>+<kbd>←</kbd>과 <kbd>Alt</kbd>+<kbd>→</kbd>(Mac은 <kbd>⌘</kbd>+<kbd>[</kbd>와 <kbd>⌘</kbd>+<kbd>]</kbd>), 또는 마우스 옆 버튼을 쓰세요.
- **휴대폰·태블릿:** 왼쪽 가장자리에서 안으로 밀거나 브라우저·Android 뒤로를 쓰세요. 메뉴, 시트, 채팅 설정, 편집기, Library 페이지, Home 순으로 위에 있는 것을 닫습니다.

알아둘 점:

- 뒤로 간 뒤 새 페이지를 열면 브라우저처럼 앞으로 갈 기록을 버립니다.
- 닫은 탭의 페이지는 건너뜁니다.
- 돌아갈 곳이 없으면 화살표가 회색이고 키와 마우스는 브라우저 기본 동작을 합니다.
- 미저장 편집은 탭 전환처럼 원래 탭에 남습니다([탭, 분할 보기, 미저장 변경](tabs-and-drafts.md) 참고).

## 키보드 단축키

<a id="moving-around"></a>
### 이동

컴퓨터나 키보드를 연결한 가로 태블릿에서 됩니다.

| 단축키 | 동작 |
| ----------------------------------------------------------------------------------- | ------------------------------------- |
| <kbd>Alt</kbd>+<kbd>←</kbd>, 또는 마우스 뒤로 버튼                             | 이전 페이지로 |
| <kbd>Alt</kbd>+<kbd>→</kbd>, 또는 마우스 앞으로 버튼                          | 뒤로 간 뒤 앞으로 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>←</kbd> 또는 <kbd>Alt</kbd>+<kbd>Page Up</kbd>   | 이전 탭 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>→</kbd> 또는 <kbd>Alt</kbd>+<kbd>Page Down</kbd> | 다음 탭 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>1</kbd> ~ <kbd>8</kbd>                        | 왼쪽부터 센 탭으로 |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>9</kbd>                                        | 마지막 탭으로 |
| <kbd>Alt</kbd>+<kbd>W</kbd>                                                         | 표시 탭 닫기 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd>                                       | 마지막 닫은 탭 다시 열기 |

브라우저가 <kbd>Ctrl</kbd>+<kbd>Tab</kbd>, <kbd>Ctrl</kbd>+<kbd>W</kbd>, <kbd>Ctrl</kbd>+<kbd>1</kbd>~<kbd>9</kbd>을 쓰므로 탭은 <kbd>Alt</kbd>+<kbd>Shift</kbd>를 씁니다. Linux의 Chrome·Firefox는 <kbd>Alt</kbd>+<kbd>1</kbd>~<kbd>9</kbd>도 씁니다. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd>는 Firefox나 설치 앱에서만 Marinara로 오며, 그 외에는 탭 우클릭의 **닫은 탭 다시 열기**을 쓰세요.

<a id="touch-gestures"></a>
## 터치 제스처

| 제스처 | 동작 |
| ----------------------------------------- | --------------------------------------------------------------- |
| 왼쪽 가장자리에서 안으로 | 한 단계 뒤로 |
| 상단 제목 좌우 스와이프 | 다음·이전 탭 |
| 상단 바 아래로 당기기 | Search, Mari 쪽으로 당기면 Professor Mari |
| Chats 목록 맨 위에서 아래로 당기기 | 다른 기기 채팅을 포함해 목록 갱신 |
| 최신 답장 좌우 스와이프 | 답장 변경(마지막 다음은 새 생성 전 확인) |
| 채팅 행 왼쪽 스와이프 | 고정·이름·태그·삭제 |
| 메시지·채팅 행·탭 길게 누르기 | 메뉴 열기 |

<a id="the-edge-swipe-in-the-home-screen-app"></a>
### 홈 화면 앱의 가장자리 스와이프

Safari의 왼쪽 가장자리 스와이프는 브라우저 소유이며 Marinara는 앱을 떠나지 않고 한 단계 돌아갑니다. **Share › Add to Home Screen** 앱에는 자체 뒤로 스와이프가 없어 Marinara가 원형 화살표를 그립니다. 손가락을 따라가다 충분히 당기면 색이 바뀝니다. 놓으면 뒤로, 가장자리로 되밀면 취소합니다. 오른쪽에서 왼쪽 언어는 오른쪽 가장자리입니다.

<a id="every-gesture-has-a-button"></a>
### 모든 제스처에 버튼이 있습니다

제스처는 필수가 아닙니다.

- **뒤로:** 페이지 위 **‹** 또는 **홈**.
- **탭 전환:** 오른쪽 위 탭 버튼의 **모든 탭**.
- **검색:** 상단 바 돋보기.
- **채팅 새로고침:** Chats의 **⋯** 안 **목록 새로고침**(컴퓨터는 목록 위 원형 화살표).
- **답장:** 최신 답장의 **Reply 1 of 3**이 다른 버전을 표시합니다.
- **채팅 작업:** 행을 길게 누르세요.

<a id="turning-swipes-off"></a>
### 스와이프 끄기

**설정 › 단축키 › 터치 동작**의 **터치 화면 스와이프 제스처**를 끄면 제목·답장·채팅 행 스와이프가 멈추고 가로 드래그는 스크롤만 합니다. 가장자리 뒤로, 아래 당기기, 길게 누르기는 유지합니다.
