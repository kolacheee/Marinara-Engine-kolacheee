# 첫 실행 튜토리얼

튜토리얼은 Marinara Engine을 처음 열었을 때 시작되는 가이드 투어입니다. 앱에 내장된 어시스턴트 Professor Mari가 앱의 주요 부분을 하나씩 안내합니다. 이 가이드에서는 투어를 건너뛰는 방법, 다시 보는 방법, 각 단계에서 다루는 내용을 설명합니다.

## 튜토리얼 다시 보기

1. **Settings → General → Confirmations & Help**(설정 → 일반 → 확인 및 도움말)를 여세요.
2. **Walkthroughs**(안내)에서 **Replay the welcome tour**(환영 둘러보기 다시 보기)를 클릭하세요.

홈의 **Things to try**(시도해 볼 것) 위젯에서 **See all**(모두 보기)을 열고 **Replay tutorial**(튜토리얼 다시 보기)을 클릭해도 됩니다. 투어가 첫 단계부터 다시 시작합니다.

**Walkthroughs**에는 버튼이 두 개 더 있습니다. **Replay the computer walkthrough**(컴퓨터 안내 다시 보기)(또는 태블릿, 휴대폰)는 현재 기기 종류에 맞는 짧은 안내를 다시 보여 주고, **Show chat mode tips again**(채팅 모드 도움말 다시 보기)은 각 채팅 모드의 도움말을 다시 표시합니다. [기기별 안내](#walkthroughs-for-each-device)를 참고하세요.

## 튜토리얼 건너뛰기

카드마다 건너뛰기 버튼이 있습니다. 첫 카드에서는 **Skip Tutorial**(튜토리얼 건너뛰기)이라고 표시됩니다. 그다음 카드부터는 **Skip**(건너뛰기)이라고 표시됩니다. 이 버튼을 클릭하면 투어가 곧바로 끝납니다.

- **Skip**, **Skip Tutorial**, 마지막 카드의 버튼은 모두 투어를 마친 것으로 기록하므로, 투어가 다시 저절로 시작하지 않습니다. 이 버튼으로 **Diligent Student**(성실한 학생) 업적이 열릴 수도 있습니다.
- 마지막 카드에는 앱 안 가이드의 언어를 고르는 목록이 있습니다. 마지막 카드의 버튼만 선택한 언어를 저장하며, **Skip**은 언어를 그대로 둡니다. 나중에 **Settings → General → Language → Documentation Language**(설정 → 일반 → 언어 → 문서 언어)에서 바꿀 수 있습니다.

## 투어 작동 방식

투어는 홈에서 시작하며 카드를 한 장씩 보여 줍니다. 카드마다 제목, 짧은 설명, 진행 상황을 나타내는 점이 있습니다. 카드가 설명하는 화면 부분을 고리로 강조하며, 일부 단계에서는 그 부분을 열어 줍니다. Library 단계에서는 사이드바의 **Library**(라이브러리) 화면을 열고(컴퓨터에서는 Characters(캐릭터) 페이지도 함께 엽니다), Chats 단계에서는 **Chats**(채팅)로 전환하며, Connections 단계에서는 Connections 페이지를 엽니다.

다음 카드로 넘어가려면 **Next**(다음)를 클릭하세요. 휴대폰이나 태블릿에서도 카드와 강조 표시는 같은 방식으로 동작하며, 터치 화면에서 각 기능이 어디에 있는지 알려 줍니다.

## 참고: 각 단계

| # | 카드 제목 | 다루는 내용 |
| --- | --- | --- |
| 1 | **Welcome to Marinara Engine!**(Marinara Engine에 오신 것을 환영합니다!) | Professor Mari가 앱을 둘러보자고 제안합니다. |
| 2 | **The Library**(라이브러리) | 오른쪽 사이드바와 **Library** 화면입니다. 캐릭터, 페르소나, 로어북, 프리셋, 정규식 스크립트가 있습니다. 상단 바의 **Library** 버튼으로 열거나 숨길 수 있습니다. |
| 3 | **Your Chats**(내 채팅) | 같은 사이드바의 **Chats** 화면과 채팅 안의 **Chat settings**(채팅 설정)입니다. |
| 4 | **Three Ways to Chat**(세 가지 채팅 방식) | **Convo**(대화), **Roleplay**(롤플레이), **Game**(게임) 탭과 각 모드의 용도입니다. |
| 5 | **Connections: Set This Up First**(연결: 먼저 설정하세요) | Connections 페이지를 엽니다. 채팅을 시작하기 전에 연결을 추가하세요. |
| 6 | **Agents**(에이전트) | 선택적 기능을 설치하는 Agents 페이지를 엽니다. |
| 7 | **Settings (and SillyTavern Imports)**(설정, SillyTavern 가져오기 포함) | SillyTavern 가져오기가 있는 **Settings**(설정)의 **Data**(데이터) 탭을 엽니다. |
| 8 | **Tabs and Search**(탭과 검색) | 상단 바의 탭과 검색 버튼(<kbd>Ctrl</kbd>+<kbd>K</kbd>)입니다. |
| 9 | **The Docs, and You're Set!**(문서까지 알면 준비 완료!) | **Docs**(문서) 버튼과 가이드의 언어 목록입니다. |

휴대폰이나 태블릿에서는 **Handy Gestures**(편리한 제스처) 카드가 추가됩니다(총 10단계). 이 기기에서는 오른쪽 위의 겹친 모양 버튼으로 Library를 열고, 같은 페이지 위쪽에서 Chats를 찾을 수 있습니다. 제목을 누르면 검색이 열리며, Docs는 Library 안에 있습니다.

## 기기별 안내

각 기기 종류(컴퓨터, 태블릿, 휴대폰)에서 Marinara를 처음 열면 짧은 안내가 표시됩니다. 다른 기기에서 전체 투어를 마쳤어도 표시됩니다. 그 기기에서 채팅, Library, 검색이 어디에 있는지 보여 주며, 터치 화면에서는 **Handy Gestures** 카드도 표시됩니다. 각 채팅 모드도 해당 기기에서 처음 열 때 자체 도움말을 보여 줍니다. **Settings → General → Confirmations & Help → Walkthroughs**(설정 → 일반 → 확인 및 도움말 → 안내)에서 다시 볼 수 있습니다.
