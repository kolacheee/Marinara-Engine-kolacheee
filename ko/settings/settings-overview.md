# 설정 개요

이 가이드에서는 **Settings**(설정)의 어느 부분에 어떤 조작 항목이 있는지 안내하고, **General**(일반) 탭을 설정하는 방법과 설정이 기기 사이에서 동기화되는 방식을 설명합니다.

## Settings 열기

**Library → Settings**(라이브러리 → 설정)를 여세요. 오른쪽 위의 **Library**를 클릭한 다음 Library 목록 아래의 **Settings**를 클릭하세요. <kbd>Ctrl</kbd>+<kbd>K</kbd>(Mac에서는 <kbd>⌘</kbd>+<kbd>K</kbd>)를 누르고 `streaming`이나 `font` 같은 설정 이름을 입력하면 바로 이동할 수도 있습니다. 휴대폰에서는 오른쪽 위의 겹쳐진 모양 버튼으로 Library를 열면 Settings가 있습니다.

페이지 맨 위의 **Search all settings**(모든 설정 검색) 입력란에서 이름으로 설정을 찾을 수 있습니다. `delete`, `streaming`, `quotes` 같은 단어를 입력하면 Marinara가 해당 섹션으로 바로 이동합니다. 인터페이스 언어로 된 이름과 영어 이름 모두 검색됩니다.

Settings에는 탭이 9개 있습니다. 탭 아래에 나란히 있는 버튼으로 열린 탭의 각 섹션으로 이동할 수 있습니다. 이 가이드들에서 **Settings → Chatting → Message Box**(설정 → 채팅 중 → 메시지 입력창) 같은 경로는 **Chatting** 탭의 **Message Box** 섹션을 뜻합니다.

### Language

| 설정 | 하는 일 |
| --- | --- |
| **Language** | 인터페이스 언어를 정합니다. 모델 프롬프트나 채팅 내용은 바꾸지 않습니다. 아직 번역되지 않은 글은 영어로 표시됩니다. 아랍어는 오른쪽에서 왼쪽으로 읽는 배치를 씁니다. 기본값: 영어. |
| **Documentation Language**(문서 언어) | 내장 가이드의 언어를 정합니다. 아래 내용을 참고하세요. 기본값: 영어. |

인터페이스 언어는 아랍어, 중국어 간체, 영어, 프랑스어, 독일어, 힌디어, 일본어, 한국어, 폴란드어, 브라질 포르투갈어, 러시아어, 스페인어입니다. 번역을 개선하거나 언어를 추가하려면 [UI 지역화](../development/localization.md)를 참고하세요.

**Documentation Language**에서 영어는 내장되어 있습니다. 다른 언어를 고르고 **Download & Replace**(다운로드 및 교체)를 클릭하세요. Marinara가 그 언어 팩을 한 번 다운로드하고 이전 팩을 지우므로, 다운로드된 언어는 하나만 남습니다. 아직 번역되지 않은 가이드는 작은 `EN` 배지와 함께 영어로 열립니다. 가이드 검색은 현재 사용 중인 언어로 작동합니다. 고른 언어는 업데이트 후에도 유지되고, 번역이 바뀌면 업데이트 뒤에 팩을 새로 받습니다. 다운로드한 가이드가 사라지거나 손상되면 **Fix documentation**(문서 복구) 버튼이 나타납니다. 이 버튼은 팩을 다시 다운로드하고, 다운로드 위치에 접근할 수 없으면 가이드를 영어로 되돌립니다.

### Notifications

Marinara는 알림에 기본 내장 소리를 재생합니다. 직접 고른 소리를 쓰려면 다음 단계를 따르세요.

1. **Settings** → **General** → **Notifications**를 여세요.
2. **Custom sound**(사용자 지정 소리) 아래의 **Choose sound**(소리 선택)를 클릭하세요. MP3, WAV, OGG, M4A, MP4, WebM 형식이며 10 MB까지 가능합니다.

이 소리는 이 서버에 연결된 모든 기기에서 재생됩니다. 미리 듣기, 교체, 제거를 할 수 있습니다. 파일을 읽을 수 없으면 Marinara는 기본 내장 소리를 재생합니다. 이 파일은 백업과 프로필 내보내기에 포함됩니다.

**Background Notifications**(백그라운드 알림)는 캐릭터가 스스로 보내는 Conversation 메시지를 알려 줍니다. **Generation Completion Notifications**(생성 완료 알림)는 Conversation, Roleplay, Game Mode에서 직접 시작한 응답을 알려 줍니다. 둘 다 Marinara를 열어 둔 채 다른 창을 보고 있을 때 작동합니다. 메시지 내용은 절대 표시하지 않습니다. **Notification position**(알림 위치)에서 오류 메시지와 다른 알림을 위쪽에 표시할지 아래쪽에 표시할지 고릅니다.

<a id="get-notifications-on-your-phone-while-marinara-is-closed"></a>
#### Marinara를 닫아도 휴대폰 알림 받기

**푸시 알림(ntfy)**는 모든 탭과 Android 앱을 닫아도 도착합니다. 서버가 Android·iPhone 앱이 있는 무료 ntfy 서비스로 보냅니다.

먼저 ntfy 앱을 설치하세요. 서버 컴퓨터에서 Marinara를 열거나 이 기기에 관리자 비밀 키가 있어야 합니다. [원격 접근](../REMOTE_ACCESS.md) 참고.

1. **설정 → 일반 → 알림**에서 **푸시 알림 보내기**를 켭니다. 무작위 **토픽**이 개인 알림 채널로 생깁니다.
2. 폰에서 **ntfy에서 열기**, 또는 **복사**로 주제를 복사해 ntfy에서 구독합니다.
3. **테스트 알림 보내기**을 누르면 “Marinara test notification”이 옵니다.

두 스위치로 고릅니다.

- **캐릭터가 스스로 보내는 메시지**: 자발적인 Conversation 메시지. 열린 기기가 없어도 서버가 씁니다.
- **완료 전에 Marinara를 닫은, 직접 시작한 답변**: 저장 전에 닫거나 떠난 답장만 알립니다. 열려 있으면 기존 알림이 담당합니다.

작성자와 “Open Marinara to read it.”을 표시합니다. **메시지 미리보기 표시**를 켜면 대신 처음 최대 200자를 보냅니다. 누르면 **열 주소**에서 채팅을 엽니다. 처음에는 활성화한 주소이므로 폰 주소가 다르면 바꾸세요.

> **참고:** `ntfy.sh`는 제목과 미리보기가 공개 서버를 지나며 주제를 아는 사람이 읽을 수 있습니다. 유출되면 **새 토픽**을 누르세요. 자체 장비에만 두려면 ntfy 서버를 운영하고 **ntfy 서버**에 주소를 넣으세요. 로컬 네트워크도 됩니다.

테스트 실패 시 이유를 표시합니다. 흔히 Marinara 서버가 **ntfy 서버** 주소에 접근하지 못한 경우입니다.

| **Swipe gestures on touch screens**(터치 화면 스와이프 제스처) | 편집 및 스와이프 | 휴대폰과 태블릿의 새 레이아웃에서 쓰는 스와이프입니다. [터치 제스처](../chats/messages.md#touch-gestures)를 참고하세요. 기본값은 켜짐입니다. |
| **Guide swipes/regens with chat input**(채팅 입력으로 스와이프/재생성 안내) | 편집 및 스와이프 | 재생성할 때 입력해 둔 초안을 지침으로 씁니다. |
| **Always show swipe menu in Conversation**(대화에서 스와이프 메뉴 항상 표시) / **in Roleplay**(롤플레이에서 스와이프 메뉴 항상 표시) | 편집 및 스와이프 | 마우스를 올릴 때만 스와이프 화살표를 표시하는 대신 항상 표시합니다. |

**Responses** 섹션에는 **Type out replies as they arrive (streaming)**(답장이 도착하는 대로 표시, 스트리밍), **Streaming speed**(스트리밍 속도), **Trim incomplete sentences from the response**(응답에서 완성되지 않은 문장 제거), **이어 쓰기 텍스트 앞에 새 줄 추가**(기본값은 켜짐), **Messages per page**(한 번에 표시할 메시지 수)가 있습니다. [메시지 보내기와 스트리밍](../chats/sending-and-streaming.md)을 참고하세요. **Thinking**에는 **Show Thinking In Messages**(메시지에 추론 표시)와 **Don't Collapse Thinking**(생각 접지 않기)가 있습니다. 메시지 조작은 [메시지 조작](../chats/messages.md)을 참고하세요.

### Text Formatting

**Settings → Chatting → Text Formatting**(설정 → 채팅 중 → 텍스트 서식)의 이 규칙들은 채팅 글을 다루는 방식을 바꿉니다. **Bold dialogue in quotes**(따옴표 안의 대사를 굵게 표시)와 **Convert LaTeX symbols**(LaTeX 기호 변환)는 글이 보이는 모양만 바꾸므로 저장된 메시지는 그대로입니다. **Quote style**(따옴표 스타일)은 입력해서 저장하는 글의 따옴표를 다시 씁니다.

| 설정 | 하는 일 |
| --- | --- |
| **Bold dialogue in quotes** | 따옴표 안의 글을 굵게 표시합니다. 기본값은 켜짐입니다. |
| **Convert LaTeX symbols** | LaTeX 수식 명령을 기호로 표시합니다. 코드는 그대로 둡니다. 기본값은 켜짐입니다. |
| **Force Solid Colors for Inline Names**(인라인 이름에 단색 강제 적용) | 메시지 안의 캐릭터 이름을 그라데이션 대신 단색으로 표시합니다. |
| **Quote style** | **Straight**는 곧은 부호를 그대로 씁니다(기본값). **Typographic**은 곧은 부호를 굽은 따옴표와 아포스트로피로 바꿉니다. |

#### Bold dialogue in quotes

이 설정을 켜면 `"I missed you," she said.`에서 따옴표 안의 글이 굵게 표시됩니다. 대사 색상만 남기고 굵은 표시를 없애려면 끄세요.

#### Convert LaTeX symbols

일부 모델은 수식을 LaTeX 명령으로 씁니다. 이 설정을 켜면 `\rightarrow`, `\neq`, `\times`, `\alpha`가 `→`, `≠`, `×`, `α`로 표시됩니다.

#### Load images from other websites in messages

이 스위치는 **Settings → Advanced → Security**(설정 → 고급 → 보안)에 있습니다. 기본값은 꺼짐입니다. 이 설정을 끄면 메시지, 인사말, 카드 미리보기에 있는 다른 웹사이트의 이미지 대신 그 웹사이트 이름과 **Load image**(이미지 불러오기) 버튼이 표시됩니다. 그래서 메시지가 스스로 다른 사이트에 접속하지 못합니다. **Load image**를 선택하면 그 이미지가 표시되며, Marinara는 이 선택을 모든 기기에서 기억합니다. 모든 이미지를 바로 표시하려면 이 설정을 켜세요. 갤러리 그림, 아바타, 스프라이트처럼 Marinara에 저장된 이미지는 항상 표시됩니다.

### Message Info

이 스위치들은 **Settings → Chatting → Message Info**(설정 → 채팅 중 → 메시지 정보)에 있습니다. **Show context usage**(컨텍스트 사용량 표시)와 **Show "older messages not sent" note**("전송되지 않은 이전 메시지" 안내 표시)를 제외하면 모두 기본값이 꺼짐입니다.

| 스위치 | 하는 일 |
| --- | --- |
| **Show message timestamps**(타임스탬프 표시) | 메시지마다 날짜와 시간을 표시합니다. |
| **Show model name on messages**(메시지에 모델 이름 표시) | 각 응답을 쓴 모델을 표시합니다. |
| **Show token usage on messages**(메시지에 토큰 사용량 표시) | 메시지별 프롬프트와 응답의 토큰 수를 표시합니다. |
| **Show context usage** | 마지막으로 측정한 요청에서 컨텍스트 창이 얼마나 찼는지를 연결 전환기와 Game 채팅 설정에 표시합니다. |
| **Show message numbers**(메시지 번호 표시) | 메시지마다 번호를 표시합니다. |
| **Show "older messages not sent" note** | 이전 메시지가 프롬프트에 다 들어가지 못했을 때 최신 응답 아래에 안내를 표시합니다. 잘리거나 비어 있는 응답에는 여전히 그 응답의 안내가 표시됩니다. |

**Include reasoning in exports**(내보내기에 추론 포함)와 **Include private notes in exports**(내보내기에 비공개 메모 포함)는 **Settings → Data → Chat Exports**(설정 → 데이터 → 채팅 내보내기)에 있습니다. [채팅 내보내기와 가져오기](../chats/export-import.md)를 참고하세요.

## 설정이 기기 사이에서 동기화되는 방식

Marinara는 대부분의 설정을 서버에 저장합니다. 그래서 브라우저와 기기를 옮겨 다녀도 설정이 따라옵니다.

1. **Settings**에서 설정을 바꾸세요.
2. 약 1초 뒤에 Marinara가 그 설정을 서버에 저장합니다.
3. 같은 서버를 여는 다른 브라우저가 그 설정을 불러옵니다.

가장 나중에 바꾼 값이 이깁니다. 변경한 직후 두 번째 기기에서 Marinara를 열면, 그 기기의 이전 사본이 방금 바꾼 값을 덮어쓸 수 있습니다. 기기를 옮기기 전에 잠시 기다리세요.

동기화되지 않는 설정이 두 가지 있습니다. **Settings → Appearance → Fonts & Text Size**에서 기기마다 다시 설정하세요.

- **Display Size**(디스플레이 사이즈): 인터페이스 글자 크기
- **Chat Font Size**(채팅 폰트 사이즈): 채팅 글자 크기

[모양 설정](../appearance/appearance-settings.md)을 참고하세요. 서버에 연결할 수 없으면 앱은 기기에 있는 설정으로 계속 동작하고, 다음에 설정을 바꿀 때 다시 저장을 시도합니다.
